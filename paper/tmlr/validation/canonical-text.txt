Emending Nonlinear Recurrence
Erik Garrison
erik.garrison@gmail.com
Poietic PBC / UTHSC, Memphis, TN, USA
Abstract
Fast interaction and feedback require models to update what they know as
new inputs arrive. Emender performs this computation in bounded recurrent
memory: each input corrects the memory’s prediction and applies a nonlinear
transformation to the state carried forward. Many small memory heads execute in
parallel, making the sequential update practical to train. At 1.3 billion parameters,
E97 trains through 150.8 billion Pile tokens on one eight-GPU workstation,
reaching training loss comparable to a closely parameter-matched Gated
DeltaNet-2 control. An extended Frontier run reaches 513.0 billion cumulative
tokens, with its final segment trained on CommaPile. On an invertible nonlinear-
map benchmark, matched-rate fine-tuning across three seeds gives 0.268% versus
0.227% full-state accuracy, with no robust trained-length separation. E97 has
lower extrapolation cross-entropy in every seed at four and eight times the
trained depth. GDN2 leads on long-horizon 𝑆5 permutation composition, a task
that admits an exact linear-state representation. Its strong learning on this task
demonstrates the utility of linear-state recurrence. Neither model learns robust
deep composition on the invertible map at these scales. Formal results characterize
E97′s repeated nonlinear state transformation and GDN’s affine state composition
under a fixed, state-independent parameter schedule. Together, these findings
establish a practical route to training nonlinear recurrence and support further
study of computation through memory in feedback, optimization, and driven
dynamics.

1 Introduction
Keeping balance, following a moving object, and adjusting a movement require continual
revision of an internal estimate as observations arrive. Conversation and perception likewise
require a model to update what it understands while the interaction unfolds. Fast feedback
puts this computation under a per-input time budget. Textual scratchpads and chains of
thought let language models perform visible intermediate computations through generated
tokens [1], [2]. Each additional token adds a decoding step and extends the working sequence.
A complementary question is how much of this ongoing computation can happen directly in
carried memory as inputs arrive. Efficient nonlinear recurrence offers such a path: at inference,
a fixed-width, fixed-depth model transforms fixed-size state with bounded work per update.
1
A sequence can require more than a record of what arrived. Its elements may be instructions
that change a running calculation, measurements that alter a feedback response, or observations
that revise an earlier association. In each case the current state is part of the next computation.
A recurrent model reads an input, updates its internal state, and carries that state into the
following step. The question is what computation the update performs, and how to train it
efficiently at language-model scale.
Emender uses a nonlinear matrix memory. At each step, a head reads its current prediction at an
input-supplied key, writes a correction toward the supplied value, and passes the updated state
through tanh. The write uses what the memory already contains; the nonlinearity transforms
what the next step will receive. Processing a long sequence therefore executes a long composition
of nonlinear state updates.
An emender is one recurrent layer, and Emender is the family of networks formed by stacking
these layers. The current instance, E97, uses separate key-axis erase/read and value-axis write
gates. Each head has a small matrix state, while projections, gates, and a SwiGLU MLP connect
the memories to the rest of the network (Section 3). The memory is revisable: later inputs can
correct earlier associations.
This choice creates a systems problem. Modern linear-state recurrences use the composability
of affine state updates to parallelize training along time [3], [4], [5], [6]. E97 keeps each head’s
nonlinear time loop serial and obtains parallelism across heads and batch elements. We call this
width-axis multi-programming: many small memory programs run side by side, with each state
tile kept on the accelerator (Section 4). This complements hybrid recurrent-attention stacks
and iterative methods for parallelizing nonlinear recurrence [7], [8].
The first empirical question is whether this route is practical. E97 trains through 150.8 billion
tokens on The Pile [9] on one eight-GPU workstation. Its GDN2 control is within 0.01% of
its parameter count. Both arms include the same SwiGLU MLP design; we use GDN2 in the
prose for the experimental arm recorded as GDN2-MLP. The pair uses the same tokenizer, 2,048-
token chunks, optimizer, and local DiLoCo recipe; CMA-ES selects each model’s geometry
and learning rate. Their training losses converge to the same narrow band at matched tokens
(Section 5). The actual-geometry systems preflight also measures comparable throughput and
lower peak memory use for E97. The same E97-MLP architecture was then continued on
Frontier from the 150.79-billion-token checkpoint to 513.0 billion cumulative accepted tokens,
and continued training reduced the recorded rank-0 loss from 2.4365 to 2.2798 nats/token, with
the final segment on CommaPile mainmix (Section 5).
The second question is what these trained models can learn to compute. An invertible two-
coordinate quadratic map tests repeated nonlinear transformation without state merging.
At matched learning rate 1e-3, three-seed fine-tuning gives E97 0.268 ± 0.091% and GDN2
0.227 ± 0.291% full-state accuracy at the trained depth. The paired difference is 0.041 ±
0.201 percentage points (mean ± sample SD): there is no robust separation. E97 has lower
extrapolation cross-entropy in every seed at four and eight times that depth. The 𝑆5 group-
state task asks the models to compose permutation actions. This computation admits an exact
linear-state representation: each token multiplies a carried permutation matrix by its generator
matrix. GDN2 learns this task more effectively in the long-horizon comparison, demonstrating
a useful learned capability on a computation compatible with linear-state recurrence. Section 6
gives the protocols and their limits.
2
The formal analysis describes the state computations behind this comparison. Lean 4 verifies
E97′s time-ordered nonlinear composition and the affine GDN state fold under a fixed, state-
independent parameter schedule. It also relates their split-gated cores and characterizes the
affine group actions of an exact 𝑆5 tracker under a token-only schedule and a decoder that
separates reachable states (Section 7). An exact construction within GDN2′s production gate
and decay ranges is the more specific realization question G3. These statements make the
mechanism precise and supply concrete targets for further experiments and proofs.
The resulting program joins a practical architecture to a testable computational hypothesis.
Feedback systems, iterative optimization, and driven dynamics provide further settings in which
a running state must be transformed repeatedly (Section 8). We proceed from the update and
its implementation to the matched language-model comparison and computational probes, then
develop the formal results and next questions.
2 Background
The central distinction is where nonlinear computation occurs. Mamba [3] and Gated DeltaNet
[5] use nonlinear input processing and gates, and their full networks are nonlinear functions of
the sequence. Once a recurrent layer’s input-derived transition parameters are fixed, its carried-
state update is affine in the previous state. E97 instead transforms the carried state nonlinearly
at each step. These choices organize computation across time differently and call for different
execution strategies.
A standard Transformer [10] processes a sequence through a fixed stack of attention and
nonlinear feed-forward layers. Its layer count is independent of input sequence length.
Autoregressive generation reuses that stack in successive decoding steps; generated intermediate
tokens extend the serial computation. A nonlinear recurrence adds another nonlinear
transformation of its carried state at every input step. This motivates asking which
computations a model learns to place in the state update, in its layers, or in a generated
working sequence.

Linear-state and nonlinear-state recurrence
The recurrent language model lineage runs from Elman networks [11] and the LSTM [12]
through the modern linear-recurrent variants: state-space models such as Mamba and Mamba2
[3], [4], gated linear attention [13], and the delta rule [14]. Many modern designs favor time-
axis parallelism via linear-state updates, whereas nonlinear-in-time recurrence generally uses a
different execution strategy. Gated DeltaNet-2 [6], the split erase/write-gate extension of Gated
DeltaNet [5], supplies the linear-state mixer in the current GDN2 control (Section 5).
A single explicit criterion classifies recurrent architectures. A recurrent layer is linear-state if its
update can be written 𝑆𝑡 = 𝐴𝑡𝑆𝑡−1 + 𝑏𝑡 with 𝐴𝑡 and 𝑏𝑡 determined by input-derived features,
independently of that layer’s previous carried state. Conditioning on these parameters makes
the update affine in 𝑆𝑡−1. Here the state is expressed in vector coordinates; a matrix state may
be vectorized for this criterion. If the previous state 𝑆𝑡−1 appears nonlinearly in its own update
equation, the layer is nonlinear-state. The distinction is structural and applies across choices of
nonlinear activation.
Linear-state designs admit a chunkwise or scan-based parallel implementation along the
time axis because composing 𝑆𝑇 = 𝐴𝑇 𝑆𝑇−1 + 𝑏𝑇 = … unfolds into a product of inputs only.
This is the reason linear-state recurrence dominates the billion-parameter landscape. Mamba,
Mamba2 (SSD), RetNet, GLA, DeltaNet, Gated DeltaNet, RWKV-4/5/6/7, HGRN2, mLSTM,
MinGRU/MinLSTM [15] and Griffin’s RG-LRU [16] are all linear-state by this criterion. At fixed
precision and width, both state regimes are finite-state recognizers. Circuit-complexity results
study restricted state-space models under specified arithmetic and transition assumptions [17].
For transformers, log-precision and uniform-circuit characterizations are given by [18] and [19].
These results motivate explicit computational tasks alongside language-modeling loss.
Nonlinear-state recurrences include the classical LSTM and GRU; the sLSTM block of xLSTM
[20] (memory-mixing through the hidden state inside exponential gates); M²RNN [7] (matrix
state inside tanh with raw-write injection); Titans [21] (MLP memory with online gradient
updates); and the architecture introduced here. The Siegelmann–Sontag result [22] concerns

The 𝑆5 state-tracking probe
The symmetric group 𝑆5 is the group of permutations of five items; it has 120 elements and is the
smallest non-solvable symmetric group. Its word problem is the following task: the model reads
a sequence of permutations — here, adjacent transpositions, the swaps of two neighboring items
— one at a time, and after each one must report the running composition of everything read
so far, its prefix product. By Barrington’s theorem [23] this task is complete for the complexity
class NC1
when exact recognition is required over all words. The experiments measure prefix-
product accuracy at specified lengths. The solvable-group control 𝑆3 (permutations of three
items, 6 elements) is included to factor out the part of difficulty that comes from prefix tracking
per se rather than from non-solvability.
Permutation composition has a direct linear-state realization. Choose 5 × 5 permutation
matrices 𝑃𝑠 with 𝑃𝑠𝑟 = 𝑃𝑠𝑃𝑟 and carry the running matrix 𝑅𝑡:

A dynamics taxonomy of head-types: eigenvalue placement ×
saturation
The linear/nonlinear hinge above, and the choice of where a head’s state may decay, reflect, or
oscillate, are two independent axes of a single design grid. The dynamics of a head’s per-token
state map locate it in a two-axis grid:
1. Eigenvalue placement in the unit disk. Where the along-key eigenvalue of the per-token
state transition sits in the complex unit disk. A real-positive eigenvalue is a decay — the
stored value fades toward zero along the key. A real-negative eigenvalue is a reflection that
flips sign each step (reflect); reaching it is the lever that lets a recurrence track non-
solvable group structure such as 𝑆5 in the restricted transition analyses motivating this grid.
A complex-conjugate pair is a rotation (rot) that oscillates the stored value. Real-positive
5
and real-negative are the two ends of the real diameter; complex placement walks off that
diameter into the rest of the disk.
2. State map: linear or saturated. Whether the state update is left linear or passed through a
bounded saturating nonlinearity (canonically hardtanh; the -nonlin axis; the Emender uses
the smooth variant tanh). Saturation latches a driven slot and makes the head bounded;
finite precision then gives a finite state space.
The grid these two axes span names every Emender head-type (Figure 1). Real × linear at the
positive end is decay, which is vanilla Gated DeltaNet; at the negative end it is reflect, Gated
DeltaNet permitted a negative eigenvalue. Real × saturated is nonlin — the saturated delta-
correcting head, historically tagged E97, whose split-gated instance is the 1.3 B model of this
paper with split erase/read and write gates. Complex × linear is rot, the complex-eigenvalue
oscillator head. Complex × saturated is rot-nonlin, a nonlinear oscillator left to future work,
included as the combination of the two axes. E97 identifies the trained instance; the architecture
vocabulary is this grid.

Parameterization choices
E97 parameterizes the per-head decay 𝑑ℎ in log space, following Mamba2 [4]: each head learns a
scalar 𝐴log and a bias 𝛿bias — the code names A_log and dt_bias — and forms the decay as 𝑑 =
exp(− exp(𝐴log) ⋅ softplus(𝛼(𝑥) + 𝛿bias)), where 𝛼(𝑥) is the input-dependent term and 𝜎 is again
the logistic sigmoid. Both decay parameters are exempt from weight decay, as is standard for
such timescale parameters. The recurrence is computed in float32 and cast back to the storage
9
precision, and the tanh on the state uses the numerically stable form tanh(𝑧) = 2𝜎(2𝑧) − 1 in
the fused kernel to avoid overflow at large pre-activations. Three remaining choices are: there
is no output normalization inside the recurrent layer — an ablation removed it for a 0.10-nat
gain, and the wrapper’s block-level pre-norm plus final norm suffice — no short convolution on
the input. E97 uses the split erase/read and write gates above; its output gate silu(𝑔) still acts
on the read alone.
The 1.3 B stack
Ingredient (d) sets the 1.3 B stack’s shape — many small heads — and the numbers follow from
it: each head’s 32 × 32 tile is small enough to live in registers (Section 4), the head count 𝐻 =
216 is large enough to give that many independent addressing programs per layer, and eleven
such layers — each followed by its SwiGLU MLP, the channel-mixer that pairs with the token-
mixing recurrence — reach the 1.3 B-class budget the paired comparison fixes. The exact values
were selected by the per-architecture search of Section 5. At batch size 4, depth 11 and 𝐻 = 216
multiply to 11 × 216 × 4 = 9{, }504 independent recurrent programs per token, each carrying
its own 32 × 32 state tile. The reference implementation and the fused Triton recurrence kernel
that steps these tiles are identified by the source register and release manifests.
The matched architectural contrast
E97 and GDN2 both use matrix memory, delta correction, split editing gates, and a SwiGLU
channel-mixing MLP. The key distinction for the present hypothesis is the operation performed
on carried state: E97 applies tanh after its correction, whereas the GDN2 state update is
affine when its input-supplied parameters are fixed. Decay placement also differs, as the core
identities above specify. The full networks contain nonlinear projections, gates, and MLPs. The
comparison centers on the transformation applied to carried state. The matched-pair probes
test what the trained architectures learn under the recorded protocol (Section 6); the formal
analysis states the narrower update-map facts (Section 7).
4 Making sequential updates practical
Multi-programming: the throughput-enabling design choice
Width-axis multi-programming supplies throughput while each head’s time loop remains serial.
A linear recurrence earns its throughput on the time axis: because 𝑆𝑡 = 𝐴𝑡𝑆𝑡−1 + 𝑏𝑡 unfolds
into a product that depends on the inputs alone, the step-by-step loop can be re-expressed as a
prefix scan or a chunkwise matrix multiplication over the whole sequence at once. E97 executes
its nonlinear state update in a serial time loop. Multi-programming obtains throughput on the
other axis by replicating the recurrent computation across many independent heads — each
with its own small bounded matrix state — and harvests parallelism across those heads, across
state tiles, and across batch elements, while the time loop inside each head still runs one step
at a time.
The design choice is a decoupling: it frees throughput from the shape of the update. The
recurrent body must stay a bounded, register-resident per-step map at a fixed matrix-state
signature — that is what keeps each head cheap. This implementation supports a programmable
nonlinear update body. The cost is paid in per-head serial time, most exposed at long sequence
10
lengths where the serial loop is longest; the gain is that a nonlinear recurrence can keep a
modern accelerator busy with no time-axis scan at all.
The 1.3 B Emender shape under multi-programming
A modern GPU exposes many independent streaming multiprocessors, each able to run a small
program out of its own registers and shared memory, and multi-programming is built to fill
them. E97, the 1.3 B Emender instance, runs 216 such programs per layer per batch element
— one per head — so at depth 11 and batch size 4 the layer stack issues 11 × 216 × 4 =
9{, }504 small independent recurrent programs per token, each carrying its own 32 × 32 state tile
small enough to live in registers. Keeping the accelerator busy therefore uses parallelism across
memory programs. The paired throughput and memory measurements below test the practical
consequence at the actual E97/GDN2 geometries; direct E97 occupancy profiling remains to
be measured.
Measured throughput and memory use
The throughput measurements and throughput-budget smokes use NVIDIA CUDA.
At the actual 1.3 B pair geometries, the matched-batch preflight on seven RTX 6000 Ada
GPUs under DDP measures E97-MLP at 3,211 tokens/s per GPU and GDN2 at 3,290, both at
batch 4. The ratio is 0.976: comparable throughput, with GDN2 slightly faster. E97 uses 28,942
MB peak memory per GPU against 35,715 MB for GDN2. E97 therefore fits batch 6 under
DDP, reaching 4,470 tokens/s per GPU, where the control cannot fit that batch (experiments/
preflight_100b/RESULTS.md). The lower memory use enables the larger-batch throughput gain.
The preflight uses DDP at the actual pair geometries. The long-run training below uses eight
independent local-DiLoCo islands. Parameter count, measured throughput, and peak memory
are the reported resource comparisons; measuring each implementation’s actual FLOPs is a
further systems experiment.
Fused Triton recurrence kernel
The forward kernel uses an internal [T, B, H, *] layout (time, batch, head, …) and dispatches
one program per (batch, head_block). The BLOCK_H parameter is autotuned over {1, 2, 4, 8, 16}
because at 𝐻 ≥ 256 per-program-per-head launch overhead dominates. The state tile lives in
registers and shared memory for the duration of the 𝑇-step loop. The following pieces are fused
into the same Triton program: tanh/silu activations on input projections, 𝐿2
normalization of
𝑞, 𝑘, the recurrent delta write, and the output gate. Each fusion removes one to two torch.cuda
launches per layer call.
Sparse-checkpoint backward
The forward kernel saves 𝑆 only every 𝐾 = 16 steps. The backward kernel processes one 𝐾-
step segment at a time: it forward-replays the 𝐾 steps to rebuild per-step 𝑆𝑡−1 from the saved
checkpoint, then walks backward to apply the chain rule. The activation memory used by the
kernel is 𝑇
𝐾 + 1 checkpoint slots instead of 𝑇. At 𝐾 = 16 this is approximately a 16 × shrink,
at the cost of a single extra forward pass per segment.

Implementation platform
The recurrence is implemented in Triton [24]. The paired production runs, throughput
measurements, and expressivity smokes use NVIDIA CUDA. Porting the pair to ROCm would
add a direct test of correctness and performance on that backend.
Distributed training
The 1.3 B-class result reported here was produced on a single eight-GPU workstation, with
no cluster and no sequence parallelism — both 150 B-token arms of Section 5 ran the same
local DiLoCo recipe on that one machine: eight independent islands (one per GPU), schedule-
free AdamW [25] inside each island, and plain model-weight averaging across islands every 𝜏 =
250 local steps (outer learning rate 1.0, momentum 0 — the conservative plain-average form of
DiLoCo [26]). Scaling the same recipe past one machine pairs schedule-free AdamW per island
with hierarchical local-SGD averaging: each island is one node of 8 GPUs with intra-island
DDP, and inter-island synchronization averages model weights on the same 𝜏 = 250 cadence.
The structural point holds either way: because the Emender distributes work across programs,
the 1.3 B implementation uses ordinary head and batch parallelism while preserving each head’s
time loop.
ParaRNN [8] offers a different systems route, using an iterative solver to parallelize nonlinear
recurrence along time. The present implementation instead retains one serial pass per head and
obtains its parallelism across heads and batch elements.

Losses stay close to the marginal-optimal reference, with a sliver below it: selected 1× cross-

Delayed learning and the composition frontier
A short run can miss learning altogether. In the instrumented one-step E97 run, validation
accuracy stays near zero for roughly 20,000 updates (2.93% at update 20,000), then follows
a clean S-curve to 97.85% at 57,000 updates. This silent-then-ignite signature explains why a
shallow training horizon can read as failure. It describes the learning curve, not its mechanism.
Replaying the earlier stopping rule would have ended this successful run at update 10,000.
The growth curriculum therefore uses an open horizon, advances only at 90% joint validation
accuracy, and stops for registered stagnation rather than a fixed training budget. Its 100,000-
update stage-local floor is calibrated against the successful one-step replay, not a guarantee of

Interpreting the current-pair evidence
The invertible-map results leave the nonlinear-state efficiency question open: neither class
learns robust deep composition in the tested regimes. GDN2′s 𝑆5 result demonstrates a useful
learned capability on a task with an exact linear-state representation. Together with comparable
language-modeling loss, these findings motivate controlled tests of which computations benefit
from nonlinearity in the temporal state path, and under what training and resource conditions.

The finite-state tracker
At fixed width and precision the Emender is a finite-state machine, and the 𝑆5 word problem it
is tested on is a concrete, fully specified finite-state target.
• Finite-state ceiling at fixed precision. At fixed width and precision, every
online recognizer of this kind has only finitely many distinct states
(S5Witness.fixed_precision_state_space_finite). This gives a finite online state space.
• 𝑆5 word problem. The target is pinned down exactly in Lean. The group 𝑆5 has 120
elements (S5Witness.s5_state_count) and is non-solvable (S5Witness.s5_not_solvable);
the prefix-product tracker that reads a word of transpositions and reports the running
product is a 120-state recognizer (S5Tracker.recognizer_state_count) whose state
composes correctly as tokens are appended (S5Tracker.run_append). A bridge lemma
confirms the Lean tracker agrees with the Python evaluation harness on every input
(S5Tracker.pythonRun_eq_tracker_tuple). The four adjacent transpositions generate all of
𝑆5: the tracker’s run map is surjective (S5Inseparability.run_surjective, via Mathlib’s
Equiv.Perm.mclosure_swap_castSucc_succ).
• Capacity lower bound (recognizer floor). Any finite-state recognizer with a
state decoder that reproduces the tracker on every input word needs
at least 120 states (S5Inseparability.capacity_lower_bound_120); equivalently,
no recognizer with fewer than 120 states can realize it under any
decoder (S5Inseparability.small_recognizer_cannot_realize_s5). The bound has
a distinguishing-pair form: any recognizer with too few states admits
two words it cannot tell apart that the tracker does distinguish
(S5Inseparability.exists_distinguishing_word_pair). This is the existential form of the
23
𝑆5-coset inseparability target: it holds for any finite recognizer family, with no architectural
assumptions.
• Lookup-table realization. The tracker is small enough to write down as a table: it uses
exactly 120 × 4 = 480 state/input keys (S5NDMRealization.s5_transition_key_count),
and any finite recognizer admits such an exact lookup-table realization
(S5NDMRealization.exactTransitionMemory_run).

Its state includes the previous iterate and the momentum schedule or clock. A surrogate study
could compare accuracy and latency while the active support changes repeatedly. After support
and signs stabilize, soft-thresholding is affine on the visited region, providing a useful second
regime for the comparison.
Conversation and perception
An ongoing conversation can revise a referent, correct an earlier fact, or change a goal. A
stream of observations can similarly revise a motion estimate. These settings suggest learning an
internal state whose update incorporates each new input into the current interpretation. Textual
scratchpads expose intermediate computation in generated form [1], [2]. Nonlinear carried
memory offers a complementary place for that computation between observations and outputs.
A useful study would vary the frequency of corrections and measure whether later responses
use the revised information, alongside state size, generated-token budget, and response latency.
Driven reservoirs
A standard echo-state network [35] uses
ℎ𝑡+1 = tanh(𝑊ℎ𝑡 + 𝑈𝑢𝑡 + 𝑏).
27
With recurrent parameters fixed, E97 also defines a driven nonlinear dynamical system, with
state mixing determined by its input keys and gates. Training such a model on long-horizon
reservoir trajectories would test how well it retains consequential nonlinear history. Varying
contraction and the rate of forgetting the initial condition would connect the comparison to the
echo-state property.
Biological dynamics
Genomic function depends on nonlinear interactions among sequence features, regulatory
signals, and cellular state. Enformer provides one example of using a nonlinear sequence model
to integrate distal regulatory information for cell-type-specific predictions [36]. Pangenomic
datasets run to terabases per study [37], [38], [39], motivating efficient nonlinear recurrence
for long, structured inputs. A future study could ask whether recurrent memory can integrate
sequence features with changing regulatory signals and cellular context, evaluated through held-
out expression or perturbation-response prediction.
Population dynamics
May’s logistic population model [40] is
𝑛𝑡+1 = 𝑟𝑛𝑡(1−𝑛𝑡).
The normalized population 𝑛𝑡 is the state and 𝑟 is a fixed parameter. An environmentally driven
extension can use 𝑟𝑡 as an input. Comparing learned trajectories across contracting, periodic,
and chaotic regimes would test how error growth and history retention shape recurrent-model
performance. The evaluation horizon and error metric should reflect each regime’s predictability.
These tasks put the computational idea to work: learn a state update whose output remains
consequential over many iterations. Width-axis multi-programming offers a practical way to run
many such learned programs concurrently. Task-specific comparisons across horizon, precision,
state size, and latency would establish where that design is useful.
9 Related Work
Intermediate computation in language models
Scratchpad training [1] and chain-of-thought prompting [2] use generated intermediate steps
to improve multi-step computation and reasoning. The generated sequence carries the working
calculation forward through successive decoding steps. Emender studies ongoing computation
in a fixed-size recurrent state, updated as each input arrives. The two forms of computation
can work together: generated intermediates provide an explicit working sequence, while
nonlinear state updates carry a revisable internal computation through the input stream. This
organization motivates tests on iterated maps and feedback tasks with a per-step time budget.
Ancestry: the fast-weight line on delta correction
The Emender update belongs to a long line that treats memory as a structure updated by
prediction error. The earliest formulation is Widrow and Hoff’s least-mean-square rule [41],
which writes the error between target and current output back into the weight vector of an
adaptive linear element. Schmidhuber recast the same idea in a recurrent setting under the name
fast-weight programmers [42]: a slow controller emits keys and values that update a fast-weight
matrix online, with the update being a correction against what the matrix currently predicts
28
at the addressed slot. Schlag, Irie, and Schmidhuber made the bridge to modern attention
explicit [43], showing that linear-transformer kernels with cumulative outer-product updates
are fast-weight programmers with a raw additive write, and proposing the delta-rule write as
a stability and capacity fix. DeltaNet [14] carried the delta rule into a parallelizable linear-
recurrent language model, demonstrating the rule at billion-parameter scale in the linear-state
regime. Emender combines delta correction with a nonlinear matrix-state update and width-
axis multi-programming. Its saturating update also motivates the conditional latching analysis
in Section 7.
Linear-state recurrent language models
The dominant comparison cohort is the family of linear-state billion-parameter recurrent LMs
surveyed in Section 2: Mamba [3] and Mamba2 [4] (selective SSMs); RetNet [44] (decayed linear
attention); GLA [13] (gated linear attention); DeltaNet [14] (delta rule, linear in 𝑆); Gated
DeltaNet [5] (gated delta rule); RWKV-4/5/6/7 [45], [46] (linear-state WKV / generalized
delta rule with linear state); HGRN2 [47] (gated linear RNN with state expansion); MinGRU/
MinLSTM [15] (input-only gates, linear scan); mLSTM/xLSTM-7B [48] (covariance update);
Griffin/RecurrentGemma [16] (RG-LRU, often hybridized with local attention). Circuit-
containment results for restricted SSM families require their stated transition and arithmetic
assumptions [17]. The current empirical comparison uses GDN2. Its long-horizon 𝑆5 result in
Section 6 demonstrates strong learning of permutation composition, a task with an exact linear-
state representation.
In the broader SSM/sequence-model lineage, S5 [49] introduces simplified state-space layers with
a multi-input multi-output linear state-space recurrence. It is distinct from the permutation
group 𝑆5 used as a probe here.
A newer linear-state result, Gated DeltaNet-2 [6], decouples channel-wise erase and write gates
and is reported by its authors to outperform GDN. It extends retrieval and state-tracking
behavior inside the linear-state envelope, and it is the linear-recurrent baseline of this paper’s
1.3 B pairing: the GDN2 arm of Section 5 is the official-style Gated DeltaNet-2 mixer (external
source commit 95709fc) with the same SwiGLU MLP as E97, selected by the same CMA-ES
protocol. The E97 split gates of Section 3 are the Emender’s corresponding edit — key-axis
erase/read plus value-axis write — inside a nonlinear state map, so the two architectures are
adjacent by design (Section 7). Its decoupled gates are a natural next ablation for the multi-
programmed substrate, as a bounded edit to the per-step update body.
Pure-nonlinear-recurrent peers and adjacent nonlinear-state work
M²RNN [7] (Mishra, Tan, Stoica, Gonzalez, Dao 2026) introduces nonlinear matrix-state
recurrence with a raw-write update 𝑍 = tanh(𝐻𝑊 + 𝑘𝑣𝑇
). It shares the central systems premise
of this work — that a nonlinear recurrence is serial in time and must take its parallelism from
the batch and head axes — and demonstrates that the update trains at 410 M dense and 7 B
MoE scale on Nemotron-CC-v2. Its headline demonstrations use hybrid stacks that interleave
attention and nonlinear recurrence. The current study instead evaluates the pure recurrent E97
mixer against a matched GDN2 control. This connects the present work to other nonlinear
matrix-state designs.
xLSTM-1.3B [20] is a 7:1 mixture of mLSTM (linear) and sLSTM (nonlinear) blocks; with
87.5% of its blocks linear-state, it sits closer to the linear-state class than to the pure-nonlinear-
29
recurrent one. It is the closest scale band among prior nonlinear-recurrent results, included here
as a peer with a small nonlinear-block share. The xLSTM-7B follow-up [48] uses only mLSTM
(linear) blocks, further from the pure-nonlinear-recurrent class still.
Titans [21] uses an MLP memory with online gradient updates and is qualitatively nonlinear-
state, but it interleaves attention layers and has not been evaluated as a pure recurrent model at
Pile-class scale. Zeroth-order LSTM scaling [50] demonstrates 1 B-scale LSTM training under
a non-gradient regime, outside the standard-gradient comparison drawn here.
Classical LSTM and GRU provide the foundational gated nonlinear recurrences [12]. E97
explores a matrix-memory implementation organized around many independently addressed
recurrent heads.
10 Open questions
Learning and evaluation
The current pair supplies one language-model training seed; the matched-rate invertible-map
study uses three fine-tuning seeds per arm. The current-pair 𝑆5 study has one seed. Common
fixed-step budgets and additional seeds would measure stability across optimization regimes.
A feasible matched 𝑆5 curriculum would test the contribution of the length-512 memory limit
encountered by GDN2.
Held-out tokenizer-invariant bpb and downstream evaluation are the next language-model
measurements. Recovering the original CMA winner logs would also supply generation-zero
fitness, spread, and total search effort for the carried-in configurations (U3.1). These records
would support a matched-total-budget search comparison.
Recurrent realization
O1: realizing the group tracker. Find an E97 update configuration, initial state, and decoder
that carry the running 𝑆5 product, then prove the trajectory property over all words.
G3: realizing group actions in the constrained affine channel. The permutation-matrix
construction establishes 𝑆5 tracking in the general linear-state class. Find a representation
satisfying GDN2′s split-gated decay-minus-rank-one transition and production gate and decay
ranges, or characterize the algebraic obstruction. The current Lean identities allow an arbitrary
decay matrix; the production restrictions define this more specific realization problem. The
observed learning results establish GDN2′s empirical capability under the reported protocol;
G3 asks for an exact all-words construction.
G2: state-dependent parameter schedules. Extend the formal update class to gates that read
carried state, and characterize its composition and cost.
G1: the cost of generating token-dependent actions. Building on the realization question,
determine the resources required by the network that supplies the per-token parameters. The
four-symbol group schedule provides a concrete case for this analysis.
G1–G3 are recorded in formal/lean/GAPS-D2.md. Persistence also needs a production-range
result: the stated hold theorem assumes 𝜆 ≥ 1, while production decay lies below one. A layer-
level and finite-precision analysis would connect that result to practical memory retention.
30
Scale and implementation
A matched 3–7 B pair would test how training loss, memory use, and computational
behavior change with scale. Current-scale internal ablations would separate the effects of state
nonlinearity, gates, and geometry. Direct E97 occupancy profiling, actual FLOP accounting,
and paired ROCm measurements would extend the systems evidence.
The application tests in Section 8 call for long-horizon error and latency measurements in their
stated regimes; feedback applications additionally call for stability testing. The bibliography’s
flagged publication metadata should be resolved during submission preparation.
11 Conclusion
Emender makes recurrent memory a site of ongoing computation. Each input corrects the
stored state and transforms what the next step receives. Running many small heads in parallel
makes this sequential computation practical: E97 trains through 150.8 B Pile tokens at 1.3 B
parameters and reaches comparable training loss to GDN2. A Frontier continuation extends the
same architecture to 513.0 B accepted tokens, with the recorded rank-0 loss falling to 2.2798
nats/token.
The invertible nonlinear-map study finds no robust trained-depth separation at matched 1e-3
across three seeds. E97 has lower extrapolation cross-entropy in every seed at 4× and 8×
depth, while under flat full-depth training both classes remain near marginal-like loss behavior
with limited predictive signal; the open-horizon curriculum then resolves a learned composition
frontier on the four-driver stage — one sequential map application for E97, three (two seeds)
and two (one seed) for GDN2, with the four-application position unsolved in every run. GDN2
leads the long-horizon 𝑆5 comparison, a meaningful success on a task with an exact linear-
state representation. These task-dependent observations leave learned nonlinear-composition
efficiency open. The formal state-channel results make the architectural distinction precise:
repeated nonlinear composition in E97, and an affine GDN fold under a fixed, state-independent
schedule.
These findings support studying nonlinear memory as a computational resource. The next step
is to test that resource across training budgets, scales, and tasks in which an evolving state
must keep being transformed: feedback, iterative optimization, and driven dynamics.

12 Next tests for the current pair
The X-series motivates controlled tests rather than a predicted architecture ordering. First, cross
learning rate with a common stopping rule and matched realized budgets, retaining all seeds and
both selected and terminal checkpoints. This would test whether the observed regime difference
survives the protocol confound. Second, track local arithmetic and post-seven-driver full-state
accuracy throughout training across the difficulty ladder. Joint improvement beyond the suffix
reference and across held-out depths would support learned composition; lower aggregate loss
alone would still indicate only predictive signal. Repeat the per-seed extrapolation cross-entropy

once the arithmetic diagnostic and depth test succeed under matched conditions. Third, repeat
𝑆5 with a mutually feasible curriculum and additional seeds, and evaluate the two immutable
language-model checkpoints on held-out text and downstream tasks.
13 Future Work
A matched 3–7 B E97/GDN2 study would test training viability, memory cost, and
computational behavior across scale. The feedback, optimization, and driven-dynamics tasks in
Section 8 would test utility beyond language. Mathematical targets are a recurrent tanh tracker
(O1), constrained affine/reflection realizability (G3), production-range persistence, and finite-
precision robustness.

\begin{abstract}
Fast interaction and feedback require models to update what they know as new inputs arrive. Emender performs this computation in bounded recurrent memory: each input corrects the memory's prediction and applies a nonlinear transformation to the state carried forward. Many small memory heads execute in parallel, making the sequential update practical to train. At 1.3 billion parameters, E97 trains through 150.8 billion Pile tokens on one eight-GPU workstation, reaching training loss comparable to a closely parameter-matched Gated DeltaNet-2 control. An extended Frontier run reaches 513.0 billion cumulative tokens, with its final segment trained on CommaPile. Fine-tuning the workstation pair on an iterated nonlinear map gives E97 99.96\% accuracy versus GDN2's 76.09\% at the trained length, and 76.07\% versus 53.36\% at eight times that length. GDN2 leads on long-horizon ${S }_{5}$ permutation composition, a task that admits an exact linear-state representation. Its strong learning on this task demonstrates the utility of linear-state recurrence, alongside E97's advantage on repeated nonlinear transformation. Formal results characterize E97's repeated nonlinear state transformation and GDN's affine state composition under a fixed, state-independent parameter schedule. Together, these findings establish a practical route to training nonlinear recurrence and support further study of computation through memory in feedback, optimization, and driven dynamics.
\end{abstract}

\section{Introduction}\label{sec:intro}


Keeping balance, following a moving object, and adjusting a movement require continual revision of an internal estimate as observations arrive. Conversation and perception likewise require a model to update what it understands while the interaction unfolds. Fast feedback puts this computation under a per-input time budget. Textual scratchpads and chains of thought let language models perform visible intermediate computations through generated tokens \citep{nye2021scratchpads} \citep{wei2022chain}. Each additional token adds a decoding step and extends the working sequence. A complementary question is how much of this ongoing computation can happen directly in carried memory as inputs arrive. Efficient nonlinear recurrence offers such a path: at inference, a fixed-width, fixed-depth model transforms fixed-size state with bounded work per update.

A sequence can require more than a record of what arrived. Its elements may be instructions that change a running calculation, measurements that alter a feedback response, or observations that revise an earlier association. In each case the current state is part of the next computation. A recurrent model reads an input, updates its internal state, and carries that state into the following step. The question is what computation the update performs, and how to train it efficiently at language-model scale.

Emender uses a nonlinear matrix memory. At each step, a head reads its current prediction at an input-supplied key, writes a correction toward the supplied value, and passes the updated state through $\operatorname{tanh}$. The write uses what the memory already contains; the nonlinearity transforms what the next step will receive. Processing a long sequence therefore executes a long composition of nonlinear state updates.

An \emph{emender} is one recurrent layer, and \emph{Emender} is the family of networks formed by stacking these layers. The current instance, \emph{E97}, uses separate key-axis erase/read and value-axis write gates. Each head has a small matrix state, while projections, gates, and a SwiGLU MLP connect the memories to the rest of the network (Section~\ref{sec:arch}). The memory is revisable: later inputs can correct earlier associations.

This choice creates a systems problem. Modern linear-state recurrences use the composability of affine state updates to parallelize training along time \citep{mamba2024} \citep{mamba2_2024} \citep{gated_deltanet2024} \citep{gated_deltanet2_2026}. E97 keeps each head's nonlinear time loop serial and obtains parallelism across heads and batch elements. We call this \emph{width-axis multi-programming}: many small memory programs run side by side, with each state tile kept on the accelerator (Section~\ref{sec:systems}). This complements hybrid recurrent-attention stacks and iterative methods for parallelizing nonlinear recurrence \citep{m2rnn2026} \citep{pararnn2025}.

The first empirical question is whether this route is practical. E97 trains through 150.8 billion tokens on The Pile \citep{thepile2020} on one eight-GPU workstation. Its GDN2 control is within 0.01\% of its parameter count. Both arms include the same SwiGLU MLP design; we use \emph{GDN2} in the prose for the experimental arm recorded as \protect\path|GDN2-MLP|. The pair uses the same tokenizer, 2,048-token chunks, optimizer, and local DiLoCo recipe; CMA-ES selects each model's geometry and learning rate. Their training losses converge to the same narrow band at matched tokens (Section~\ref{sec:lm}). The actual-geometry systems preflight also measures comparable throughput and lower peak memory use for E97. The same E97-MLP architecture was then continued on Frontier from the 150.79-billion-token checkpoint to 513.0 billion cumulative accepted tokens, and continued training reduced the recorded rank-0 loss from 2.4365 to 2.2798 nats/token, with the final segment on CommaPile mainmix (Section~\ref{sec:lm}).

The second question is what these trained models can learn to compute. An iterated nonlinear map repeatedly transforms a running value, directly testing the computational pattern that motivates E97. After fine-tuning on a modular-quadratic recurrence, E97 reaches 99.96\% versus 76.09\% accuracy at the trained length and 76.07\% versus 53.36\% at eight times that length. Its higher accuracy and greater length robustness support nonlinear transformation in the carried-state path as a useful inductive bias. The ${S }_{5}$ group-state task asks the models to compose permutation actions. This computation admits an exact linear-state representation: each token multiplies a carried permutation matrix by its generator matrix. GDN2 learns this task more effectively in the long-horizon comparison, demonstrating a useful learned capability on a computation compatible with linear-state recurrence. Section~\ref{sec:expressivity} gives the protocols, learning trajectories, and length-dependent results for both tasks.

The formal analysis describes the state computations behind this comparison. Lean 4 verifies E97's time-ordered nonlinear composition and the affine GDN state fold under a fixed, state-independent parameter schedule. It also relates their split-gated cores and characterizes the affine group actions of an exact ${S }_{5}$ tracker under a token-only schedule and a decoder that separates reachable states (Section~\ref{sec:formal}). An exact construction within GDN2's production gate and decay ranges is the more specific realization question G3. These statements make the mechanism precise and supply concrete targets for further experiments and proofs.

The resulting program joins a practical architecture to a testable computational hypothesis. Feedback systems, iterative optimization, and driven dynamics provide further settings in which a running state must be transformed repeatedly (Section~\ref{sec:applications}). We proceed from the update and its implementation to the matched language-model comparison and computational probes, then develop the formal results and next questions.


\section{Background}\label{sec:background}


The central distinction is where nonlinear computation occurs. Mamba \citep{mamba2024} and Gated DeltaNet \citep{gated_deltanet2024} use nonlinear input processing and gates, and their full networks are nonlinear functions of the sequence. Once a recurrent layer's input-derived transition parameters are fixed, its carried-state update is affine in the previous state. E97 instead transforms the carried state nonlinearly at each step. These choices organize computation across time differently and call for different execution strategies.

A standard Transformer \citep{vaswani2017attention} processes a sequence through a fixed stack of attention and nonlinear feed-forward layers. Its layer count is independent of input sequence length. Autoregressive generation reuses that stack in successive decoding steps; generated intermediate tokens extend the serial computation. A nonlinear recurrence adds another nonlinear transformation of its carried state at every input step. This motivates asking which computations a model learns to place in the state update, in its layers, or in a generated working sequence.

\subsection*{Linear-state and nonlinear-state recurrence}


The recurrent language model lineage runs from Elman networks \citep{elman1990} and the LSTM \citep{lstm1997} through the modern linear-recurrent variants: state-space models such as Mamba and Mamba2 \citep{mamba2024} \citep{mamba2_2024}, gated linear attention \citep{gla2023}, and the delta rule \citep{deltanet2024}. Many modern designs favor time-axis parallelism via linear-state updates, whereas nonlinear-in-time recurrence generally uses a different execution strategy. Gated DeltaNet-2 \citep{gated_deltanet2_2026}, the split erase/write-gate extension of Gated DeltaNet \citep{gated_deltanet2024}, supplies the linear-state mixer in the current GDN2 control (Section~\ref{sec:lm}).

A single explicit criterion classifies recurrent architectures. A recurrent layer is \emph{linear-state} if its update can be written ${S }_{t } =  {A }_{t } {S }_{t - 1} +  {b }_{t }$ with ${A }_{t }$ and ${b }_{t }$ determined by input-derived features, independently of that layer's previous carried state. Conditioning on these parameters makes the update affine in ${S }_{t - 1}$. Here the state is expressed in vector coordinates; a matrix state may be vectorized for this criterion. If the previous state ${S }_{t - 1}$ appears nonlinearly in its own update equation, the layer is \emph{nonlinear-state}. The distinction is structural and applies across choices of nonlinear activation.

Linear-state designs admit a chunkwise or scan-based parallel implementation along the time axis because composing ${S }_{T } =  {A }_{T } {S }_{T - 1} +  {b }_{T } =  \ldots $ unfolds into a product of inputs only. This is the reason linear-state recurrence dominates the billion-parameter landscape. Mamba, Mamba2 (SSD), RetNet, GLA, DeltaNet, Gated DeltaNet, RWKV-4/5/6/7, HGRN2, mLSTM, MinGRU/MinLSTM \citep{mingru_2024} and Griffin's RG-LRU \citep{griffin2024} are all linear-state by this criterion. At fixed precision and width, both state regimes are finite-state recognizers. Circuit-complexity results study restricted state-space models under specified arithmetic and transition assumptions \citep{merrill2024transformers}. For transformers, log-precision and uniform-circuit characterizations are given by \citep{merrill_sabharwal2023log_precision} and \citep{chiang2025uniform_tc0}. These results motivate explicit computational tasks alongside language-modeling loss.

Nonlinear-state recurrences include the classical LSTM and GRU; the sLSTM block of xLSTM \citep{xlstm2024} (memory-mixing through the hidden state inside exponential gates); M\textsuperscript{2}RNN \citep{m2rnn2026} (matrix state inside $\operatorname{tanh}$ with raw-write injection); Titans \citep{titans2025} (MLP memory with online gradient updates); and the architecture introduced here. The Siegelmann--Sontag result \citep{siegelmann1995} concerns nonlinear recurrent nets under its stated precision and resource assumptions. Barrington's theorem identifies the non-solvable ${S }_{5}$ word problem as an NC\textsuperscript{1}-complete witness.


\subsection*{Matrix state}


Matrix state $S  \in  {\mathbb{R} }^{N  \times  V }$ is shared by several recurrent architectures. Linear-state designs (mLSTM, RWKV-5/6, DeltaNet) already use matrix or expanded states; RetNet's accumulation ${S }_{t } =  \gamma  {S }_{t - 1} +  {k }_{t } {v }_{t }^{T }$ is matrix-valued. The point of matrix state is that an outer-product update ${S }_{t } =  \ldots  +  {k }_{t } {\delta }_{t }^{T }$ provides $O ( N  V ) $ scalars of dynamic state at $O ( N  V ) $ computational cost per token, with content-addressable retrieval via ${S }^{T } q $. Matrix state is common to the post-Mamba landscape (Mamba2 with \protect\path|d_state|, GLA, DeltaNet, RWKV-5/6/7, mLSTM, M\textsuperscript{2}RNN). E97 and GDN2 both use this structure.


\subsection*{The ${S }_{5}$ state-tracking probe}


The symmetric group ${S }_{5}$ is the group of permutations of five items; it has $120$ elements and is the smallest non-solvable symmetric group. Its \emph{word problem} is the following task: the model reads a sequence of permutations --- here, adjacent transpositions, the swaps of two neighboring items --- one at a time, and after each one must report the running composition of everything read so far, its \emph{prefix product}. By Barrington's theorem \citep{barrington1986} this task is complete for the complexity class NC\textsuperscript{1} when exact recognition is required over all words. The experiments measure prefix-product accuracy at specified lengths. The solvable-group control ${S }_{3}$ (permutations of three items, 6 elements) is included to factor out the part of difficulty that comes from prefix tracking \emph{per se} rather than from non-solvability.

Permutation composition has a direct linear-state realization. Choose $5 \times  5$ permutation matrices ${P }_{s }$ with ${P }_{s  r } =  {P }_{s } {P }_{r }$ and carry the running matrix ${R }_{t }$:
\[\begin{aligned}{R }_{0} =  {I }_{5},  \quad  {R }_{t } =  {R }_{t - 1} {P }_{{a }_{t }}, \end{aligned}\]
 where ${a }_{t }$ is the incoming adjacent transposition. Then ${R }_{t } =  {P }_{{a }_{1} \ldots  {a }_{t }}$, which identifies the full group element. For each token, right multiplication by its fixed generator matrix is linear in the carried matrix, and remains linear after vectorization. Thus ${S }_{5}$ tracking belongs to the general linear-state class despite the group's noncommutativity and the word problem's NC\textsuperscript{1} completeness. This representation explains why learning the task is a meaningful success for a linear-state architecture. Its realization within a particular gated transition family is a separate, more specific question (Section~\ref{sec:formal}, G3 in Section~\ref{sec:limitations}).


\subsection*{A dynamics taxonomy of head-types: eigenvalue placement $\times $ saturation}


The linear/nonlinear hinge above, and the choice of where a head's state may decay, reflect, or oscillate, are two independent axes of a single design grid. The \emph{dynamics} of a head's per-token state map locate it in a two-axis grid:




\begin{enumerate}[label=\arabic*.]
\item \emph{Eigenvalue placement in the unit disk.} Where the along-key eigenvalue of the per-token state transition sits in the complex unit disk. A real-positive eigenvalue is a \emph{decay} --- the stored value fades toward zero along the key. A real-negative eigenvalue is a \emph{reflection} that flips sign each step (\protect\path|reflect|); reaching it is the lever that lets a recurrence track non-solvable group structure such as ${S }_{5}$ in the restricted transition analyses motivating this grid. A complex-conjugate pair is a \emph{rotation} (\protect\path|rot|) that oscillates the stored value. Real-positive and real-negative are the two ends of the \emph{real diameter}; complex placement walks off that diameter into the rest of the disk.
\item \emph{State map: linear or saturated.} Whether the state update is left linear or passed through a bounded saturating nonlinearity (canonically $\text{hardtanh}$; the \protect\path|-nonlin| axis; the Emender uses the smooth variant $\operatorname{tanh}$). Saturation latches a driven slot and makes the head bounded; finite precision then gives a finite state space.
\end{enumerate}
The grid these two axes span names every Emender head-type (Figure~\ref{fig_taxonomy}). Real $\times $ linear at the positive end is \protect\path|decay|, which is vanilla Gated DeltaNet; at the negative end it is \protect\path|reflect|, Gated DeltaNet permitted a negative eigenvalue. Real $\times $ saturated is \protect\path|nonlin| --- the saturated delta-correcting head, historically tagged E97, whose split-gated instance is the 1.3 B model of this paper with split erase/read and write gates. Complex $\times $ linear is \protect\path|rot|, the complex-eigenvalue oscillator head. Complex $\times $ saturated is \protect\path|rot-nonlin|, a nonlinear oscillator left to future work, included as the combination of the two axes. E97 identifies the trained instance; the architecture vocabulary is this grid.

The adjacent split-gated cores locate the linear-recurrent baseline in this grid.


 \emph{Shared split-gated cores, with different decay placement.} Gated DeltaNet-2 and E97 have adjacent split erase/write cores. E97 uses $\lambda  S  -  {k ( e  \odot  k ) }^{T } S  +  {k ( w  \odot  v ) }^{T }$, whereas GDN-2 uses $( I  -  {k ( e  \odot  k ) }^{T })  D  S  +  {k ( w  \odot  v ) }^{T }$. The exact Lean identity applies E97's unit-decay linear core to the \emph{pre-decayed} state $D  S $; with identity decay the cores coincide (Section~\ref{sec:formal}). The grid organizes these heads by their state dynamics.

\section{Computing with a nonlinear memory}\label{sec:arch}



\subsection*{Per-head update}


Section~\ref{sec:intro} named the emender layer by what it does --- read what the memory predicts at the addressed slot, compute the prediction error, and write the correction --- and named E97 as the 1.3 B instance carried through the paper. This section makes the layer concrete: the per-step computation, the choices that fix it, and the shape numbers that make E97 one specific member of the family.

An emender layer runs $H $ independent heads side by side. Each head $h $ owns its own matrix-state memory ${S }_{h } \in  {\mathbb{R} }^{N  \times  V }$ --- the matrix state of Section~\ref{sec:background}, here addressed by an $N $-dimensional key and holding a $V $-dimensional value at each addressed slot. (Section~\ref{sec:formal}'s resource theorems use a single symbol $d $ for the common matrix dimension; in E97, $d  =  N  =  V  =  32$, so each head's memory is a $32 \times  32$ tile.) At each token, the layer's input projections supply, per head, a key ${k }_{h }$ and query ${q }_{h }$ in ${\mathbb{R} }^{N }$ that name the slots to write and read, a value ${v }_{h } \in  {\mathbb{R} }^{V }$ to store, a scalar decay ${d }_{h } \in  ( 0, 1) $ that fades the old state, and an output gate ${g }_{h } \in  {\mathbb{R} }^{V }$. E97 controls its write with two input-dependent gates, split along the two axes of the matrix state: a key-axis \emph{erase/read} gate ${e }_{h } \in  {( 0, 1) }^{N }$ that scales the address under which the old content is retrieved, and a value-axis \emph{write} gate ${w }_{h } \in  {( 0, 1) }^{V }$ that scales what is written (the GDN-2-inspired half of the design; Section~\ref{sec:formal}'s split-gated theorem set pins the relationship). The display below is one head's full step in execution order: normalize the two addresses, gate the read address and the write value, read the memory, form the retrieval error, update the bounded state, and gate the read output. The formal core identities in Section~\ref{sec:formal} use abstract real-valued key/gate/state domains. The production ranges are specified above. This per-head step is the core, bound to the full stack by limitation G2 (Section~\ref{sec:limitations}).


\[\begin{aligned}{k }_{h } &\leftarrow  \frac{\text{silu}( {k }_{h }) }{{\Vert \text{silu}( {k }_{h }) \Vert }_{2}} \quad  ( {\text{L}}^{2} \text{-normalized key}) \\ {q }_{h } &\leftarrow  \frac{\text{silu}( {q }_{h }) }{{\Vert \text{silu}( {q }_{h }) \Vert }_{2}} \quad  ( {\text{L}}^{2} \text{-normalized query}) \\ {e }_{h } &=  \sigma ( {E }_{h } {x }_{t })  \quad  ( \text{key-axis erase/read gate}) \\ {w }_{h } &=  \sigma ( {W }_{h } {x }_{t })  \quad  ( \text{value-axis write gate}) \\ {r }_{h } &=  {S }_{h }^{T } ( {e }_{h } \odot  {k }_{h })  \quad  ( \text{gated read at the key}) \\ {\delta }_{h } &=  {w }_{h } \odot  {v }_{h } -  {r }_{h } \\ {{S }'_{h }} &=  \operatorname{tanh}( {d }_{h } {S }_{h } +  {k }_{h } {\delta }_{h }^{T })  \\ {y }_{h } &=  \text{silu}( {g }_{h })  \odot  {( {{S }'_{h }}) }^{T } {q }_{h }\end{aligned}\]


The displayed normalization is idealized for nonzero addresses; production regularizes with \protect\path|norm+1e-6| (shared fused normalization: \protect\path|elman/models/e88_fused.py:239-242|).

Here $\text{silu}$ is the smooth pointwise activation $x  \odot  \sigma ( x ) $, with $\sigma $ the logistic sigmoid, ${v }_{h }$ is the post-activation value input (the activated value supplied to the cell, so the write gate scales an already-activated write), and ${\Vert \cdot \Vert }_{2}$ is the Euclidean norm. The first two lines put the key and query on the unit sphere so the addressing is bounded; the middle lines make the write a correction against the content already read --- under a gated address and at a gated magnitude; and the final line gates only the read output. The state stays inside $\operatorname{tanh}$, so the update is nonlinear-state for every gate setting. The formal specialization and adjacent-core identities are given in Section~\ref{sec:formal}. This is the per-head primitive. Algorithm 1 spells out the same read-before-write order; its inputs are the projected quantities described above, and its output uses the returned state.

\emph{Algorithm 1 --- E97 per-head step.}
\begin{verbatim}
Input: S, projected k, q, activated v, d, e, w, g
1. k <- silu(k) / norm2(silu(k))
2. q <- silu(q) / norm2(silu(q))
3. r <- transpose(S) (e hadamard k)
4. delta <- (w hadamard v) - r
5. S_next <- tanh(d S + outer(k, delta))
6. y <- silu(g) hadamard (transpose(S_next) q)
Return: S_next, y
\end{verbatim}


E97 repeats the same per-head equation across a residual stack.

E97 fixes these family choices to one billion-parameter instance: model width 1792, depth 11, $H  =  216$ heads per layer, $N  =  V  =  32$, expansion 1.0, a bias-free SwiGLU MLP of hidden width 4,032 after each mixer (mlp ratio 2.2623), per-rank batch size 4, a recurrence chunk length of 2048 tokens, and 1,286,589,072 parameters in total ($1\{ , \} 048\{ , \} 152\{ , \} 720$ non-MLP plus $238\{ , \} 436\{ , \} 352$ in the eleven MLPs). For E97, at depth 11, $H  =  216$, and batch size 4 the stack runs $11 \times  216 \times  4 =  9\{ , \} 504$ independent recurrent programs per token, each carrying a $32 \times  32$ state tile ($216 \times  ( 32 \times  32) $ recurrent-state scalars per layer). Around the recurrent core the language-model wrapper is conventional --- a pre-norm residual stack with a final normalization and tied input/output embeddings. Heads never share recurrent state; each layer learns its own key, query, value, decay, split-gate, and output-gate projections; and the recurrent state starts at zero when no prior state is carried in.

For the Emender family, four ingredients are load-bearing; E97 uses all four in the instance above.




\begin{enumerate}[label=(\alph*)]
\item \emph{Bounded matrix state via $\operatorname{tanh}$ on $S $.} The state-channel duality (Section~\ref{sec:formal}) distinguishes the executed nonlinear composition from an affine fold. Applying the nonlinearity to the carried state makes an emender layer nonlinear-state.
\item \emph{Delta-correcting write $w  \odot  v  -  {S }^{T } ( e  \odot  k ) $.} The emender layer reads what memory predicts at the gated address $e  \odot  k $, computes the prediction error $\delta $ against the gated write value $w  \odot  v $, and writes the correction. Under unit decay and all-one gates, the pre-$\operatorname{tanh}$ core with orthonormal keys gives exact overwrite at one slot while preserving orthogonal slots (\protect\path|linearDeltaWrite_overwrites_one_preserves_others|); full-state $\operatorname{tanh}$, split gates, and arbitrary keys change that guarantee. The current pair shares delta correction; its distinction is the nonlinear carried-state path, together with the stated decay placement.
\item \emph{Saturation latching of the $\operatorname{tanh}$ bound.} A slot driven near $\pm  1$ resists perturbations under the saturation theorem's hypotheses; sign-preserving hold and counter-delta release have separate decay and write-budget assumptions. These motivate revisable memory and motivate studying persistence in production E97. Section~\ref{sec:formal} (saturation insensitivity, sign-preserving hold, counter-delta release) formalizes all three as slot-wise statements on the full emender-layer update.
\item \emph{Many independent small heads.} E97 at 1.3 B uses $H  =  216$ heads of $32 \times  32$ each ($11 \times  216 \times  4 =  9\{ , \} 504$ independent programs per token at batch size 4). Per-head ${L }^{2}$-normalized $q , k $ give many independent addressing programs across the value heads.
\end{enumerate}

\subsection*{GDN2 state channel}


Algorithm 2 defines the adjacent GDN-2 linear core used by the formal comparison: decay is applied \emph{before} retrieval and correction, and no $\operatorname{tanh}$ is applied to the returned state. Its inputs are an already supplied key, split gates, value, and pre-decay matrix. E97 applies $\operatorname{tanh}$ to its updated state. Both trained models also use nonlinear input processing and the SwiGLU MLP described in Section~\ref{sec:lm}. GDN2 retains its own projection processing. Algorithms 1 and 2 present the abstract core; the released baselines add projection, normalization, gate-domain, and residual machinery whose full-stack binding is carried by limitation G2 (Section~\ref{sec:limitations}).

\emph{Algorithm 2 --- GDN-2 split-gated linear core.}
\begin{verbatim}
Input: S, D, k, e, w, v
1. P <- D S
2. r <- transpose(P) (e hadamard k)
3. delta <- (w hadamard v) - r
4. S_next <- P + outer(k, delta)
Return: S_next
\end{verbatim}



\subsection*{Parameterization choices}


E97 parameterizes the per-head decay ${d }_{h }$ in log space, following Mamba2 \citep{mamba2_2024}: each head learns a scalar ${A }_{\operatorname{log}}$ and a bias ${\delta }_{\text{bias}}$ --- the code names \protect\path|A_log| and \protect\path|dt_bias| --- and forms the decay as $d  =  \operatorname{exp}( - \operatorname{exp}( {A }_{\operatorname{log}})  \cdot  \text{softplus}( \alpha ( x )  +  {\delta }_{\text{bias}}) ) $, where $\alpha ( x ) $ is the input-dependent term and $\sigma $ is again the logistic sigmoid. Both decay parameters are exempt from weight decay, as is standard for such timescale parameters. The recurrence is computed in float32 and cast back to the storage precision, and the $\operatorname{tanh}$ on the state uses the numerically stable form $\operatorname{tanh}( z )  =  2 \sigma ( 2 z )  -  1$ in the fused kernel to avoid overflow at large pre-activations. Three remaining choices are: there is no output normalization inside the recurrent layer --- an ablation removed it for a 0.10-nat gain, and the wrapper's block-level pre-norm plus final norm suffice --- no short convolution on the input. E97 uses the split erase/read and write gates above; its output gate $\text{silu}( g ) $ still acts on the read alone.


\subsection*{The 1.3 B stack}


Ingredient (d) sets the 1.3 B stack's shape --- many small heads --- and the numbers follow from it: each head's $32 \times  32$ tile is small enough to live in registers (Section~\ref{sec:systems}), the head count $H  =  216$ is large enough to give that many independent addressing programs per layer, and eleven such layers --- each followed by its SwiGLU MLP, the channel-mixer that pairs with the token-mixing recurrence --- reach the 1.3 B-class budget the paired comparison fixes. The exact values were selected by the per-architecture search of Section~\ref{sec:lm}. At batch size 4, depth 11 and $H  =  216$ multiply to $11 \times  216 \times  4 =  9\{ , \} 504$ independent recurrent programs per token, each carrying its own $32 \times  32$ state tile. The reference implementation and the fused Triton recurrence kernel that steps these tiles are identified by the source register and release manifests.


\subsection*{The matched architectural contrast}


E97 and GDN2 both use matrix memory, delta correction, split editing gates, and a SwiGLU channel-mixing MLP. The key distinction for the present hypothesis is the operation performed on carried state: E97 applies $\operatorname{tanh}$ after its correction, whereas the GDN2 state update is affine when its input-supplied parameters are fixed. Decay placement also differs, as the core identities above specify. The full networks contain nonlinear projections, gates, and MLPs. The comparison centers on the transformation applied to carried state. The matched-pair probes test what the trained architectures learn under the recorded protocol (Section~\ref{sec:expressivity}); the formal analysis states the narrower update-map facts (Section~\ref{sec:formal}).


\section{Making sequential updates practical}\label{sec:systems}



\subsection*{Multi-programming: the throughput-enabling design choice}


Width-axis multi-programming supplies throughput while each head's time loop remains serial. A linear recurrence earns its throughput on the \emph{time axis}: because ${S }_{t } =  {A }_{t } {S }_{t - 1} +  {b }_{t }$ unfolds into a product that depends on the inputs alone, the step-by-step loop can be re-expressed as a prefix scan or a chunkwise matrix multiplication over the whole sequence at once. E97 executes its nonlinear state update in a serial time loop. \emph{Multi-programming} obtains throughput on the other axis by replicating the recurrent computation across many independent heads --- each with its own small bounded matrix state --- and harvests parallelism across those heads, across state tiles, and across batch elements, while the time loop inside each head still runs one step at a time.

The design choice is a decoupling: it frees throughput from the \emph{shape} of the update. The recurrent body must stay a bounded, register-resident per-step map at a fixed matrix-state signature --- that is what keeps each head cheap. This implementation supports a programmable nonlinear update body. The cost is paid in per-head serial time, most exposed at long sequence lengths where the serial loop is longest; the gain is that a nonlinear recurrence can keep a modern accelerator busy with no time-axis scan at all.
\subsection*{The 1.3 B Emender shape under multi-programming}


A modern GPU exposes many independent streaming multiprocessors, each able to run a small program out of its own registers and shared memory, and multi-programming is built to fill them. E97, the 1.3 B Emender instance, runs 216 such programs per layer per batch element --- one per head --- so at depth 11 and batch size 4 the layer stack issues $11 \times  216 \times  4 =  9\{ , \} 504$ small independent recurrent programs per token, each carrying its own $32 \times  32$ state tile small enough to live in registers. Keeping the accelerator busy therefore uses parallelism across memory programs. The paired throughput and memory measurements below test the practical consequence at the actual E97/GDN2 geometries; direct E97 occupancy profiling remains to be measured.


\subsection*{Measured throughput and memory use}


The throughput measurements and throughput-budget smokes use NVIDIA CUDA.

At the actual 1.3 B pair geometries, the matched-batch preflight on seven RTX 6000 Ada GPUs under DDP measures E97-MLP at 3,211 tokens/s per GPU and GDN2 at 3,290, both at batch 4. The ratio is 0.976: comparable throughput, with GDN2 slightly faster. E97 uses 28,942 MB peak memory per GPU against 35,715 MB for GDN2. E97 therefore fits batch 6 under DDP, reaching 4,470 tokens/s per GPU, where the control cannot fit that batch (\protect\path|experiments/preflight_100b/RESULTS.md|). The lower memory use enables the larger-batch throughput gain.

The preflight uses DDP at the actual pair geometries. The long-run training below uses eight independent local-DiLoCo islands. Parameter count, measured throughput, and peak memory are the reported resource comparisons; measuring each implementation's actual FLOPs is a further systems experiment.


\subsection*{Fused Triton recurrence kernel}


The forward kernel uses an internal \protect\path|[T, B, H, *]| layout (time, batch, head, $\ldots $) and dispatches one program per \protect\path|(batch, head_block)|. The \protect\path|BLOCK_H| parameter is autotuned over $\{ 1,  2,  4,  8,  16\} $ because at $H  \geq  256$ per-program-per-head launch overhead dominates. The state tile lives in registers and shared memory for the duration of the $T $-step loop. The following pieces are fused into the same Triton program: $\operatorname{tanh}$/$\text{silu}$ activations on input projections, ${L }^{2}$ normalization of $q ,  k $, the recurrent delta write, and the output gate. Each fusion removes one to two \protect\path|torch.cuda| launches per layer call.


\subsection*{Sparse-checkpoint backward}


The forward kernel saves $S $ only every $K  =  16$ steps. The backward kernel processes one $K $-step segment at a time: it forward-replays the $K $ steps to rebuild per-step ${S }_{t - 1}$ from the saved checkpoint, then walks backward to apply the chain rule. The activation memory used by the kernel is $\frac{T }{K } +  1$ checkpoint slots instead of $T $. At $K  =  16$ this is approximately a $16 \times $ shrink, at the cost of a single extra forward pass per segment.


\subsection*{Implementation platform}


The recurrence is implemented in Triton \citep{triton2019}. The paired production runs, throughput measurements, and expressivity smokes use NVIDIA CUDA. Porting the pair to ROCm would add a direct test of correctness and performance on that backend.


\subsection*{Distributed training}


The 1.3 B-class result reported here was produced on a single eight-GPU workstation, with no cluster and no sequence parallelism --- both 150 B-token arms of Section~\ref{sec:lm} ran the same \emph{local DiLoCo} recipe on that one machine: eight independent islands (one per GPU), schedule-free AdamW \citep{schedulefree2024} inside each island, and plain model-weight averaging across islands every $\tau  =  250$ local steps (outer learning rate 1.0, momentum 0 --- the conservative plain-average form of DiLoCo \citep{diloco2023}). Scaling the same recipe past one machine pairs schedule-free AdamW per island with hierarchical local-SGD averaging: each island is one node of 8 GPUs with intra-island DDP, and inter-island synchronization averages model weights on the same $\tau  =  250$ cadence. The structural point holds either way: because the Emender distributes work across programs, the 1.3 B implementation uses ordinary head and batch parallelism while preserving each head's time loop.

ParaRNN \citep{pararnn2025} offers a different systems route, using an iterative solver to parallelize nonlinear recurrence along time. The present implementation instead retains one serial pass per head and obtains its parallelism across heads and batch elements.

\section{What the current models learn to compute}\label{sec:expressivity}


Comparable language-modeling loss leaves open what the carried state can learn to compute. We fine-tune the same 1.3 B E97 and GDN2 checkpoints on two explicit computations. The modular-quadratic task repeatedly applies a nonlinear map to a running value; E97's advantage supports the mechanism hypothesis that motivates its state update. The ${S }_{5}$ task composes permutations, whose running product admits the linear matrix-state update in Section~\ref{sec:background}. GDN2's stronger performance on this task is positive evidence for learning a computation compatible with linear-state recurrence. The two probes therefore test useful learned capabilities with different state-update structure: linear permutation actions and a map nonlinear in its running scalar value. Both studies concern learned performance under stated budgets and protocols.


\subsection*{Iterating a nonlinear map with the trained pair}


The decisive experiment uses the E97 and GDN2 checkpoints of Section~\ref{sec:lm}, with Schedule-Free y-mode recovery, on ${x }_{t } =  ( {x }_{t - 1}^{2} +  {c }_{t })  \operatorname{mod} 256$, 5 input drivers and running supervision. Both arms receive the identical full-fine-tune recipe: bf16 AdamW(betas=0.9,0.95), constant learning rate 0.00005, warmup 300, weight decay 0.01, gradient clip 0.5, batch 32, trained length 128, seed 42. The throughput-derived common cap of 18269 steps was fixed before accuracy was seen (\protect\path|budget.json|, \protect\path|1989656c|). It projects 4.35 GPU-hours if both arms reach the cap. The same pre-registered validation-loss plateau rule stopped E97 after 2500 steps and GDN2 after 2200 steps; actual training elapsed 0.649 GPU-hours, excluding loading and final evaluation. The common rule therefore yields different realized training durations.

The protocol below summarizes the retained driver, \protect\path|scripts/expressivity_1p3b_depthwall.py|, including its zero-based probe indices. Evaluation uses the weights at each arm's plateau stop. The terminal sweep is grad-free and scores every masked position using full-vocabulary argmax; reduced evaluation batches on OOM are recorded with the results.

\emph{Algorithm 4 --- matched-cap fine-tune and terminal evaluation.}
\begin{verbatim}
Input: bound y-mode weights; common recipe, cap, seed
1. Build fixed validation batches; initialize AdamW.
2. For step j = 0,...,cap-1:
   a. Draw a batch at T=128; run bf16 forward.
   b. Backpropagate masked cross-entropy over all positions.
      On OOM, split the same batch and accumulate gradients.
   c. Warm up LR for 300 steps, then keep LR constant;
      clip gradient norm to 0.5; take an optimizer step.
   d. Every 100 updates (and at cap), probe validation loss.
      With 4 probes and j >= min(1000,cap), stop if
      loss <= 1e-4 OR both 200/300-step gains are < 1%.
   e. Every 250 updates, record trajectory probes unless stopped.
3. Retain stop weights and actual update count for each arm.
4. For T in {128,256,512,1024,2048,4096,8192}:
   a. Set B=max(1,floor(32768/T)); build 8 seeded batches.
   b. Compute masked accuracy and loss without gradients.
      On OOM, halve B and rebuild with the same length seed.

\subsection*{Interpreting the current-pair evidence}


The iterated-map result is the direct empirical test of the motivating mechanism: E97's nonlinear state path repeatedly transforms the value that will enter the next update. The ${S }_{5}$ result demonstrates that GDN2 learns permutation composition strongly, as measured by its lead at every reported length. The formal results describe the state computations tested above: time-ordered nonlinear composition, the conditioned affine fold, finite-group tracking, adjacent split-gated cores, and conditional latching. Each statement below gives its assumptions and Lean source name.


\subsection*{Temporal composition and routing}



\begin{theorem}
The concrete repeated-map family is the schedule of \protect\path|CompositionalDepthDuality.E97Step| values $( k , e , w , v ) $ at fixed $\lambda $ (Lean field \protect\path|b| is the paper's erase gate $e $), acting through \protect\path|e97Step| on matrix state. \protect\path|e97Step_eq_tanh_comp| identifies the step as elementwise $\operatorname{tanh}$ after the state-affine split-gated core. \protect\path|e97StateAfter_eq_compose| gives its time-ordered composition, and \protect\path|e97_compositional_depth_grows_in_time| states that appending a step applies one more such map. For a fixed, state-independent schedule of \protect\path|CompositionalDepthDuality.GdnStepParams|, \protect\path|gdn_state_channel_depth_bounded_in_time| gives matrices $A , C $ with ${S }_{T }= A  {S }_{0}+ C $ for every initial state (Lean writes $H $ for this matrix). The theorem's state-channel depth is zero under this fixed, state-independent schedule.

\begin{theorem}

\subsection*{The finite-state tracker}


\emph{At fixed width and precision the Emender is a finite-state machine, and the ${S }_{5}$ word problem it is tested on is a concrete, fully specified finite-state target.}


\begin{theorembullet}
\emph{Finite-state ceiling at fixed precision.} At fixed width and precision, every online recognizer of this kind has only finitely many distinct states (\protect\path|S5Witness.fixed_precision_state_space_finite|). This gives a finite online state space.
\end{theorembullet}
\begin{theorembullet}
\emph{${S }_{5}$ word problem.} The target is pinned down exactly in Lean. The group ${S }_{5}$ has 120 elements (\protect\path|S5Witness.s5_state_count|) and is non-solvable (\protect\path|S5Witness.s5_not_solvable|); the prefix-product tracker that reads a word of transpositions and reports the running product is a 120-state recognizer (\protect\path|S5Tracker.recognizer_state_count|) whose state composes correctly as tokens are appended (\protect\path|S5Tracker.run_append|). A bridge lemma confirms the Lean tracker agrees with the Python evaluation harness on every input (\protect\path|S5Tracker.pythonRun_eq_tracker_tuple|). The four adjacent transpositions generate all of ${S }_{5}$: the tracker's run map is surjective (\protect\path|S5Inseparability.run_surjective|, via Mathlib's \protect\path|Equiv.Perm.mclosure_swap_castSucc_succ|).
\end{theorembullet}
\begin{theorembullet}
\emph{Capacity lower bound (recognizer floor).} Any finite-state recognizer with a state decoder that reproduces the tracker on every input word needs at least 120 states (\protect\path|S5Inseparability.capacity_lower_bound_120|); equivalently, no recognizer with fewer than 120 states can realize it under any decoder (\protect\path|S5Inseparability.small_recognizer_cannot_realize_s5|). The bound has a distinguishing-pair form: any recognizer with too few states admits two words it cannot tell apart that the tracker does distinguish (\protect\path|S5Inseparability.exists_distinguishing_word_pair|). This is the existential form of the ${S }_{5}$-coset inseparability target: it holds for \emph{any} finite recognizer family, with no architectural assumptions.
\end{theorembullet}
\begin{theorembullet}
\emph{Lookup-table realization.} The tracker is small enough to write down as a table: it uses exactly $120 \times  4 =  480$ state/input keys (\protect\path|S5NDMRealization.s5_transition_key_count|), and any finite recognizer admits such an exact lookup-table realization (\protect\path|S5NDMRealization.exactTransitionMemory_run|).
\end{theorembullet}

\subsection*{Conditional latching}


\emph{Saturation, hold, and release are described by slot-level bounds.}

These three results formalize the latching half of the Emender primitive: saturation makes a slot insensitive to further bounded writes, sign is preserved under sub-threshold counter-input, and a sufficient counter-delta releases the latch. All three are slot-wise statements on the full abstract Emender update, where $v $ denotes the bounded post-nonlinearity value input already supplied to the recurrent body, ${S }' =  \operatorname{tanh}( \lambda  S  +  k  {( v  -  {S }^{T } k ) }^{T }) $ at slot $( i , j ) $, with $\omega  :=  {k }_{i } ( {v }_{j } -  {( {S }^{T } k ) }_{j }) $ the write contribution into that slot. The proofs run through the standard tanh-perturbation foundation. The module carrying them (\protect\path|EmenderLatching|, introduced at \protect\path|696299b4|) is included in the refreshed inventory and the current clean \protect\path|lake build ElmanProofs.PaperCore|.


\begin{theorembullet}
\emph{Saturation insensitivity.} If the slot is saturated in the sense $| {{S }'_{i , j }}|  >  1 -  \epsilon $, and a perturbation $\delta $ to the pre-activation entry has $| \delta |  \leq  M $ with $\epsilon  +  M  <  1$, then the post-tanh slot moves by at most $2( \epsilon  +  M )  | \delta | $. The bound shrinks linearly in both the saturation slack $\epsilon $ and the perturbation magnitude $M $; at deep saturation a bounded write barely moves the slot. Lean: \protect\path|EmenderLatching.emender_saturation_insensitivity|. A two-input corollary \protect\path|EmenderLatching.emender_saturation_two_inputs_close| lifts the bound to two value vectors sharing one key.
\end{theorembullet}
\begin{theorembullet}
\emph{Sign-preserving hold.} With $\lambda  \geq  1$ and a bounded write $| \omega |  \leq  T  <  \lambda  ( 1 -  \eta ) $ at slot $( i , j ) $, a slot already saturated with $| {S }_{i , j }|  >  1 -  \eta $ keeps its sign after one Emender step and stays bounded below in magnitude by $\operatorname{tanh}( \lambda  ( 1 -  \eta )  -  T ) $. For $\lambda  >  1$ and small $\eta ,  T $ the argument $\lambda  ( 1 -  \eta )  -  T $ exceeds $1$, so the lower bound exceeds $\operatorname{tanh} 1 \approx  0.76$ and the latch holds with margin. The hypothesis $T  <  \lambda  ( 1 -  \eta ) $ is the "no sufficient counter-delta" clause; counter-delta release is the next result. Lean: \protect\path|EmenderLatching.emender_latch_holds_by_default|.
\end{theorembullet}
\begin{theorembullet}
\emph{Counter-delta release.} With $\lambda  >  0$, ${S }_{i , j } >  0$, and a write contribution $\omega  <  - \lambda  {S }_{i , j }$ in the opposite sign, the post-update slot is strictly negative --- the latch flips out of its basin in one step. Symmetrically for the negative basin. The release threshold is ${T }^{\ast } :=  \lambda  | {S }_{i , j }| $; any counter-delta exceeding ${T }^{\ast }$ in the opposite sign suffices. Lean: \protect\path|EmenderLatching.emender_latch_releases_on_counter_delta|. The quantitative companion \protect\path|EmenderLatching.emender_latch_release_quantitative| shows that if the counter-delta exceeds the threshold by margin $\mu  >  0$, the post-update slot lies on the opposite side of the origin with magnitude at least $\operatorname{tanh} \mu $.
\end{theorembullet}

\section{Repeated nonlinear maps in the wild}\label{sec:applications}


Balance, motion tracking, and movement correction offer an intuitive starting point: each new observation revises an estimate that guides the next action. The iterated-map study isolates a related computational question: how well can a recurrent model learn to keep transforming an evolving state? A common description is
\[\begin{aligned}{S }_{t + 1} =  {F }_{\theta ( {S }_{t }, {u }_{t }) }, \end{aligned}\]
 where $\theta $ fixes the update law and ${u }_{t }$ supplies the input at each step. E97's all-one split-gate specialization is
\[\begin{aligned}{S }' =  \operatorname{tanh}( \lambda  S  +  {k ( v  -  {S }^{T } k ) }^{T }) \end{aligned}\]
 with state $S $ and input $( \lambda , k , v ) $. Its returned state becomes the next step's input. The abstract E97 fold fixes $\lambda $ and supplies $( k , e , w , v ) $ at each step; the production architecture also supplies input-dependent decay.

\emph{Algorithm 5 --- repeated-map fold.}
\begin{verbatim}
Input: initial state S_0, fixed update law F_theta, input schedule
1. S <- S_0
2. For each input u in time order:
   S <- F_theta(S, u)
Return: S
\end{verbatim}


The examples below move from feedback and signal processing to optimization, conversation, and biological dynamics. They suggest further tests of learned recurrent surrogates. For each one, the state equation identifies the computation, and the proposed comparison identifies the regime and error measure that would make a difference useful.


\subsection*{Feedback and movement}


A controller must update its estimate and response while a system moves. A discrete-time plant with a smooth actuator limit and state feedback can be written
\[\begin{aligned}{a }_{t } =  {a }_{\operatorname{max}} \operatorname{tanh}( \frac{K  {x }_{t } +  L  {r }_{t }}{{a }_{\operatorname{max}}}) ,  \quad  {x }_{t + 1} =  A  {x }_{t } +  B  {a }_{t } +  E  {d }_{t }. \end{aligned}\]
 The state is ${x }_{t }$ and the inputs are reference ${r }_{t }$ and disturbance ${d }_{t }$. The resulting closed-loop map is $F ( x , ( r , d ) ) = A  x + B  {a }_{\operatorname{max}} \operatorname{tanh}( \frac{K  x + L  r }{{a }_{\operatorname{max}}}) + E  d $. Actuator saturation is a standard nonlinear-control concern \citep{khalil2002}. A learned surrogate comparison could vary how often saturation determines subsequent decisions, measuring trajectory error, latency, and closed-loop stability across operating regimes.


\subsection*{Signal processing}



\subsubsection*{Sigma--delta conversion}


A first-order sigma--delta modulator accumulates an analog sample and feeds back a quantized output \citep{candy_temes1992}:
\[\begin{aligned}{a }_{t } =  {r }_{t } +  {x }_{t },  \quad  {q }_{t } =  Q ( {a }_{t }) ,  \quad  {r }_{t + 1} =  {a }_{t } -  {q }_{t }. \end{aligned}\]
 The residue ${r }_{t }$ is the state, ${x }_{t }$ is the sample, and the fixed map is $F ( r , x ) = r + x - Q ( r + x ) $. A one-bit quantizer selects between two output levels. Its discontinuous output changes the residue used at the next step. A useful surrogate test would compare exact bitstream accuracy and filtered signal quality near quantizer thresholds over long streams, varying state precision and representation.


\subsubsection*{Adaptive filtering and gain control}


Normalized LMS \citep{haykin2002} updates coefficient state ${w }_{t }$ using regressor ${x }_{t }$ and desired sample ${d }_{t }$:
\[\begin{aligned}{e }_{t } =  {d }_{t } -  {w }_{t }^{T } {x }_{t },  \quad  {w }_{t + 1} =  {w }_{t } +  \mu  {x }_{t } \frac{{e }_{t }}{\epsilon  +  {\Vert {x }_{t }\Vert }^{2}}. \end{aligned}\]
 For fixed inputs this update is affine in ${w }_{t }$. Adding a componentwise coefficient limit gives ${w }_{t + 1}= {\text{clip}}_{B ( {w }_{t }+ \mu  {x }_{t } \frac{{e }_{t }}{\epsilon + {\Vert {x }_{t }\Vert }^{2}}) }$, which applies a nonlinear state transformation after the correction. Automatic gain control feeds measured output level back into gain \citep{lyons2011}. A bounded log-gain controller can use
\[\begin{aligned}{y }_{t } =  \operatorname{exp}( {g }_{t })  {x }_{t },  \quad  {g }_{t + 1} =  {\text{clip}}_{[ {g }_{\operatorname{min}}, {g }_{\operatorname{max}}] } ( {g }_{t } +  \mu ( {P }_{0} -  {y }_{t }^{2}) ) . \end{aligned}\]
 Here ${g }_{t }$ is the state and $( {x }_{t }, {P }_{0}) $ is the input. Repeated limiter crossings and state-dependent power measurements provide tests of nonlinear history. Stable operating regimes provide a complementary test of how much short-history approximation suffices.


\subsection*{Iterative optimization}


For the objective $\frac{1}{2} {\Vert A  z - b \Vert }^{2}+ \rho  {\Vert z \Vert }_{1}$, ISTA \citep{daubechies2004} repeatedly applies
\[\begin{aligned}{z }_{j + 1} =  {\text{soft}}_{\eta  \rho } ( ( I  -  \eta  {A }^{T } A )  {z }_{j } +  \eta  {A }^{T } b ) , \end{aligned}\]
 where ${\text{soft}}_{\tau ( a ) }= \text{sign}( a )  \operatorname{max}( | a | - \tau , 0) $ acts componentwise. The iterate is the state; each optimization step combines a gradient update with soft-thresholding. FISTA \citep{beck_teboulle2009} adds momentum:
\[\begin{aligned}{z }_{j + 1} =  {\text{soft}}_{\eta  \rho }( {y }_{j } -  \eta  {A }^{T ( A  {y }_{j }- b ) }) ,  \quad  {y }_{j + 1} =  {z }_{j + 1} +  {\beta }_{j ( {z }_{j + 1}- {z }_{j }) }. \end{aligned}\]
 Its state includes the previous iterate and the momentum schedule or clock. A surrogate study could compare accuracy and latency while the active support changes repeatedly. After support and signs stabilize, soft-thresholding is affine on the visited region, providing a useful second regime for the comparison.


\subsection*{Conversation and perception}


An ongoing conversation can revise a referent, correct an earlier fact, or change a goal. A stream of observations can similarly revise a motion estimate. These settings suggest learning an internal state whose update incorporates each new input into the current interpretation. Textual scratchpads expose intermediate computation in generated form \citep{nye2021scratchpads} \citep{wei2022chain}. Nonlinear carried memory offers a complementary place for that computation between observations and outputs. A useful study would vary the frequency of corrections and measure whether later responses use the revised information, alongside state size, generated-token budget, and response latency.


\subsubsection*{Driven reservoirs}


A standard echo-state network \citep{jaeger2001} uses
\[\begin{aligned}{h }_{t + 1} =  \operatorname{tanh}( W  {h }_{t } +  U  {u }_{t } +  b ) . \end{aligned}\]
 With recurrent parameters fixed, E97 also defines a driven nonlinear dynamical system, with state mixing determined by its input keys and gates. Training such a model on long-horizon reservoir trajectories would test how well it retains consequential nonlinear history. Varying contraction and the rate of forgetting the initial condition would connect the comparison to the echo-state property.


\subsection*{Biological dynamics}


Genomic function depends on nonlinear interactions among sequence features, regulatory signals, and cellular state. Enformer provides one example of using a nonlinear sequence model to integrate distal regulatory information for cell-type-specific predictions \citep{avsec2021enformer}. Pangenomic datasets run to terabases per study \citep{hprc2023} \citep{guarracino2023acrocentric} \citep{pggb2024}, motivating efficient nonlinear recurrence for long, structured inputs. A future study could ask whether recurrent memory can integrate sequence features with changing regulatory signals and cellular context, evaluated through held-out expression or perturbation-response prediction.


\subsubsection*{Population dynamics}


May's logistic population model \citep{may1976} is
\[\begin{aligned}{n }_{t + 1} =  r  {n }_{t ( 1- {n }_{t }) }. \end{aligned}\]
 The normalized population ${n }_{t }$ is the state and $r $ is a fixed parameter. An environmentally driven extension can use ${r }_{t }$ as an input. Comparing learned trajectories across contracting, periodic, and chaotic regimes would test how error growth and history retention shape recurrent-model performance. The evaluation horizon and error metric should reflect each regime's predictability.

These tasks put the computational idea to work: learn a state update whose output remains consequential over many iterations. Width-axis multi-programming offers a practical way to run many such learned programs concurrently. Task-specific comparisons across horizon, precision, state size, and latency would establish where that design is useful.


\section{Related Work}\label{sec:related}



\subsection*{Intermediate computation in language models}


Scratchpad training \citep{nye2021scratchpads} and chain-of-thought prompting \citep{wei2022chain} use generated intermediate steps to improve multi-step computation and reasoning. The generated sequence carries the working calculation forward through successive decoding steps. Emender studies ongoing computation in a fixed-size recurrent state, updated as each input arrives. The two forms of computation can work together: generated intermediates provide an explicit working sequence, while nonlinear state updates carry a revisable internal computation through the input stream. This organization motivates tests on iterated maps and feedback tasks with a per-step time budget.


\subsection*{Ancestry: the fast-weight line on delta correction}


The Emender update belongs to a long line that treats memory as a structure updated by prediction error. The earliest formulation is Widrow and Hoff's least-mean-square rule \citep{widrow_hoff_1960}, which writes the error between target and current output back into the weight vector of an adaptive linear element. Schmidhuber recast the same idea in a recurrent setting under the name \emph{fast-weight programmers} \citep{schmidhuber_1992_fastweights}: a slow controller emits keys and values that update a fast-weight matrix online, with the update being a correction against what the matrix currently predicts at the addressed slot. Schlag, Irie, and Schmidhuber made the bridge to modern attention explicit \citep{schlag_irie_schmidhuber_2021}, showing that linear-transformer kernels with cumulative outer-product updates \emph{are} fast-weight programmers with a raw additive write, and proposing the delta-rule write as a stability and capacity fix. DeltaNet \citep{deltanet2024} carried the delta rule into a parallelizable linear-recurrent language model, demonstrating the rule at billion-parameter scale in the linear-state regime. Emender combines delta correction with a nonlinear matrix-state update and width-axis multi-programming. Its saturating update also motivates the conditional latching analysis in Section~\ref{sec:formal}.


\subsection*{Linear-state recurrent language models}


The dominant comparison cohort is the family of linear-state billion-parameter recurrent LMs surveyed in Section~\ref{sec:background}: Mamba \citep{mamba2024} and Mamba2 \citep{mamba2_2024} (selective SSMs); RetNet \citep{retnet2023} (decayed linear attention); GLA \citep{gla2023} (gated linear attention); DeltaNet \citep{deltanet2024} (delta rule, linear in $S $); Gated DeltaNet \citep{gated_deltanet2024} (gated delta rule); RWKV-4/5/6/7 \citep{rwkv4_2023} \citep{rwkv7_2025} (linear-state WKV / generalized delta rule with linear state); HGRN2 \citep{hgrn2_2024} (gated linear RNN with state expansion); MinGRU/MinLSTM \citep{mingru_2024} (input-only gates, linear scan); mLSTM/xLSTM-7B \citep{xlstm7b2025} (covariance update); Griffin/RecurrentGemma \citep{griffin2024} (RG-LRU, often hybridized with local attention). Circuit-containment results for restricted SSM families require their stated transition and arithmetic assumptions \citep{merrill2024transformers}. The current empirical comparison uses GDN2. Its long-horizon ${S }_{5}$ result in Section~\ref{sec:expressivity} demonstrates strong learning of permutation composition, a task with an exact linear-state representation.

In the broader SSM/sequence-model lineage, S5 \citep{s5_2022} introduces simplified state-space layers with a multi-input multi-output linear state-space recurrence. It is distinct from the permutation group ${S }_{5}$ used as a probe here.

A newer linear-state result, Gated DeltaNet-2 \citep{gated_deltanet2_2026}, decouples channel-wise erase and write gates and is reported by its authors to outperform GDN. It extends retrieval and state-tracking behavior inside the linear-state envelope, and it is the linear-recurrent baseline of this paper's 1.3 B pairing: the GDN2 arm of Section~\ref{sec:lm} is the official-style Gated DeltaNet-2 mixer (external source commit \protect\path|95709fc|) with the same SwiGLU MLP as E97, selected by the same CMA-ES protocol. The E97 split gates of Section~\ref{sec:arch} are the Emender's corresponding edit --- key-axis erase/read plus value-axis write --- inside a \emph{nonlinear} state map, so the two architectures are adjacent by design (Section~\ref{sec:formal}). Its decoupled gates are a natural next ablation for the multi-programmed substrate, as a bounded edit to the per-step update body.


\subsection*{Pure-nonlinear-recurrent peers and adjacent nonlinear-state work}


\emph{M\textsuperscript{2}RNN} \citep{m2rnn2026} (Mishra, Tan, Stoica, Gonzalez, Dao 2026) introduces nonlinear matrix-state recurrence with a raw-write update $Z  =  \operatorname{tanh}( H  W  +  k  {v }^{T }) $. It shares the central systems premise of this work --- that a nonlinear recurrence is serial in time and must take its parallelism from the batch and head axes --- and demonstrates that the update trains at 410 M dense and 7 B MoE scale on Nemotron-CC-v2. Its headline demonstrations use hybrid stacks that interleave attention and nonlinear recurrence. The current study instead evaluates the pure recurrent E97 mixer against a matched GDN2 control. This connects the present work to other nonlinear matrix-state designs.

\emph{xLSTM-1.3B} \citep{xlstm2024} is a 7:1 mixture of mLSTM (linear) and sLSTM (nonlinear) blocks; with 87.5\% of its blocks linear-state, it sits closer to the linear-state class than to the pure-nonlinear-recurrent one. It is the closest scale band among prior nonlinear-recurrent results, included here as a peer with a small nonlinear-block share. The xLSTM-7B follow-up \citep{xlstm7b2025} uses \emph{only} mLSTM (linear) blocks, further from the pure-nonlinear-recurrent class still.

\emph{Titans} \citep{titans2025} uses an MLP memory with online gradient updates and is qualitatively nonlinear-state, but it interleaves attention layers and has not been evaluated as a pure recurrent model at Pile-class scale. \emph{Zeroth-order LSTM scaling} \citep{lstm_zoo_2025} demonstrates 1 B-scale LSTM training under a non-gradient regime, outside the standard-gradient comparison drawn here.

Classical LSTM and GRU provide the foundational gated nonlinear recurrences \citep{lstm1997}. E97 explores a matrix-memory implementation organized around many independently addressed recurrent heads.


\section{Open questions}\label{sec:limitations}



\subsection*{Learning and evaluation}


The current pair supplies one language-model training seed and one seed for each reported computational probe. Repeated seeds, common fixed-step budgets, and comparison of terminal with best-validation checkpoints would measure the stability of the observed gaps. A feasible matched ${S }_{5}$ curriculum would test the contribution of the length-512 memory limit encountered by GDN2.

Held-out tokenizer-invariant bpb and downstream evaluation are the next language-model measurements. Recovering the original CMA winner logs would also supply generation-zero fitness, spread, and total search effort for the carried-in configurations (U3.1). These records would support a matched-total-budget search comparison.


\subsection*{Recurrent realization}


\emph{O1: realizing the group tracker.} Find an E97 update configuration, initial state, and decoder that carry the running ${S }_{5}$ product, then prove the trajectory property over all words.

\emph{G3: realizing group actions in the constrained affine channel.} The permutation-matrix construction establishes ${S }_{5}$ tracking in the general linear-state class. Find a representation satisfying GDN2's split-gated decay-minus-rank-one transition and production gate and decay ranges, or characterize the algebraic obstruction. The current Lean identities allow an arbitrary decay matrix; the production restrictions define this more specific realization problem. The observed learning results establish GDN2's empirical capability under the reported protocol; G3 asks for an exact all-words construction.

\emph{G2: state-dependent parameter schedules.} Extend the formal update class to gates that read carried state, and characterize its composition and cost.

\emph{G1: the cost of generating token-dependent actions.} Building on the realization question, determine the resources required by the network that supplies the per-token parameters. The four-symbol group schedule provides a concrete case for this analysis.

G1--G3 are recorded in \protect\path|formal/lean/GAPS-D2.md|. Persistence also needs a production-range result: the stated hold theorem assumes $\lambda  \geq  1$, while production decay lies below one. A layer-level and finite-precision analysis would connect that result to practical memory retention.


\subsection*{Scale and implementation}


A matched 3--7 B pair would test how training loss, memory use, and computational behavior change with scale. Current-scale internal ablations would separate the effects of state nonlinearity, gates, and geometry. Direct E97 occupancy profiling, actual FLOP accounting, and paired ROCm measurements would extend the systems evidence.

The application tests in Section~\ref{sec:applications} call for long-horizon error and latency measurements in their stated regimes; feedback applications additionally call for stability testing. The bibliography's flagged publication metadata should be resolved during submission preparation.


\section{Conclusion}\label{sec:conclusion}


Emender makes recurrent memory a site of ongoing computation. Each input corrects the stored state and transforms what the next step receives. Running many small heads in parallel makes this sequential computation practical: E97 trains through 150.8 B Pile tokens at 1.3 B parameters and reaches comparable training loss to GDN2. A Frontier continuation extends the same architecture to 513.0 B accepted tokens, with the recorded rank-0 loss falling to 2.2798 nats/token.

The iterated nonlinear-map experiment connects that practicality to the architectural motivation. E97 learns the recurrence more accurately and retains a larger fraction of its accuracy as sequence length grows. GDN2 learns ${S }_{5}$ permutation composition strongly and leads its long-horizon comparison. Since this task admits an exact linear-state representation, GDN2's result is a meaningful success on a computation compatible with linear-state recurrence. Alongside E97's advantage on iterated nonlinear maps, it shows why the computational structure of the task matters. The formal state-channel results make the architectural distinction precise: repeated nonlinear composition in E97, and an affine GDN fold under a fixed, state-independent schedule.

These findings support studying nonlinear memory as a computational resource. The next step is to test that resource across training budgets, scales, and tasks in which an evolving state must keep being transformed: feedback, iterative optimization, and driven dynamics.

\section{Next tests for the current pair}\label{sec:predictions}


The current results motivate three direct tests. First, repeat the iterated-map and ${S }_{5}$ protocols across seeds and common realized training budgets, recording both terminal and best-validation checkpoints. Persistence of the map advantage would strengthen the mechanism hypothesis; its disappearance under those controls would locate an optimization or protocol dependence. Second, ablate the state nonlinearity within the current E97 geometry, holding the remaining implementation and training choices fixed, to test its causal role at this scale. Third, evaluate the two immutable language-model checkpoints on held-out text and downstream tasks.


\section{Future Work}\label{sec:future_work}


A matched 3--7 B E97/GDN2 study would test training viability, memory cost, and computational behavior across scale. The feedback, optimization, and driven-dynamics tasks in Section~\ref{sec:applications} would test utility beyond language. Mathematical targets are a recurrent $\operatorname{tanh}$ tracker (O1), constrained affine/reflection realizability (G3), production-range persistence, and finite-precision robustness.

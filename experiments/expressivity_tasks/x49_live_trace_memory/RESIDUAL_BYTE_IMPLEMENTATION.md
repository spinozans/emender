# How to test one extra byte without secretly reading the old vector

[Registered comparison](RESIDUAL_BYTE.md). On an earlier `color: b…`, D can reconstruct a value from the `b` and two notes about how surprising it was. R pays to compute the actual vector at that point, compares it to D, and leaves a third byte. Later, can those eight bits help predict the next real byte better than **another occurrence's** eight bits, even if the `b` and its two notes are identical?

[`residual_codec.py`](residual_codec.py) derives the eight axes only from the frozen read head, not FIT or PROBE. It orients and stores the axes as FP32, uses an ordered FP64 sum for each sign, and refuses ambiguous leading eigenvalues. FIT accumulates residual sums and counts by the new byte at all eligible observed positions, without receiving any future target or hit mask. The deployed per-code means and global control are FP32. [`residual_byte.py`](residual_byte.py) separates emitting records from reading them: only three independent byte tapes and a one-window scope token travel with a record. In the diagnostic panel, selected full-vector controls are returned separately; the compact path requests none. Its sham picks the chronological successor (wrapping in the eligible age bin) with the same discrete triple, without seeing the third byte. Only the scorer receives the target shift.

**Mechanism check:** 14 tests passed in 7.34 s at `5efdd8223b518a9ad59b84e14fad0f1ae08101e9`, CPU-only with the retained native text writer. Log SHA-256 `3c38bdb598917e098a6f6a8c48849e4bfa8cc7c9034d81d7e64db9c2515c16c0`. The invented-stream comparisons cover bit order and fallback, dense donor and score oracles, B/U/J/D parity, post-write isolation, prefixes, clipping and all-target accounting. This establishes that the extra byte can be tested without the compact reader accessing the old vector, not that it helps on text.

**Two separate freezes.** [`residual_run.py`](residual_run.py) identifies each actual W-B state, U/J coefficients, prior DR FIT seal and private D table. CPU qualification derives a digest and spectral checks on each strictly loaded head. Natural preparation requires the matching public qualification receipt. [`residual_data.py`](residual_data.py) replays DR and earlier exclusions using descriptors, not previous windows. Only the next full native TRAIN block is eligible. The raw reader prepares FIT only. Before opening raw PROBE the independent observer must witness the completed FIT boundary and the seal must replay for all three seeds, including actual codebook/global control, moments, source journal, checkpoint, axes and D identities. The progress counter measures positions consumed; there is no FIT target-loss measurement.

After each codebook is fitted, save and reload the actual arrays and compare the complete B/U/J/D and standalone R answers at that checkpoint on **invented** bytes. Four extra synthetic prefills per seed outside natural exposure. [`residual_stats.py`](residual_stats.py) counts support for displacement separately from a changed third byte: many donors can still carry the same information. Seven absolute losses include misses. The independent close audit recomputes mean checks, previously unseen code reads, hit-component MSE denominators and eleven document-paired intervals without rereading text. Codebooks, axes and document records stay private. Timing the write and read components in a shared panel is not a streaming inference benchmark.

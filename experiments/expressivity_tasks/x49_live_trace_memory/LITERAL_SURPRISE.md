### A fixed literal forecaster with no learned table

At observation `j`, before inserting `x[j]`, form a predictive distribution from **only** `x[:j]`. Start with the order-zero KT estimate `p(b)=(count(x[:j], b)+1/2)/(j+128)` over all 256 byte values. For depths `d=1,2,4,8` in ascending order, when `j>=d` take key `x[j-d:j]`. Among earlier positions `d<=i<j` with `x[i-d:i]` equal to the key, let `C_b` be the multiplicity of follower `b`, `N=sum C_b` and `K` the number of distinct followers. If `N>0` replace `p(b)` with `(C_b+K*p(b))/(N+K)` for each `b` (interpolated Witten–Bell); otherwise leave it alone. This is a normalized forecast even on unseen contexts. Use all observed continuations, including overlaps and recent ones, **no** 16-byte delay in this estimator. The *read address* still uses B's exact H4096 geometry/delay. No fitted smoothing, imported counts, tokenizer, EOS, padding or global byte statistics.

On each `j>=1`, write `T[j]=Q(-log p(x[j]))` using U's original round-half-up saturated quantizer `min(255,floor(16*max(0,s)+0.5))`, natural log and FP64 arithmetic. Write one actual uint8 per input with slot 0 zero/unread. Incorporate the arrived byte in the count tables only **after** forming its mark; include `x[0]` in subsequent order-zero history. A sparse implementation may evaluate only the observed component of this already-defined distribution. An observed byte can be marked on arrival; the *next prediction target* cannot be used as a feature. Verify against independent dense distributions on growing binary prefixes, including empty contexts, exact multiplicities, ties/overlap and reset. No text table, neural value, mark or host state crosses documents or weights.

## One cheaper, key-blind pair table

Let `q_t` be the bare host's top predicted next byte at t (lowest tied byte). When actual `c_j` arrives, `a_j=q_{j-1}` becomes a recorded mistake only if `a_j != c_j`. PAIR retains a separate guessed-byte → actual-correction table **at each literal key**. PREFIX instead keeps **one** sparse table of earlier mistakes in this window. It gets the same local marginal features as MARG, but must not keep, read or reconstruct any per-key *pair* counts. It must not re-execute a host or scan occurrences to infer them. The shared ERROR marginal index is still local to each literal key; it is not free or removed.

At frontier t the prefix table has admitted every arrival `1<=j<=t-16` once. Denote its pair counts `G[a,b]` and actual-correction counts `G[*,b]`. For this lookup only, **discount the selected key's latest eligible arrival** if it was a mistake (subtract its single edge and column count). This is the same latest observation already handled by J; do not subtract it from live state used at later/different keys. Other eligible records including the older records of this key stay in the global table. PREFIX is a lower-state alternative, **not** a disjoint donor panel. Forecasts can include the current query without appending it or observing its future follower.

Use PC's older local marginals `M_b` (number of times b was the missed actual follower), `W_q` (wrong guesses of q), `C_q-M_q` (correct historical guesses of q). On no hit, singleton, or `h=W_q=0` all new rules return ERROR unchanged. Otherwise PC's `A=h/(1+h+C_q-M_q)`, `v_b=1[b!=q] M_b/(sum M - M_q)` and MARG's `f0_b=A*(v_b-1[b=q])` stay fixed. The alternative to the true conditional law `D[q,b]/h` is

```
z_b = M_b * G[q,b]/G[*,b]    for b!=q and M_b>0, else 0
r_prefix_b = z_b / sum(z)
f1_prefix_b = A * (r_prefix_b - v_b)
```

The prefix frequency estimates **how often this guess was made when b was missed**. Weighting the local alternatives this way compares like with like: if the prefix consisted only of the local older mistakes, the rule would give the exact true law. No smoothing knob or external confusion table. Check `G[*,b]>=M_b` on the supported alternatives (after discount) and that `sum(z)>0` on every active row: at least one earlier local mistake actually guessed q. Fail closed on violated support, never choose a fallback from the observed scores. The extra column is zero at q, and both PAIR and PREFIX have the same activation, local alternative vocabulary, discount, unpaired column and coefficients. Differences test the source of the *association*, not just the fact a guess was wrong. Even a win against PREFIX wouldn't exclude a fitted corpus-wide confusion model.

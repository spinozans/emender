For each checkpoint take the FP64 copy of `A=head.mix.weight[:,host_dim:host_dim+32]` (64×32): these are exactly the weights multiplying the old payload before the outer `tanh`. The top eight right singular directions of A are the orthogonal payload perturbations that most change this *linear preactivation* per unit squared change. Require finite orthonormal eigenvectors and separated leading eigenvalues, including the 8th vs 9th (`gap > 64*eps64*largest_eigenvalue`); refuse an ambiguous basis instead of trying another codec. Bit `i` of the new byte is 1 iff the projection of `e_j` on stored axis `i` is **strictly positive**; bit 0 is the highest-eigenvalue axis. Promote each FP32 operand to FP64 and sum components 0..31 in order, no fused reassociation. Exactly zero → 0. Slot 0 is zero/unread.

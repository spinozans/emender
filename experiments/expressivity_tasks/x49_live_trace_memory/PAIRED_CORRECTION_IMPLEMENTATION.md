[Registered comparison](PAIRED_CORRECTION.md) · [earlier locked transfer](RESULT_ERROR_TRANSFER.md). **No PC natural result here.** At an observed frontier the current lookup symbol is the bare host's top prediction, whether or not it will be right. Earlier lookups' guesses become eligible for the correction table only after their actual followers arrive, age into the literal index, and cease to be the selected key's latest eligible record. No current label or extra neural call is needed.

[`correction_index.py`](correction_index.py) holds one pending follower per admitted suffix and sparsely counts committed mistakes by guessed byte, then actual follower. At query it emits only the current guess's row of nonzero corrections; even a deeper singleton wins over a shallower key. The reference control has its own table. It keeps an unmatched old mistake provisionally on its real edge until the second old mistake commits. Only then can it replace two edges by crossed edges; it neither rewrites past queries nor creates a correct-guess edge. [`paired_correction.py`](paired_correction.py) independently checks the table geometry against frozen ERROR, the queried row sum against `W_q`, and each proposed count against its permissible missed-alternative count. Standalone MARG constructs no pair table, and PAIR never constructs switched pairs. Component peak counts are not Python heap sizes. The CPU research implementation builds the extra pair index from scratch, not a free look-aside into a service.

The marginal feature and per-guess conditional law use only observed data; the control retains the same two margins and current query support. [`paired_correction_fit.py`](paired_correction_fit.py) fits one MARG and two two-scalar rules per weight, at the unchanged ERROR distribution. Denominator = *all* real FIT targets. Zero-support rows do not silently disappear from the normalization or scoring. The three systems' common first-column moments must agree. After the FIT/PROBE boundary SWAP takes PAIR's sealed coefficients without fitting.

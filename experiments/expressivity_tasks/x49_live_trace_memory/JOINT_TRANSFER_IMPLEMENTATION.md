# Frozen joint-reader transfer: implementation boundary

[Protocol](JOINT_TRANSFER.md) · [prior full-window result](RESULT_LITERAL_SURPRISE.md) · [exact writer](RESULT_JOINT_READER.md).

[`transfer_score.answers`](transfer_score.py) receives only observed bytes. It makes one causal host prefill, constructs B and the correct neural fields once, then runs two separate branches from that same unmodified packet. U returns its ordinary correction. [`joint_reader.branch`](joint_reader.py) builds the native tape, gathers only the correct entries, inserts the literal field before the neural field, and returns the fixed J correction. This is also the branch used by `load_candidate`. A subclock measures the entire native writer call inside J. The two branch clocks alternate order on rank + seed index; H is a different fixed vector on the neural-only fields and runs outside both clocks. All four complete score arrays exist before `document` receives shifted labels at the scoring seam. Shared and branch clocks do not count as two independently timed model runs.

[`transfer_data`](transfer_data.py) rebuilds exclusions up through both LS roles and verifies their reservation against the LS result. Only `calibration`, SHA residue 0 and 2–4,096 bytes, can enter the new rank. Duplicate hashes use the earliest eligible offset. First crossing of 524,288 targets or refuse; no final fallback. Metadata reservation rederives the descriptors twice without opening the text. [`transfer_panel`](transfer_panel.py) binds the LS FIT seal, original U confirmation, verified writer binary, exact W-B endpoints, JT qualification, membership, release scope and its own one-job envelope. The shared short-document scaffold uses closed `UC`/`JT` dispatch; the campaigns do not inherit each other's split, data root, job, fits, authority or release. The raw reader checks scope *inside* the open path, after shape/score parity on synthetic input. C14 checks the entire SHA and both true shifts; no padding or persistent window cache.

[`transfer_run`](transfer_run.py) has no update, fit, DOE, or final mode. A detached witness independently reconstructs the cumulative real target count from the variable-length reservation, not `units × 4096`. [`transfer_stats`](transfer_stats.py) rejects timing order or table-work mismatches, conserves hits/misses and copy correctness, and resamples whole documents with their actual lengths. [`transfer_analysis`](transfer_analysis.py) separately recombines the measured per-document shared and branch times, rehashes the weight files and journals, checks release/charge and reconstructs all five comparisons from absolute losses and bootstrap multiplicities. No text or model execution is required for closure.

# X49-Q — which compatible past computation should a literal read return?

Prospective, 2026-11-25 UTC, after [closing W](RESULT_WRITE.md). No Q selection, natural address census or Q scores yet. **Keep B's trained writes; vary only which real write supplies the neural value.** W showed a much larger effect of shuffling the outer value than the inner one. The old sham preserves byte and age bin, but need not preserve the matched suffix. It does not show that *the most recent* compatible record is the best address. Nor does sensitivity to a binding show that a new address beats B. This is a small frozen-predictor comparison, not retraining, a new scale nomination, or a reopening of any final.

## Three one-read predictors

For each seed 4901/4902/4903, freeze its full-dose **W continued-B** host and head (`wB-<seed>/weights-1024.pt`, checked against [the W receipt](receipts/write_result.json), SHA `538811441a9fb0dba5502a10d6b9ca550a179c463003b623a86433794f6b8b0d`). The W source is `a8eda5bf15228c1f198176cb40bfd68cfb7900fc`. No gradient, policy, learned selector, new weights, optimizer, mixtures or archive. One raw 4,096-input window at a time; one ordinary full causal host prefill per weight/document. **H4096 only** for this address diagnostic. No new horizon or wall-matched training claim.

At prediction frontier `t`, after observing `x[t]` and before seeing its target, run the unchanged B literal query. `d` is its longest eligible depth in 8/4/2/1; `j` is its latest follower slot. On a miss all models return B's ordinary answer. On a hit **fix** `x[j]`, `h_t`, the full B histogram and direct probabilities, depth/support and latest-age features (these still describe the actual literal query at `j`), and the same writer/readout tensors. Separate the address of the **neural payload** from the address of that fixed byte evidence. Do not choose a different observed continuation, pool extra histograms or read several vectors to rank them.

Eligible slots `k` match the depth-`d` key **and** have `x[k]=x[j]`; `k-d>=lo=max(0,t+1−H)` and `k<=t−16`. Define `ell(k)` to be the greatest `m` from `d` through **32** for which both suffixes stay in bounds and `x[k−m:k] == x[t+1−m:t+1]`. This is left context **before** the stored follower, never bytes to its right. All overlap multiplicities remain in B's original counts. Thirty-two is a bounded address comparison, not a new host context or an effect-size cutoff.

- **J (incumbent):** read the base neural write at `j`, exactly B.
- **E (extension):** take a slot of maximal `ell`, breaking ties by largest `k`. If no slot strictly improves `ell(j)`, this returns `j`. Read just its neural payload. This is a constructive candidate, not a generic wrong-binding shuffle.
- **M (matched substitution):** where E stays, stay. Where E moves to `e`, seek another eligible `k != j,e` with `ell(k)==ell(j)` and the same log2 age bin as `e`, i.e. `(t−k).bit_length()==(t−e).bit_length()`. Minimize `abs(k−e)`; ties choose larger `k`. If no such control exists, use **E itself**, not J. Thus E and M move off J on precisely the same frontiers; differences between them are confined to support with a real matched alternative. They pay for their actual address operations, not unchosen neural reads. Age *bins* match; exact ages generally cannot. Report the age displacement on matched substitutions. This does not independently randomize all aspects of source context.

Every arm writes the same `b_k=tanh(writer([h_k,embed(x[k])]))`. On a hit the sole neural read is from its chosen slot. No extra feature describing `ell`, no training on the alternatives, no lookup with a target or caller-supplied candidate positions, no private scratch as text. Qualified batched computations must agree with per-prefix searches. Never cache host features or values across weights or documents. A given model's packet can serve its three frozen sibling interventions; no output may feed back into the host or the next document. Cost J without extension work, E without placebo search, and M with it. This is not the X43 positional experiment, which changed continuation **histograms** using older word anchors.

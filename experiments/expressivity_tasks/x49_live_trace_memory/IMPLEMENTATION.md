# X49 reference learner (before any natural learner runs)

**Status:** CPU source/fixture specification, not a natural LM or Lux performance result. [Charter](CHARTER.md) and [plan](PLAN.md) govern. [V1 data stop](DATA_STOP_V1.md) remains binding. These choices specify how to implement the registered predictors, not an amendment to the splits, budget or decision thresholds.

- **Origin:** verify the private 1,310,089,971-byte X48 direct H step-1024 checkpoint (`cf7337b5…`), binding, step, measured GDN2 source and chunk kernel. Strict-load the actual host and four direct tensors into new modules. **Do not restore X48 optimizer moments.** One unsegmented 4,096-byte causal host forward per training document: T1 packet, 256 normalized hidden channels plus 256 logits, BF16 host autocast and FP32 master. CPU FP32 restored DirectTrust and heads. No cached old features, cross-document state, archive, padding or fake reads. The [synthetic device meter](RESULT_METER.md) subsequently demonstrated this geometry and priced real successor replay, not natural performance.
- **Literal B**: 16-dimensional byte embedding; `tanh(linear([h_j, embed(x_j)],32))` write on each observed input. The shared 64-wide tanh read head sees current `h_t`, selected value, follower embedding, 11 direct statistics and the full normalized local histogram. A 256-logit residual has a zero-initialized final projection and preserves the original log mass. Misses return direct unchanged. A recomputes the same-sized projection using `h_t` and the same historical byte. Both have 83,684 head parameters. No archive expert mass in either arm.
- **Private F/C:** retain the literal B answer. Every observed `j>=1` files one private categorical byte and a distinct 32-dim tanh value from `h_j` and the observed follower embedding. Every `t` queries one symbol. Only the most recent eligible exact private match is read; lag 16; no speculative alternatives. The trace correction is a 64-wide tanh projection of current state, observed follower embedding and the bound private value; final 256-logit output zero at birth. Fixed contact schedule, no generated natural-language scratch text and no trace-conditioned change to the causal host stream. Total F/C head sizes match; F freezes its two key-logit maps, C learns them.
- **Choices:** literal-conditioned categorical prior with mass `.9 + .1/256` at the literal symbol, `.1/256` elsewhere. C adds zero-initialized affine logits from the causal host state to the log prior. Local CPU `torch.Generator`, first 8 SHA256 bytes of `x49-private-v1:<seed>:<document ID>:<visit>:<file|query>` as a big-endian integer, one FP64 uniform per frontier/role; search the normalized cumulative probabilities for that frontier. No tensor containing future text or a full-document content hash is a model input. Coupled draws, not a fixed tape of choices. In evaluation use visit zero for every arm/horizon/intervention; seed is the paired training seed.
- **Credit:** pathwise NLL gradients on values and host. For C, add gradient-only `log π(a) × detached advantage` divided by number of external targets. For a query at `t`, advantage is current byte loss less fixed baseline 2. For filing at `j`, it is the sum of those terms for `j+16 <= t < min(T,j+H)` on *all* those external targets, not just hits. Outside that interval this write cannot affect any return in this model: keys depend on observed bytes and host state only. This is a sampled, potentially high-variance estimator; executing it does not show the filing policy is useful. F has no key-policy gradient.
- **Optimization:** X48 H schedule and global clipping from the plan. GDN2 option B: 191 host Muon tensors, 406 AdamW. Literal hidden/writer/mix/byte-logit output matrices on Muon, byte embeddings, four-expert vote and all biases on AdamW. Private value/mix/delta matrices on Muon; filing/query output maps (C) and small auxiliaries on AdamW. Exact named partition with frozen policy parameters excluded for F. Checkpoint replay compares selected scores, parameters and both optimizer states on the *next transition*, not just reload success.
- **Checks:** independent prefix scan and native XSA locate/byte, exact integer addresses and birth draws, bitwise A/B/F/C birth scores on the common strict CPU fixture, FP32 prefix log-probability tolerance absolute `2e-6`, zero relative tolerance. Delayed gradient and causal wrong binding. Deterministic CPU next-transition replay requires tensor equality. These are CPU fixture tolerances; no segmented host or weaker CUDA parity substitution is authorized here. Natural admission pins the metered local environment: Python 3.12.3, Torch 2.9.1+cu128 (distribution 2.9.1), Triton 3.5.1, FLA 0.5.1, NumPy 2.4.6, pinned autotuning, RTX 6000 Ada with 50,876,841,984 device bytes, BF16 host/FP32 masters and four CPU threads. Each job must retain device/build/binding, timing, memory and charge. See [the one-budget panel](PANEL.md).

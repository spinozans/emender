## What varies

Use the same retained 150M GDN2 and trained direct head (X48 direct step 1024, SHA-256 `cf7337b520958056a648e4f78a939ded3ed5a4d1bc8f871d8a900d64464b1357`). Keep the host, document-local follower distribution, and latest observed follower. Mask the unavailable archive expert identically in all arms; no archive requests or archive-derived features. Learn corrections on top of direct, never instead of direct. Train both backbone and head. Absolute scores from X48, older Emender or a Transformer are not controls.

| Arm | Read, at the same external prediction position | Question |
|---|---|---|
| **A: bytes** | Live suffix counts and last follower; current host + byte-conditioned MLP. No old neural value. | Strong live-only incumbent, including nonlinear use of the answer. |
| **B: bound values** | Exactly A's positions, bytes, counts and supports. At the chosen old position also recall the 32-dimensional learned value written when its follower became visible. | Does a correctly addressed earlier computation beat recomputing a feature now? |
| **F: fixed trace** | B plus one private one-byte filing key per write and one key query per step. Fixed literal-based key policy with the same exploration prior as C. | Pays for the extra table, capacity, accesses and stochasticity without learning where to file. |
| **C: learned trace** | Same read/write schedule and value path as F. Learn which one-byte private symbol to file and which to query. No additional external supervision. | Does learning a searchable trace add anything beyond B **and** the matched fixed-key control? |

A/B are first. F/C follow once the same-address implementation qualifies; all four train from common source weights at the **same total exposure**, not an extra dose for C. A scientific B null is recorded and does not silently cancel C. A technical failure blocks descendants that rely on the failed mechanism. No extra flavors of A/B/C based on interim losses.

### The causal contract

* One fresh live context and private record space per document **window**. At `t`, `x[0:t+1]` is visible; predict and score `x[t+1]` before appending it. Scratch symbols, END, and model guesses are never observed text or scored targets. All 256 bytes, including NUL/0x1e/0xff, are ordinary values. Never use target labels, future eligibility, other documents, or cached activations from different weights.
* Start with a bounded exact string kernel: longest usable suffix at depth **8, 4, 2, 1**. For horizon `H`, `lo=max(0,t+1-H)`. At depth `d` the matched key is `x[t+1-d:t+1]`; eligible earlier followers have `j-d >= lo`, `j <= t-16`, and `x[j-d:j] == key`. Use the first depth with any eligible follower. Count all their byte values with multiplicity; return the latest `j`, its byte, support, depth and age. No match means zero evidence; the host still predicts. A cap refusal is not an empty answer. A/B differ neither in coverage nor which position is read. A batched address plan from observed bytes is allowed only with prefix-by-prefix equivalence to independent overlapping counts and real XSA `session` locate/byte on the causal range; never call a precomputed byte-key map a learned trace or a native speed measurement.
* In B, `v_j = W(h_j, x[j])`, where `h_j` is the causal host representation **including** the observed follower. In A the same-size projection gets `h_t` and the same retrieved byte, not `h_j`. The common head gets `h_t`, direct evidence and the projected value; its additive 256-logit correction is zero at birth, followed by normalization. Missing memory supplies no correction. Fresh undetached values in B, with later losses able to reach the actual earlier writer and host. A need not do useless writes to equalize wall time.
* F/C also file `(private symbol, follower byte, computed value)` at each historical `j>=1`. Distinct address space from literal text, session-scoped; keys are labels, **not** float vectors in a suffix tree. Use the most recent exact private-symbol match in `[lo,t-16]`. At birth the filing prior is 90% point mass on `x[j-1]` plus 10% uniform over 256; the query prior analogously uses `x[t]`. F keeps these distributions. C adds zero-initialized trainable corrections to the log priors using the available host state. Couple draws by seed, document, step and role; no target input. An additional zero-output residual keeps the direct predictor intact initially. Train values pathwise; discrete chosen writes get credit for subsequent scored external bytes, chosen queries for the prediction they affect. Use likelihood-ratio gradients, a detached action-independent baseline, **no straight-through derivative of an exact address**, no querying all unchosen destinations. File and query counts are fixed; price real time and work. Require separate literal vs trace counters and a no-scratch-append invariant. No prose generation required.

## Corpus, dose and analysis freeze

1. Use the existing raw Pile document manifest (`documents.jsonl.gz` SHA-256 `48b9095eeccb023ff1cb2a4f6da899a8b3e4eb3b76b2804e730f1d6ad031c414`). Preserve its document splits. Offset ≥100,600,000,000, length ≥4097, one **4096-target** window per unique full-document SHA. Reject conflicting split IDs/hashes. Exclude X48 training SHAs, all W3 panels and their recursive historical exclusions, any additional known previously seen/reserved evaluation panels (including the XSA survey reservation), all by full-document identity **before selection**. Validate the entire selected document against the receipt before slicing its window. Region separation does not rule out duplicated passages. No W3 confirmation, X48 holdout, or previously scored final is reopened.
2. On metadata alone, sort eligible documents in each native split by SHA256 of ASCII `x49-live-v1:` followed by the lowercase hex document SHA (content SHA then document ID break ties). Use the first **1024 train, 128 calibration, 128 final**. Window start = `4096 * (int(sha[16:32],16) % ((length-1)//4096))`. Source identity, exclusions, selected lists, windows/shift hashes and split disjointness must be privately receipted. Insufficient clean documents = stop, no substitution. C14 checked shifts, one document per sample, no cross-window recurrence/padding loss. Preflight on synthetic or designated TRAIN bytes only. No evaluation-text statistics to design the model.
3. **Three paired training seeds: 4901, 4902, 4903.** Same windows, same seed-specific order across arms (SHA256 of ASCII `x49-order:<seed>:<document SHA>`), no wrapping. One 4096-target document per optimizer update, 1024 updates = 4,194,304 distinct targets per trajectory. Seed replicates are not new document samples. Real recurrent state within the window; if segmented, demonstrate equivalence within declared numeric tolerances **including gradients**, no detached history or optimizer update inside the window. Horizon 4096 for training. Same X48 hybrid Muon grouping (GDN2 option B), new moments, joint norm clip 1, betas (.9,.95), wd .01, peak host/head LR `1e-4/6e-4`, warmup 16, cooldown last 128. No optimizer bake-off or best-seed selection. Use the common X48 host feature bridge. Pin new head widths, groups, sampling/baseline formula, native binary, versions and exact numerical tolerances in the implementation manifest **before any natural learner runs**. If infeasible, amend prospectively in a new version without consuming an evaluation split.
4. Report **nats per real external byte**, all positions, sum of losses divided by target count; lower is better. Distinguish pre-update train, calibration, and final. Freeze and digest all endpoints/controls before the one final evaluation campaign. Calibration for stage checks only; no per-arm fitting, additional LR trials or threshold changes. Evaluate memory horizons **128 / 1024 / 4096** on the exact same targets with the same *full host context*, varying only memory eligibility. Record no-hit mass, age (>128, >1024), keys, reads, writes, trace collisions, peak device/host memory, native/host CPU, prefill, decode, and end-to-end wall. Report age/hit strata as diagnostics, never filter the primary denominator.
5. **Binding intervention**, same weights: preserve addresses, supports, follower bytes, work and current features. Replace only the recalled neural payload, deterministically rotating the eligible past records within the same follower-byte and log2-age bucket at that frontier (position order, one place cyclically; singleton unchanged). For C also break only the trace-key-to-value binding, keeping the literal read intact. Perturb no archived or future value; disclose number actually reassigned. Not a substitute for separately trained A/F. Report per-seed effects and document-paired 95% percentile intervals: resample documents jointly across methods/seeds, 10,000 draws, RNG seed 4900, mean across the three seeds. Do not treat bytes or reused documents as independent replicates.
6. **Match both exposure and wall.** Charge setup, index construction/queries, writes, optimization, checkpointing, and failures (including CPU time); report shared preparation separately and attribute it equally. Save weights-only analysis milestones every 32 updates with inclusive elapsed timestamps; full atomic recovery state privately on fixed cadence. At a pair's common wall budget (minimum of its two full inclusive times, per seed), use each arm's latest complete milestone no later than that budget. Report actual time, slack, targets and selected step; no interpolation or reruns; >5% slack makes this comparison inconclusive. Also report total paid cost including evaluation. Operational run caps, storage/disk check and timeout are required **before launch**; capped arms are partial, no imputed final score.

A nominee earns **only** a separately costed Lux portability/throughput pilot (same-weight and same-update checks, node memory and resident index costs, actual sustained throughput), then a matched larger-dose/host test against A.

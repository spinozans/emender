# Running the frozen U predictor and qualifying X49-V

The [U confirmation](RESULT_SURPRISE_CONFIRMATION.md) applies to three specific W-B weight files and three fixed four-scalar U readouts. [`local_u.load(seed)`](local_u.py) is an opt-in adapter for an **already admitted** inference worker in the retained workspace. It verifies the confirmed aggregate, seed/file association and lease owner, uses the strict W-B loader, and returns a callable. Give it 1–4,096 observed bytes from **one document**; it returns all 256 log scores after each observed byte. Calls start afresh. It does not fit, read corpus text, acquire a device, copy probability tables across models, or run the wrong-record control. This bounded prefill API is not an incremental serving implementation. The CPU fixture compares its score path, including misses, to the original research readout and makes sham search fail if called.

**V's question differs from U's.** [`alternative.fields`](alternative.py) constructs U once with the correct original mark. It really writes a second `uint8` tape by masking the arrived byte in the *previous* forecast row and taking the first maximum. D/V/K are three answers with the same U copy score. They use the current best non-copy, that plus the true old forecast alternative, or that plus the wrong occurrence's alternative. Only K pays for a rotation. No predictor can use the target to select an address or a proposal. `alternative.response` accumulates offsets (including two offsets to the same byte) before a single non-copy normalization; it restores U's exact score for the copy and leaves all misses unchanged. These are 256-way responses, not just conditional losses on a selected subpopulation.

[`alternative_fit.Moments`](alternative_fit.py) accumulates FP64 right sides and Gram blocks on FIT, including the cross-block covariance `p(a) (1[a=b]−p(b))`. Copies and misses contribute zero derivative but **do** count in the all-target denominator. No per-target list survives a document. A positive-definite ridge solve at unchanged U is the only fitting step. On PROBE the target gather follows construction of all four complete predictions. Synthetic dense autograd checks use a separately normalized non-copy softmax; the tests cover ties, collisions, a saturated proposal feature, displacement, future prefix changes, empty hits, a full-length fit and exactly one host prefill.

**Data and admission.** [`alternative_data`](alternative_data.py) reconstructs all metadata through the U confirmation and verifies the next native TRAIN block; the short final contributes to exclusions, not data. [`fit_phase`](fit_phase.py) dispatches only the two named studies. U and V have separate roots, reservations, fit maps, job identities and budgets. A V source guard binds the [spec](FORECAST_ALTERNATIVE.md), U confirmation aggregate and first mechanism gate. The shared raw reader accepts no caller-supplied document or offset: CPU prepare rederives membership then reads FIT only. Before raw PROBE it verifies the active worker/renewing detached owner, frozen plan and byte hashes, complete per-seed FIT journals/systems, coefficients and independent FIT-unit witness. No persistent PROBE byte copy. [`alternative_panel`](alternative_panel.py) pins U's original coefficients in the initial plan; the FIT map covers the nine **new** D/V/K readouts. [`alternative_run`](alternative_run.py) shares the single-use lease loop, not U's authority or exposure. No neural training.

[`alternative_analysis`](alternative_analysis.py) checks role-specific work, support, conditional proposals, all-target sums, unchanged literal geometry across seeds and measured clocks. [`alternative_report`](alternative_report.py) rechecks terminal hashes, solves the nine small FIT systems by Cholesky, rehashes the three actual checkpoints, and independently resamples PROBE by document multiplicities using absolute policy losses.

# X49-W: can a recalled computation improve a *new write* for a still-later prediction?

Prospective, 2026-11-25 UTC, after closing [X49](RESULT.md) and [X49-R](RESULT_RELATIVE.md). No W learning or fresh short-test text seen. B's correctly bound earlier neural value improved prediction; R's learned keys did not beat fixed addressing even after a large credit repair. **Use B, keep literal addresses fixed, and test composition at the writer**, not another routing or optimizer sweep. This is a new local scientific study, not a rerun or amendment to either closed final, and not a Lux scope. Nulls, losses and partials count.

## One capability and its controls

For each seed 4901/4902/4903 start **all** new learners from its own completed v2 **B full-dose host and head** (strict hash/binding); do not select a seed. Reset host and head optimizers for *all* new arms, then run the same complete 1,024-update warmup/main/cooldown schedule on new training documents. These are continuations in weights, not resumption of v2 moments. No new policy/trace symbols, archive, `ENTER`, supervised address or teacher read.

`h_j` is the causal host at observed byte `x[j]`. `b_j=tanh(writer([h_j,embed(x[j])]))` is the unchanged B write. Let the usual prefix-causal literal query at frontier `j` optionally retrieve follower `k` (longest eligible depth 8,4,2,1, at least 16 old, bounded history, exact overlapping follower counts). A later query at `t` retrieves `j` using exactly that same rule. The outer head still receives `h_t`, the actual observed follower `x[j]`, the same direct evidence and one 32-D value. Only the value bound when writing `j` changes:

- **B** uses `b_j`, unchanged trained reader, no extra network.
- **P** (matched local recomputation) and **L** (linked computation) use `v_j=b_j` on an inner miss; on a hit, `v_j=b_j + O(tanh(M([b_j,embed(x[k]),u])))`. `M:80→64`, `O:64→32`, affine. Set `O` weight and bias exactly zero at birth; initialize `M` with PyTorch Linear default and a fresh CPU RNG seeded with `49000 + seed` (matching P/L). P's `u=tanh(writer([h_j,embed(x[k])]))`; L's `u=b_k` from the true earlier row. Each pays for its actual work. Same weights available, dimensions, read schedule, literal bytes and evidence in P/L; no dummy historical value read in P. M/O weights join head Muon and biases AdamW. No other parameter, optimizer or LR change.
- Strictly **one additional hop**. L reads the BASE `b_k`, not recursively linked `v_k`. The inner value can influence the prediction at `t` only via a write `j` actually selected in that window. Ordinary end-to-end NLL gradients reach both real writers and the causal host; no action estimator. Precompute/batch *only* prefix-equivalent observed-byte addresses and same-weight differentiable tensors in the current window. Both hops use H independently at their respective frontier: a composed write can carry information from >H positions before `t`; this is not permission for an unbounded lookup, future bytes, or cross-window state. At H4096 and dose T4096 everything stays in one document window. No padding.

**Interventions.** Full-dose evaluation at memory H128/1024/4096, same full causal host. At H4096 additionally run (i) the original outer payload-only sham for B/P/L, replacing the complete retrieved write at `j` by the eligible rotated donor while leaving direct features, observed follower and chosen address fixed; (ii) for L alone, an **inner-only** sham, where at writer `j` only the `b_k` neural operand is replaced by a donor at the same observed follower byte/log2 age bucket using the original rotation rule *at j*. Keep `b_j`, `x[k]`, outer source `j`, all counts, choices and other inputs identical. Never change both bindings together. Report how many inner writes are modified and how often a modified write is actually consumed, distinct from merely constructing a donor map. Omit untouched shams at common-wall-only endpoints. Inspect address/coverage, double hits and ages, including no-hit losses; no filtering of primary targets.

## New documents, including short ones

Use the same authoritative flagship `documents.jsonl.gz` and source identity, native SHA-based splits, offset ≥100,600,000,000, v2 historical exclusions (including early reconstructed memberships) **plus every v2 reservation and every R reservation**, by full content SHA. Metadata-only supply audit: 39,916 such excluded unique SHAs; 25,491 eligible TRAIN docs ≥4,097 bytes; zero remaining such native final docs. **Do not reopen a spent document, including at another window, or invent a delimiter to extend the manifest.** The legitimate new test population is *shorter whole documents in the native final split*, not long-doc replication. 1,040 eligible documents of 2–4,096 bytes, covering 1,565,002 shifted targets in total, remain under these exclusions. No inference from source region to a shuffled Pile average; repeated passages can survive full-document deduplication.

On metadata only, choose 1,024 fresh ≥4,097-byte TRAIN documents by the existing v2 `x49-live-v1:` SHA rank among the remaining pool, same aligned start rule and seed-specific `x49-order:<seed>:<sha>` permutation; each new arm gets exactly these 4,194,304 raw targets. Keep a private TRAIN-only shift-verified stream; no unregistered substitution or overlap. For the new test, deduplicate content (earliest eligible source descriptor), rank all 1,040 by SHA256 of ASCII `x49-w-short-v1:` + full document SHA, with SHA/offset tie breaks. Take the shortest **prefix of that fixed rank** whose sum of `(byte_length−1)` reaches **561,152 targets** (the size of the R board); include the last document in full. This is a sample-size rule, not a nats threshold or a rank by document length. All documents/bytes at ranks beyond it remain unspent. No calibration stage or sweep. Report by length as a diagnostic, especially whether any two-hop lookup is possible. Entirely new native test; no test payload before all full-dose and actual common-wall endpoints are durably hashed/frozen.

**Scoring.** One document per independent prefill and memory namespace. For length `n+1` (1≤n≤4095), predict from real inputs `raw[:-1]`, score exactly `raw[1:]`. Document ends supply no extra structural target. Refuse missing/foreign hashes, skipped tails, padding, concatenation and model state transfer. Primary loss is **total NLL / total real external targets**, NOT an unweighted mean of document means. For all contrasts resample the N frozen documents jointly with replacement, `numpy.random.default_rng(4905).integers(0,N,size=(10000,N))`; in each draw sum paired NLL differences and divide by **that draw's total target count**, then average the three seeds, linear-percentile 95% CI. Mean at full dose, per seed, intervals, H4096 vs H128 interaction, and common-wall H4096 for L:P, L:B and P:B. Positive = control minus candidate. Report intervention wrong-minus-correct. Full-dose H4096 L:P isolates where the inner computation comes from; L:B asks whether it beats the practical baseline. An L that only beats B but not P does not establish a second-hop neural benefit. A positive inner-sham effect alone is not a win over trained controls. No new minimum gain rule. Separate sensitivity, practical choice and scale claims.

For each seed in order train B, P, L. Atomically bind and time weights every 32 steps, full weights+both optimizers every 128 (including 1,024). Per pair/seed choose latest complete milestone within min inclusive full wall, report targets and slack (>5% resolution inconclusive), no interpolation. Attribute actual common TRAIN preparation equally to nine new trajectories; all share the same previously paid seed-specific B origin. One separate final lease, score full-dose models on all registered cells, deduplicate additional common-wall predictors for correct H4096 (up to 18 distinct weight endpoints total).

[`correction_transfer_reader.contract`](correction_transfer_reader.py) binds seven readouts per weight to PC's audited result, PC's seal from before PROBE, its FIT identity and the earlier EH/ET anchors. SWAP and PREFIX take PAIR's exact coefficients. The public code and aggregate receipts do not include the fitted arrays.

[`correction_prefix.distribution`](correction_prefix.py) records each sufficiently old mistaken arrival **once**, without its literal key. On a query with earlier matching mistakes, it looks up the current guessed byte among the local alternatives supplied by ERROR. In the prefix counts it temporarily discounts the selected key's most recent eligible mistake, if any; J already uses that occurrence. It does not discount it for future queries or remove the older local evidence. If all the relevant prefix and local association rates agree, PREFIX should return the same answer as PAIR, even when exchanged pairs would give a different answer. A single table is not a guarantee of lower wall time or even fewer occupied cells on every input.

[`correction_transfer_score`](correction_transfer_score.py) builds the host/J/ERROR scores and marginal-count snapshot once. MARG, PAIR and PREFIX each pay for a fresh marginal feature assembly and the full normalized 256-byte answer. Only PAIR builds local pair tables; only PREFIX builds its prefix table. The six branch orders rotate as registered. Outside their clocks a separate diagnostic pass obtains both switched answers, the other anchors and comparisons of the queried distributions. Only then are labels gathered. No new symbols, cached host responses across weights or cross-document state.

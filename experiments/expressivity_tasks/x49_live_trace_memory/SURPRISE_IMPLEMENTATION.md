# X49-U implementation and first mark gate

[Registration](PAST_SURPRISE.md), public `514f475e7675cac8c67cd5d94e7c43c9121fec6d`. The learned part here is three or four **scalar copy-odds coefficients** per readout/seed, not another neural host or a changed address. B's 32-D value comes from its actual latest literal hit even in S. Only the new byte is displaced in S. The probe is out of the scalar fit, **within the native TRAIN split**.

## What the first gate verified

At `3c3e1226cd0956c74fa0ed7ac1d754436a3f8896`, all 22 mark, prior address and compact tests passed (7.91 s). The separate real XSA literal check matched 654 synthetic frontier/horizon answers (248 hits, 406 misses; four sessions closed). No U reservation, natural score, fitted natural coefficient, or lease in this gate.

- [`surprise.py`](surprise.py) requests an **output-only** record of the routes the B head actually used; it cannot pass addresses to B. The writer quantizes the log loss under the preceding bare host forecast *once the observed byte arrives*, stores actual `uint8` with a reserved first slot, and reads only one selected code per U or S hit. N normalizes the current host only on its literal hits; U and S can share those same-row normalizers, computing the missing ones needed to encode every prior forecast. Slots, neural values and observed bytes remain separate.
- [`surprise_fit.py`](surprise_fit.py) accumulates small FP64 moments in document order and solves once per readout. Only FIT sufficient statistics and small document aggregates persist. The 255-way complement in the copy log odds is reduced directly rather than obtained by subtracting a rounded probability from one. On PROBE every alternative finishes producing scores before the target gather. [`test_surprise.py`](test_surprise.py) checks independent scalar routes, old-versus-current forecast indexing, reset, unchanged neural binding, all 256 scores/mass, real shifts and a dense-softmax autograd gradient/Hessian witness at zero. A fitted scalar's sign or magnitude is not itself a predictive result.

## Lifecycle gates

[`surprise_data.py`](surprise_data.py) reconstructs the chain through Q using **metadata only**, then ranks a single FIT+PROBE reservation. The preparation role can open only FIT. The worker must rebind every checkpoint file and the prepared identity before consuming FIT; the raw PROBE reader separately checks a live worker license, the initial freeze, terminal FIT progress, an independent FIT-boundary observation, and the complete fitted readout hash before source access. The private PROBE extraction retains the shift hashes but no on-disk raw probe copy.

[`surprise_panel.py`](surprise_panel.py) binds the map of separate FIT receipts, including moments, coefficient vectors, hashes of the per-document FIT journals, source and weights. [`surprise_run.py`](surprise_run.py) constructs fresh frozen models from the appropriate checkpoint for each seed/role, never handing model features to a different weight or document. It discards each FIT document packet, freezes all three fits, then reads only the bound coefficients for PROBE. All 1,152 units count real 4K windows; FIT uses targets to accumulate derivatives and is not reported as an out-of-fit NLL. The lease covers both phases, not two acquisitions.

[`surprise_analysis.py`](surprise_analysis.py) consumes completed journals, never corpus text. It checks the fitter's actual dose, clock, mark work, positive release, signed all-byte contrasts and paired document bootstrap. [`test_surprise_pipeline.py`](test_surprise_pipeline.py) exercises these boundaries with invented, hash-checked binary documents and small CPU predictors. Full source qualification also checks the strict real checkpoint loads against Q's logical host/head digests. Do not infer model quality from a synthetic or infrastructure gate.

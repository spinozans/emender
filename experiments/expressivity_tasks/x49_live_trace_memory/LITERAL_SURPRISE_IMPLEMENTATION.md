# X49-LS implementation and access boundary

[Protocol](LITERAL_SURPRISE.md) · [confirmed neural mark](RESULT_SURPRISE_CONFIRMATION.md). LS compares two *writers*, not a text-only language model with GDN2. All predictors still use the same frozen neural host and B read path.

[`LiteralHistory`](literal_mark.py) keeps order-zero byte counts, one table keyed by 1/2/4/8-byte suffixes, and at most eight recent literal bytes. Each occupied table row has a total and a dictionary of follower multiplicities. `observe(b)` looks up the old rows, computes the one component of the interpolated distribution needed for this arrival, quantizes it, **then** updates rows and the suffix. An unseen context contributes no interpolation weight. A fresh history and real `uint8` tape are constructed on each window. This implementation counts logical operations/entries, not Python allocator bytes. The order-zero and context dictionaries are in addition to the one-byte tape; time for their construction is charged even though the natural design shares the tape among sibling readouts.

The LS field builder calls B/U's registered address and mark path once. It reads only the **correct** literal code for the original `j`. J and S share that code; S alone uses the wrong neural mark. N/T/H/J/S independently fit 3/4/4/5/5 scalars, U uses its original unchanged four. The [fit code](literal_mark_fit.py) checks the nested current-field moments in every system and the full T block in both joint systems. Every PROBE response preserves non-copy relative odds and has all 256 scores before any target gather. One causal prefill per seed/document; no raw targets enter a feature, and no tape or feature survives to another weight or document.

[Data](literal_mark_data.py) reconstructs the spent V membership from metadata, verifies V's aggregate and prepared identities, and checks that LS takes the next contiguous native TRAIN rank after **both** V roles. [Admission](literal_mark_panel.py) and the [runner](literal_mark_run.py) select LS's own job, authority, reservation and frozen U bases via closed dispatch. They do not inherit V's lease or read permission. CPU preparation rederives the reservation before opening FIT. The raw PROBE reader is available only to the live licensed worker after the fit identity, all fifteen solves, journals and the independent all-seed FIT witness match. No persistent PROBE window file. A partial cannot trigger reacquisition.

[Analysis](literal_mark_analysis.py) reports pooled, hit-weighted Pearson correlations using exact integer sums, checks Cauchy–Schwarz and byte-code bounds, and distinguishes total table construction over windows from maximum entries in any one window. Text-only counts/sums must match across seeds even though the neural marks need not. The [publication audit](literal_mark_report.py) independently solves all systems, reproduces each paired comparison from absolute document losses and sample multiplicities, rehashes the three real model files, and rechecks correlations by pooling within-document moments around the common means in decimal arithmetic. No text or model execution is needed for closure.

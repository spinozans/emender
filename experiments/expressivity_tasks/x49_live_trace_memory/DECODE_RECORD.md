# X49-DR: can two small notes stand in for the old neural vector?

Prospective, 2026-11-25 UTC, **before** DR membership, text, decoder fitting or scores. [JT](RESULT_JOINT_TRANSFER.md) showed a small repeatable gain from retaining both what the model and what local counts had expected at an earlier occurrence. But both JT readers still used B's **32-component FP32 vector stored at every input**. The notes were additions, not replacements. The engineering question now is materially different: can a reader reconstruct a useful value from the follower and the two notes it already has, without storing or reading that historical vector at all? This is not a sweep over quantizers or another final on the same model.

### One fixed teacher and one fixed decoder per checkpoint

Use the actual three W-B checkpoints and their corresponding U and J coefficients bound by the [JT aggregate](receipts/joint_transfer_result.json), SHA `62db2e0beb85bee456b1fea2005d98b4f5684f6d41f493841ac3fc499b9a24d6`. Bind the [LS result](receipts/literal_surprise_result.json), SHA `4e2789566883cbaf11131919bfa72781f0ac0c0d74a0c58289caea2728fe99a2`, and qualified native literal writer receipt `25389c636ec9524888bf63f0a8301abaab449ba45aa6e4b427f0474bfc660c0c`. No neural weight updates or refits of the trust corrections.

At each **observed input** `j>=1` of each new FIT window, teacher value `v_j=tanh(writer([h_j,E(x[j])]))` is B's actual 32-D CPU FP32 computation *after* observing the byte, with frozen same-weight causal host features. Let `c=x[j]` and `a=(literal_arrival_code[j], neural_arrival_code[j])/64` in that order, both codes exactly as in LS. Both notes are written from the preceding forecasts when `x[j]` arrives. Accumulate by `c` counts, sums of `a` and `v`, `aaᵀ` and `avᵀ` in FP64. All 4,095 eligible writes per 4,096-input window get equal weight, **whether or not they will be read**. Slot 0 is never an eligible value address and does not enter the fit. No next-target loss, lookahead, future hit sampling, NLL optimization or choosing a decoder by PROBE. One shared host prefill per seed/document.

For each observed byte cell, `m_c=mean(v|c)`, `b_c=mean(a|c)`. From the cell means of centered products solve once `K_c=(Cov(a,a|c)+I/4096)^{-1} Cov(a,v|c)` (population denominator `count[c]`, not `count-1`); symmetrize the 2×2 covariance before the solve. The intercept is not shrunk. For absent cells, `m_c` is the global mean of teacher values over all FIT writes at that weight, `b_c=0`, `K_c=0`. Serialize `m[256,32]`, `b[256,2]` and `K[256,2,32]` once to **FP32**; seal their hashes with the counts, sufficient statistics, seed, actual weight and FIT identities. Counts/moments are private audit material, not deployed tables. Decode in FP32, `clip(m_c + (a0-b_c0)*K_c[0] + (a1-b_c1)*K_c[1], -1, 1)`, adding terms in that order. Fixed rule even on a singular (pre-ridge) or one-write cell. No other features, projections, learned codes or target-specific value stores.

### What changes on a read

Latest B address at H4096: longest usable 8/4/2/1-byte suffix, B's delay, same follower `c`, counts, age, direct evidence and current hidden row for every branch. At a hit only the *payload supplied to the existing B answer head* varies. Compute that branch's own raw 256-way scores, copy margin and current confidence **after** substituting its payload. Giving a compact branch the full-vector B scores/confidence would leak the very record it's meant to eliminate. Every J correction always uses the **true** pair of old trust notes and that weight's frozen J coefficients. Preserve non-copy relative odds and all misses. No scratch symbols, future bytes, externally supplied addresses or neural reads at unchosen destinations.

| Reader | Value at B's address | Copy-odds correction |
|---|---|---|
| B | true historical `v_j` | none |
| U | same full vector | original U, true neural note |
| J | same full vector | original J, both true notes |
| P | byte prototype `m_c` | fixed J on P's own raw scores |
| D | decode from `c` and its two **correct** notes at `j` | fixed J on D's own raw scores |
| S | same decoder but use the **paired notes together** from the U/LS matched wrong occurrence `k` (same follower and log-age bin; singleton stays) | fixed J on S's own raw scores, with **both true trust notes at `j`** |

P/D/S store no historical value vectors. S is a binding intervention on the decoder inputs only, **not** a separately fitted rival. Compare only selected records; the sham is an audit cost, not a deployed expense. In the full comparison the B/U/J sibling legitimately makes B's full value table once. Separately prove that D **alone** computes its full answers on observed bytes with the historical value writer disabled (even on hits), no sham or teacher scores. Reproduce the original B/U/J answers against their reference programs at all 256 bytes on invented streams; verify exact source/rotation/fallback assignments, binary overlaps, reset, sparse/constant FIT cells, independent dense ridge fits and coefficient casting. Report explicitly if full path numerical parity needs more than FP32 rounding tolerance; no changing the model to win.

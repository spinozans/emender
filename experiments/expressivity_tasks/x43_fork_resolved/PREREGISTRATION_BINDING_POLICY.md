# First trained positional policy: constrained feasibility, not program discovery

Native locate/byte trace gate first. Then use one small eager X45 MatrixBlock as a three-way handle selector. Interpreter supplies three query anchors in permuted order (no semantic tag/slot identities to network), current positional range, and per-handle occurrence counts within that range. Two scope instructions then one payload read; policy selects the handle at each instruction. Invalid choices (non-singleton anchors) abstain. The interpreter owns range semantics, label width, payload offset, and register lifetime. Network does not get target positions, gold ops, example IDs or value bytes as features. Train from exact marginal probability of the final correct byte across legal executions, with uniform byte prediction for abstention. Enumerate all legal paths on training examples only. Three steps are a supplied skeleton, not induced control flow. Singletons may uniquely determine success: explicitly compare deterministic unique-first; no claim of beating this baseline or needing a neural memory.

Seed 3401, CPU AdamW 0.003, 200 minibatches of 16 examples sampled with replacement; training fixtures seeds 1000..1063 (both twins, 4x2x3). Final seeds 2000..2031 both twins 4x2x3, and 3000..3031 both twins 8x4x4. No tuning. Freeze checkpoint before both tests. Greedy live inference; count invalid programs as incorrect. Pair passes only if both different answers are correct. Compare unique-first and a no-coordinate control (same selected field occurrence count, read the next occurrence cyclically in the history instead of the selected occurrence). Report training loss, pairs and operation counts. Capability only: matched success on >=90% of pairs in each size plus collapse under coordinate reassignment; failure reported unchanged. Separate from natural LM and full K15.

# Multi-anchor positional reads on ordinary next-byte prediction

The controlled natural-text test in `PREREGISTRATION_NATURAL_POSITIONAL.md` passed its two quality gates. This is the small trained byte predictor + a new trained mixture head, not K15, not program discovery. No task labels or document grammar. The two projected historical anchor gaps select candidate suffix occurrences whose earlier word was in approximately the right place. The action reads its continuation frequencies at those coordinates. Restricting, for example, an occurrence of `the` to cases preceded by the same earlier word can change what the predictor expects *after* `the`.

One CPU training seed, 32768 target bytes in 128 documents; calibration 32 documents; fresh test 16384 targets in 64 different documents not in the previous final-test set. Same target offsets, frozen local predictor and optimizer budget for restricted and full heads. Test NLL (nats/byte):

| Method | NLL |
|---|---:|
| Local only | 2.68156 |
| Best fixed expert (3-byte pooled suffix) | 2.08243 |
| Trained router, local and pooled suffix evidence only | 2.00916 |
| **Trained router, also allowed positional reads** | **2.00088** |
| Same full router, payloads shifted among suffix addresses | 2.02803 |

The incremental positional gain was 0.00828 (95% paired by-document interval 0.00500–0.01163). The coordinate intervention cost 0.02715 (0.02213–0.03238) without changing pooled counts or positional supports. 4542/16384 targets had any nonempty positional read; 2981 had a nonempty histogram different from pooled. The remaining positions are included in all scores. The older-word expert had mean mixture weight 0.028; a mixture weight alone is not evidence of usefulness. Every locate, byte and branch answer was audited against an independent prefix scan. A fresh-session first-test-document replay after loading the weights reproduced target probabilities exactly.

**Limits:** short windows; the two most recent ASCII word fragments are a heuristic. No learned anchor creation, free program, recurrent decision state, MEM operation, conditional execution or indefinite-length serving guarantee. All experts are computed before mixing. On test that meant 48759 locate calls, 94368 byte reads and 16384 branch calls for 16384 predictions. Cap overflow is an explicit refusal. A future policy should choose reads before paying for them. Do not compare absolute scores to other target sets.

Small trained weight bundle and ordered manifest in `receipts/natural_position_v1/`; frozen local base in `receipts/xsa_controller_v1/`. Demo from repository root with the hash-bound SXGC debug executable:

```bash
D=experiments/expressivity_tasks/x43_fork_resolved
OMP_NUM_THREADS=4 .venv/bin/python -m experiments.expressivity_tasks.x43_fork_resolved.xsa_position_predict \
  /home/erikg/sxgc/xsa/target/debug/xsa "$D/receipts/natural_position_v1" /path/to/raw-document --steps 8
```

Single persistent session and one logically open document: predict, append generated byte, predict again. The demo returns raw generated bytes as hex. Seed prefix must contain >=16 bytes.

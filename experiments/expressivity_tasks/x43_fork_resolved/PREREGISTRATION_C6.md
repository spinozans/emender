# C6 frozen execution protocol

Registered 2026-11-02 before training or evaluation. Prediction: Emender final-test fork-aware standalone overall NLL is strictly below transformer; equality or positive Emender-minus-transformer delta refutes. Primary standalone is the two-system distribution: deterministic corpus-label forced walk, normalized learned decision distribution at forks. Secondary decisive fork-role comparison uses fork NLL. Report fusion separately; do not select a winning definition after evaluation.

Scope: C3-comparable **corpus-label diagnostic**, not a causal train-index experiment. Maximal contexts and forced/fork labels are the receipted corpus-wide direct-SA decomposition. Train-prefix counts filter occurrences to positions < floor(.9*n). The history selector and forced labels still depend on held-out corpus structure; training branch features contain the training targets. No causal generalization or deployable walk claim is permitted. A causal training-only context selector is deferred and must be reported as an unmet broader ledger requirement.

True bytes are consumed at every position, including forced positions. At input index j the conditioning and target mask belong to target j+1. Dense heads reset every 128 bytes at held-out split; random 128-input windows train with batch 16. Train fork loss is sum of per-target NLL over forks / number of forks in that batch; forced losses have zero weight. Controls use all targets and zero conditioning. Same seed 4301, AdamW lr .0003, decay .01, grad clip 1, 180 seconds per arm, optimizer-step loop includes first kernel compilation; no warm-up optimizer steps. Initialization, index preparation and evaluation are timed separately. All models receive actual current input bytes; no target byte is given to their neural stream.

Conditioning: 256 binary supported-byte indicators, explicit empty-support/OOD indicator, log1p(total train interval count), log1p(distinct branches), natural-log count entropy. One shared-form learned linear 260-to-256 projection adds to byte embeddings before each head's sequence layers. Output has 257 logits: supported byte logits plus one OOD logit. Normalize only supported byte logits and OOD. Distribute OOD mass uniformly over the unsupported bytes; when all 256 supported, disable OOD. Empty support produces a uniform byte distribution (explicit abstention). This intentionally restrictive OOD choice is fixed before execution. Neural-only controls use ordinary 256-way softmax, with conditioning module present but unused. Match trainable parameters within 5% where practical; report actual counts and GDN mismatch if any. Attempt fla 0.5.1 GatedDeltaNet byte head; record import/runtime failures without substituting a different head.

Held-out targets are split exactly as C3: 55,769 calibration then 55,770 final test. No gradient updates on either. Save only target probabilities and confidence on held-out data, plus receipts, never commit .pt. Gate: C3 learned logistic feature mixture on train-prefix counts; intercept, neural max probability, log1p(corpus selected context length), log1p(branch count); standardize non-intercept features on nonempty calibration forks; L-BFGS-B [-20,20], maxiter 1000, ftol 1e-12. Empty support abstains, forced walk uses corpus-label byte with probability one. Freeze gate coefficients to disk with SHA256 before final-test scoring. Standalone, fusion, retrained controls, and C3 numbers all reported. Report overall/fork/forced/covered/unsupported/zero-target NLL and denominators, retaining zero-target cases. No significance claim from one seed.

Hash binding: execution refuses unless PROGRAM.md embeds this protocol's SHA256; training receipt records protocol and executable SHA256. Final scoring refuses unless calibration gate artifact has been saved and its hash recorded. No outcomes existed at registration.

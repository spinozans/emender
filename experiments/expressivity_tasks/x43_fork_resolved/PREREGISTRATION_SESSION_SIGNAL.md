# Local XSA evidence pilot: fixed predictors, no neural claim

CPU-only calibration instrument, before looking at the scores. Does the live index supply predictive evidence outside a short history? First 32 distinct calibration documents in flagship-manifest order with >=2049 bytes; verify full document hash, use only first 2049 bytes (one checked window per document). Use bytes 256..2047 as scored targets (zero-based). Reset session between documents. No final-test access, external corpus or training. No selection on match success.

Shared bounded base q: smoothed unigram from preceding 256 bytes, add 1/256 count per byte (one total pseudocount). Off = q. For both on arms use one 8-byte suffix and the same fixed rule: P(b)=(hist[b]+q(b))/(support+1). Short = counts restricted to the preceding 256 bytes. Full = actual XSA session branch reply over all visible bytes in this window. Append the true target only after scoring it. Seal at 512-byte intervals. Positive short-minus-full NLL means the longer index helped beyond the matched short lookup. Also score a negative control rotating full histogram labels by one byte. Report paired mean differences, per-document wins, support and byte accuracy; not a trained controller, no significance threshold or second-stage selection. A negative or small gain is retained. A positive result earns testing the same evidence on frozen LM logits, not assuming it will beat the LM. Do not compare absolute pilot scores to banked neural NLLs.

# Unattended CPU campaign: pay only for selected reads

This is an eight-hour maximum unattended allocation, not a requirement to burn eight hours. No GPU, Slurm, board runs or changes to previous checkpoints. Stop on integrity failure, deadline, or completion of all listed cells. Keep per-document atomic feature shards locally; retain binary/source/target/checkpoint hashes. Multiple seed/horizon cells run in series, not workers.

Question: can a policy trained on next-byte outcomes buy comparable prediction quality with fewer synchronous read calls than the always-read natural_position_v1? Start each decision with local logits and one depth-3 branch histogram. Available moves: stop, buy depth-8, or refine by any of up to eight distinct earlier word fragments from the preceding 192 bytes (no permanently assigned semantic slots). Rank candidate anchors with one shared key encoder using pre-read features only (rank, length, gap, coarse spelling); stop/depth8 have dedicated type features. Refining uses ranged locate of suffix and chosen anchor, positional gap join (tolerance 4), then byte reads ONLY for surviving occurrences. Hard choose one move before fetching its answer. Mandatory depth3 is disclosed. No learned arbitrary-depth loops in this slice. Same frozen local predictor as v1.

Use the existing flagship manifest; verify complete document hashes. For the 2048 and 8192 byte horizons independently take first 512 eligible train, 64 calibration and 128 final_test docs (length >= horizon+1), in manifest order, excluding all previously used final-test hashes/IDs from new evaluation and calibration/training. Exclude overlap within and across splits; disclose overlap across horizon studies (not independent replications). Targets: last 1792 bytes of each horizon at stride 7 starting at horizon-1792; score identical bytes for all methods at that horizon. Fresh session per document, starts with actual prefix. Score 256 positions regardless of support. No output-based exclusions. Hard-fail cap overflow. Materialization for training and calibration may compute counterfactual actions; report such work separately. Before final results live replay the chosen path only and verify predicted probability/call count vs counterfactuals on at least one complete held-out document per cell. Independent direct scan checks every training/evaluation candidate's positions and continuation counts.

Two-stage training: a shared post-read 3-way probability mixer over local, mandatory and selected expert (action-specific masking, use (q+h)/(1+support)); trained by equally weighted available-action NLL. A shared pre-read value net regresses realized NLL improvement vs stop and incremental read calls. Calibrate price among 0,.002,.01,.04 nats/call by minimum calibration NLL among policies no more expensive than v1; report each price. CPU AdamW .002, batch 256, 8 epochs per stage, seeds 3401,3402. Compare v1 as-is, stop-only, best fixed move type/rank on calibration (missing defaults to stop); oracle ex-post ceiling is descriptive only. Quality/cost clause per cell: paired by-document upper 95% bootstrap endpoint (10000 resamples seed 3401) for selected minus v1 NLL <= .01 AND mean calls <= 0.75 * v1; strict gain requires upper endpoint <0. Report nulls. Calls are not latency: time actual deployment path separately, not counterfactual feature building. Deterministic report, then exit; no tuning on held-out results.

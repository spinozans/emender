# Train a first live-XSA read controller (distinct from the frozen K15/GDN2 study)

Before training: first 128 eligible flagship train documents and first 64 eligible final_test in manifest order (>=2049 bytes); fail on train/test ID or content overlap. No calibration or final-test model selection. Use the same first 2049 bytes and score positions 256..2047; verify source document hashes and final target digest against neural evidence manifest. Reset all context at each document. Training replies come from the actual depth-8 session protocol, oracle-checked and cached solely to batch backprop. Append after read. Query suffix length is fixed, not a learned address.

CPU feasibility pilot, seed 3401: embedding(256,16), preceding 16 embeddings flattened to 96 GELU units, 256-way local distribution q. Train the local net and a sigmoid gate jointly by next-byte NLL: with nonempty histogram, mix q with the normalized branch histogram; gate inputs are local hidden features, log(1+support), max branch fraction and local probability assigned to the histogram. Empty reply uses q exactly. Gate output initialized at 1/2. Compare matched local-only and constant 1/2 mixture trained independently from identical local initialization. All use AdamW 0.002, batch 512, 3 epochs, same shuffle; no early stopping. Also compare a best global scalar mixture on the **learned controller's frozen local logits**, selected by training NLL among 0,0.05,...,0.95. No model tuning on held-out scores.

Report final NLL (nats/byte), byte accuracy, gate distribution on supported rows, final-test document-paired bootstrap (seed 3401, 10000 resamples). Evidence-use claim requires lower NLL than both masked and rotated answers; conditional gating advantage requires positive lower paired 95% bound against train-selected scalar. Separately report vs local-only and independently trained fixed-gate arm. Verify checkpoint reload and one full held-out document through the real append/branch CLI reproducing cached scores. No inference about large-model competitiveness, learned query addresses, allocation or multi-cycle working memory.

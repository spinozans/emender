# First neural XSA comparison: fixed read, two frozen predictors

Freeze before any neural arm. Question: does an actual full-history branch reply improve next-byte prediction once the base already knows how to predict text? This tests attaching evidence at output, **not** learning a query program, a writable-memory intervention, or a claim to be a final architecture.

* Models: exact seed-3401 corrected K15 composition and corrected GDN2 speedrun checkpoint after constant-180 + 24 cooldown. Evaluation mode, no optimizer updates. Use the banked reproduction recipes, not a similarly named .pt file. Source entrypoint SHA-256 `e769a26157ca3da36569258289476f0c1e74e9b2e33e3d187e8b185076349d2c` (k15_probe_composition.py) and `2610942b448416d7365474130f1dc3e17056295b0defbe775b8128518a53b8b9` (protocol_correction.py). Hash the resulting weights before arm scoring. Require original cal endpoints **1.3811104467936925** and **1.3521734476089478** exactly under original evaluation; abort on mismatch. The K15 run directory contains metrics, not the final snapshot; if replay is needed retain the atomic artifact, not just a score.
* Data: take first 64 distinct final_test documents in registered flagship order with >=2049 bytes, first 2049 bytes only. Bind IDs, source offsets, document SHA-256 and ordered target digest before inference; reject overlap by ID or digest with calibration pilot. Score all targets at positions 256..2047; no success filter. Reset neural state every nonoverlapping 256-input block from position zero; each input predicts the following byte. Long reference uses one 2048-input forward per document. Identical target offsets across methods. Index resets every document, not every neural block. Never append target until after query.
* Both models get the same single depth-8 branch reply (release binary SHA `fdf5f97cb23d35e427161b60f9d7be47f5eeed6fd0bbf1a4bf4b81dbb6c0f1f0`), same interpolation, same causal budget. Let q be frozen local softmax, p=(q+lambda*h)/(1+lambda*sum(h)). Choose lambda separately per model by lowest **calibration** mean NLL on signal pilot IDs among {0,1/16,1/4,1,4}; ties choose smaller. No final-test tuning. Report short-neural off, on, restricted-to-previous-256 histogram, cyclically shifted histogram, long-neural off and preregistered fixed-unigram full-index predictor. Off and zero-hist must reproduce q. Build one immutable causal evidence file per split; audit all branch rows against independent overlapping in-document enumeration before consuming. Output timing excludes evidence-cache precomputation only if identified as offline scoring; separately measure actual serial append/query/decode.
* Primary gain = short off minus full on, mean nats per target. For each base independently require positive gain, superiority to restricted and rotated controls, and positive lower endpoint of paired by-document percentile bootstrap 95% CI (10,000 resamples, seed 3401) for off minus on. Failure is no demonstrated indexed gain for that base; no averaging failed arms away. Report long off vs short on gap without making superiority a gate. No claim about either new trainable connections or matched 2700 s. If both benefit, learn a read gate next; if neither benefits, inspect support-conditioned calibration before proposing new training.

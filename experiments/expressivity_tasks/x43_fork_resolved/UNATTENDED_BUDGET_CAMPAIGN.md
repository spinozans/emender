Check process identity as well as file timestamps; a stale progress file is not evidence of liveness. `archive.log` records the small per-cell artifact commits and live remote verification or an archival failure. Neither the experiment nor archiving requires the chat session. Single CPU experiment process, at most one native session at a time, no GPU lease. `timeout` enforces a hard wall-clock bound even inside a hung RPC. No self-modifying agent, scheduling service, unbounded retries or auto-retuning. Host reboot is not covered. Fatal errors stop the chain rather than manufacture substitute results.

The runner atomically writes a document shard and its digest before marking it complete. On restart it rechecks those digests. A completed training stage writes weights atomically and checks the digest on reuse. An interrupted uncheckpointed training stage repeats from the registered seed. `xsa_budget_launch.py ROOT --resume` refuses a live original session leader or an expired allocation. Use only after inspecting the failure; the original source bindings and deadline still apply. `xsa_budget_publish.py ROOT --detach` can separately restart the bounded archiver if needed after verifying no live publisher. Shards remain under ROOT; only the policies, small manifests and receipts are staged in git. No raw corpus or large replay checkpoint publication.

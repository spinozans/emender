# Co-trained token-host / archive-reader pilot (Triton window 1)

## Question and scope

Does a token LM learn a useful recurrent read of retrieved natural passages when *both sides train from the beginning*? Does applying the selected passages to a copy of its live memory improve on a blank start or a generic live-state path? Compare GDN‑2 and nonlinear Emender E97 split-edit **cores**, including crosses and a fixed-total-width two-reader mix. These small models are freshly initialized token LMs, not head transplants into production checkpoints. Test document continuation, not QA or a universal architecture ranking. No frozen-host win is required. No hardware/compiler result substitutes for a language comparison.

## The search and the target

- The immutable BUILD archive contains consecutive document-local pages of ≤32 native tokens, deduplicated by their whole token sequence. Index presence of token 1-, 2- and 3-grams *within each page*. Codes are collision-free for p50k. Each occurrence of a query gram votes for every distinct page containing it; vote = width × (1 + floor(256 ln((1+number of pages)/(1+document frequency in pages)))). Repeated query grams can vote repeatedly. Return up to four **positive** page scores in descending order, ties by ascending BUILD page ordinal. A miss supplies no hint. No PROBE/FIT text enters BUILD. CPU builds the immutable sorted postings once; Triton does batched search, integer voting, deterministic top-k and masked fetch. Cache only immutable candidate IDs and lexical scores per actual prefix across training updates. Re-encode true selected spans at current weights. Measure the search cost rather than charging a cached training address as a free online read.
- Tile each 4,097-byte-derived token sequence on the **target** axis into consecutive 64-target windows (stride 64, last may be shorter); the next window can begin on the previous window's last real token, but no hidden state crosses windows or documents. Count every real shifted token of the chosen sequence once on evaluation. Only actual input tokens 0…15 choose candidates at position 15. Neural score is log lexical mass plus a learned dot product of lower-host state and masked passage key. No targets or any other live suffix enter addressing. Padded targets are masked, padded recurrence steps cannot write memory. Before position 15 there is no hint. Starting at 15, use the one lookup to answer multiple queries from the evolving causal host; no per-token hidden search. Input is an observed token stream, not online byte segmentation.
- Whole-document SHA disjointness and deduplicating archive pages do **not** prove passage novelty. Record all positions, eligible positions, supported eligible positions and, as a diagnostic, supported eligible positions where ≥8 eligible targets exist and their first eight are **not** contiguous in the returned pages. Make that last flag only for scoring, never an input. It is not a full near-duplicate audit. No claim of passage-deduplicated generalization.

## Architecture and matched trials

Both host families: native p50k vocabulary and tied embeddings, residual width 128, two trainable recurrent/MLP blocks, four 16×16 heads. The lower block sees only real inputs; save its post-token-15 state. A headwise learned left/right projection supplies a common seed for its candidate passages. The upper block receives the gated hint as part of the live representation. The archive controls depend only on the current passage (embedding plus one-token left context reset at each page). The same candidate set is used across arms, but the learned softmax weights may differ between fits. GDN‑2 decays before erasing. E97 uses a scalar head decay, erases from incoming state and applies tanh after each update; its seeded residual is **not** an affine map. No extrapolation from this core to an entire deployed model.

Each host independently trains LOCAL (eligible live seed only, same support and gate), G-STATE, G-NEUTRAL, G-EFFECT, E-STATE, E-NEUTRAL, E-EFFECT and MIX-EFFECT. STATE reads `F(0)`, NEUTRAL reads `F(0)+S` only on support, EFFECT reads `F(S)`. For the mix split the four head slots 2+2; keep separate projected/gated channels. Don't add incompatible states across reader families. All weights needed by each arm are trainable from the first real update. No frozen passage values. LOCAL does not pretend to evaluate the absent archive encoder. Matched geometry isn't equal compute. Literal text conditioning, semantic proposal learning and related pretrained checkpoints are separate questions, not run here.

Three paired seeds 5411/5412/5413, same initialization and shuffled window stream within seed, rotated cell order. 2 hosts × 8 readers/controls × 3 seeds = 48 fits. Shared batch and number of optimizer updates. BF16 autocast for projections, FP32 recurrent math/saved states, FP32 master weights, full-vocabulary exact softmax (vocabulary padding rows excluded), fused AdamW `.0005`, betas `.9/.98`, decay `.01`, grad norm clip 1, linear warmup for first 1/32 of dose then cosine to 10% of peak. Full CUDA graph replay includes loss/backward/clip/optimizer; invented warm/capture iterations are reset, never counted as natural exposure. Training samples reshuffle all FIT windows per epoch, without replacement inside the epoch. Never drop or preferentially sample retrieval misses.

Dose is fixed **before training** by `natural_panel.make_plan`: use time remaining in the single authorized window, per-cell worst warm block clocks from the invented shape meter, reserve for upper-estimated PROBE scoring using only FIT geometry, checkpointing and closure, and round the common dose down to blocks of 64. No model quality is used to set dose. Save a second checkpoint on first crossing a common training-clock threshold (60% of the smallest metered per-step time × shared dose), measured in synchronized training blocks including batch fetch and update, not file writes. Report actual times/overshoot and whether threshold reached; no fictitious exact equal wall time. Progress, real exposures, atomic recovery checkpoints and hashes are private. If the deadline runs out before complete freezes, stop and keep partials, not a new result.

## Outcomes and interpretation

Primary equal-dose test: for GDN‑2 host/GDN‑2 reader, compare EFFECT vs trained STATE and trained NEUTRAL on all real tokens, and rotate just `F_i(S)-F_i(0)` at fitted EFFECT weights with original blank writes, routes, seed and gate unchanged. Positive requires all three comparisons' paired 95% lower bounds >0 and each seed gain >0. Independently report STATE vs LOCAL: useful passage *content* is not evidence for a special live-seeded transformation. At unchanged weights also mask the hint and rotate whole values; donors are the other rows in fixed cyclic order only when all four hits exist and lengths match. Otherwise leave that window unchanged and disclose coverage. Retain whole-distribution NLL; no hit-only wins. Time-point results, other family combinations, each mix vs both corresponding singles, and secondary bands are exploratory. Don't pick a best seed/reader on PROBE and call it confirmed.

Gain = baseline minus candidate total NLL divided by total real target count. Pair by document, keep seeds paired, bootstrap whole documents with replacement (10,000 shared resamples, seed 5410); recompute denominators for every band. Report full clocks, update/target counts, one-time archive/index/fetch work, host-only/reader costs and unresolved/negative comparisons. No reuse of this PROBE or automatic follow-up conditioned on it.

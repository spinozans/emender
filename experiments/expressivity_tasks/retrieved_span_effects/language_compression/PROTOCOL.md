## Four co-trained models

Same fresh 64-wide causal LM, two pre-norm residual attention/MLP blocks, 4 heads, learned reset-window positions, no dropout. Small causal prefix encoder on actual inputs; query and local keys from the live host; each local successor must already have been observed. Archive keys are trainable projections of the endpoint token plus its document-prefix context; values are learned successor vectors. Train current weights on both sides, no stale learned bank across updates. Optional no-read row has a zero vector hint. Read plus live state drives the 256-way LM. No known-support label or synthetic auxiliary supervision.

* LOCAL: causal local rows and no-read, no archive rows.
* COUNT: same local model plus a learned scalar mixture with a cheap archive suffix distribution (deepest available suffix among lengths 1..4; eight root pseudo-observations, root add-half). Learn the mixture on the same actual targets. No hard copy/zero probabilities.
* EXACT: exact dot-product softmax over every archive endpoint, local rows, and no-read in one normalizer.
* INDEXED: same rows/sources/priors; exact scores over the complete interval matching the last three observed bytes, rank-32 positive Gaussian background everywhere else, 128-row leaves. Feature seed 5750, static integer plans, differentiable bank rebuilt each update. Never equate a miss with an absent corpus. Identical exact and indexed source priors, including `log(max(1,N_corpus))` on no-read. Missing archive in LOCAL/COUNT is an explicit different source set.

FP32, no TF32, AdamW `.002`, betas `.9/.98`, decay `.01`, clipping 1, 32 steps linear warmup then cosine to `.0002`. Matched initial common parameters and ordered target exposures within seeds.

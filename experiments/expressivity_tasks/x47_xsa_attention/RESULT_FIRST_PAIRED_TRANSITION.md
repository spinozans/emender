# T13: the first paired execution matched both sealed value updates

**On two disjoint TRAIN batches, sharing one structural read at the current byte preserved the full training transition.** The frozen selector chose each program from its own current state. The value learner executed exactly those choices with its own encodings, writable cells and gradients. Every compared route, result, byte-score, joint-score, gradient, parameter and AdamW-state hash matched the [separate T12 reference](RESULT_PAIRED_FRONTIER.md) on both updates. Nothing in the second batch required a pre-recorded program from the first. **One candidate only: repeatability, throughput and footprint promotion are not established.**

**What was shared.** Consent here means that both internal roles run under the *same* trusted grant and the same private observation owner for each document. After an actual selected read, [`FixedFrontierPair`](../../../ndm/memory_program/paired_frontier.py) binds its complete non-neural reply to the raw reader object, ordered keys, cap and live watermark. A checked forced execution consumes it on this frontier only. It never copies the selector's encoded values into the learner or issues a lookup on a guessed choice. The high-water stage held at most 16 physical calls, 22 keys, 1,837 result rows and 7,697 charged text/key bytes at one frontier (not Python heap size); no frame remained staged at release. The original choice/structural checks include the per-client instructions, ordered register keys, provenance, raw masses, refusals and empties, in addition to physical dispatch order.

**What changed across batches.** The original step-1 P2 selector never received an adjoint or update. Thirty value tensors had gradients on each step; the five dedicated selector tensors stayed unchanged. Batch two started with batch one's updated values **and optimizer moments**. All 16 second-batch documents had at least one different value score than the immutable selector at the same executed choices. Both roles still matched their *respective* separate references exactly: 2,097,152 full-distribution byte-score elements and 8,192 joint scores over both batches/roles, plus losses, argmaxes, used-gradient masks, preclip adjoints/norms and both updated states. The two experiments' authority digests differ by design because their true source refs differ; each was recomputed independently before comparing the remaining evidence. No selector tape or historical scores were inputs to the candidate.

**Actual price, no rate comparison.** The candidate used 99,152 LF steps, 614 ranks, 22 verified spans, 32 private starts and 4,128 observed/acknowledged appends: exactly one role's work instead of the reference's two.

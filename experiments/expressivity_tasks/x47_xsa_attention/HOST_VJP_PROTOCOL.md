# T1 — exact host gradient bridge, without an optimizer step

Serving feasibility and training cost are different. S8 made CPU workbench inference practical in one envelope; previous P2 fresh training was 161.7 targets/s on B32 **with a frozen 2M host**. Do not translate S7/S8 decode bytes/s into a quality budget. This engineering test checks a way to give a *real 150M host* the memory policy's gradients without keeping its entire activation graph alive across dependent native I/O. No model update, new data, quality panel or wide/flagship training. X47 ≤842/1800.

**Interface.** One deterministic, causal byte-host encoder on GPU. In direct mode keep the ordinary differentiable host computation and send its feature/logit packet to the CPU controller. In rematerialized mode stage the exact same host packet as CPU leaves and release accelerator activations; execute the *actual* sampled workbench and backpropagate its all-byte + policy-gradient objective on CPU, including old writes. Recompute each original host microbatch once on exactly its observed input, check the forward packet, inject the accumulated cotangents to the real shared host parameters, discard that microbatch's tape. No delayed writer detaches, surrogate gradient for an integer, invented archive value, or forced trajectory masquerading as on-policy. Only first derivatives. Fail closed on stochastic/state-mutating host encoders, shape/dtype/model-version changes, stale/duplicate transaction, missing/nonfinite gradients or nonidentical rematerialized packet. Caller must discard policy and host gradients on failure; require fresh host gradients. No use of the inference recurrent cache or CUDA graphs in backward.

**Registered natural fixture.** Retained 149,855,670-param GDN2 from S4, original training-mode external chunk kernels under BF16 autocast (FP32 masters), no dropout, causal hidden and 256 logits, same first-256 hidden width bridge. CPU FP32 P2 step-1 packed controller on four CPU threads. All active host/controller parameters require grad, none are updated. Same verified W3 TRAIN first 129 raw bytes/window, host microbatch four, full 128 targets/document. P2 limits/8 readers/work prices .001/key and .0001/non-emit, baseline two nats per remaining byte. Action-independent indexed uniforms seed 7809, row ID / visible length (index zero unused) / instruction step / factor. Compare B4 rows 4..7 direct then remat, B32 rows 0..31 remat then direct. Fresh mounts, sessions and grad leaves per cell. No plotting train NLL between doc sets as quality. 9,216 scored targets including matched repeats; not optimizer throughput.

**Correctness.** CPU tests compare exact host adjoints including across multiple microbatches and reject mutation/double commit/dropout. CUDA real arm pairs: same per-document logical instructions, keys/statuses and byte targets, all 256 byte log-probs, joint policy logps and same-weight objective at P2 tolerances (atol=5e-5/rtol=2e-5); every host and policy parameter gradient first-order max `2e-4 + 2e-4 * ref_max`, equal unused masks, finite; report actual nonzero/covered parameter counts and max errors. Remat packet itself must be bit-equal to its staged prepass at the same shape. No tuning or tolerance widening on failure. B4 pass required before B32. Retain compact hashes/numeric summaries, no raw windows/activations/grad tensors/checkpoints in receipts.

**Cost gate.** Include causal encoding, typed native calls, CPU workbench forward, its backward and host backward/rematerialization in timed path; gradient snapshots/comparison, setup and allocator purge separately. Report device live allocation after forward while the policy waits, peak allocated/reserved, graph/saved-activation evidence (not RSS alone), CPU RSS, host fwd/recompute token counts, actual targets/s. Select bridge for **memory relief** on this envelope only if matches all semantics, B32 post-rollout live device allocation at least 20% below direct and full gradient wall ≤1.5× direct. Report peak even if worse. No training-quality panel on the strength of this test. ≤220 additional inclusive card-seconds, detached 0/1 lease and acknowledged progress keyed to actual scored/backpropagated targets, CPU qualification and runnable ref frozen before acquisition.

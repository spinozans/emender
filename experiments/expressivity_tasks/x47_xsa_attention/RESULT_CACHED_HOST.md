# A causal host cache is qualified; it is not a C14 serving speedup

One host prediction, then as many dependent memory instructions as the controller actually chooses. The [bounded cache API](../../../ndm/memory_program/host_cache.py) owns one frontier and scrubbed slot per admission. C14's pre-norm keys and values stay there, with its last hidden state and 256 byte log probabilities. Prefill groups equal lengths; an incremental query uses its own absolute learned position and masks keys beyond **its** frontier, even when peers are further along. Duplicate, stale or foreign admissions, wrong lengths and overflow fail closed. Release clears persistent tensors before re-use. The interface is inference-only; caller owns one immutable model/device stream. It does not solve multi-process isolation, dynamic allocation of long-context KV or training gradients.

# W3: all-byte natural LM test of addressed writes and branch binding

**Question.** On actual Pile documents outside a mounted 100 GB archive, does a trained current-byte join earn anything beyond direct neural/index prediction, the same join with a fixed writer, and a model given all the same reads without the edge-to-tag binding? W2's marker grammar and two-document codebook are not used. This is a bounded, single-seed probe of an initialized read/write algorithm, not a new flagship from scratch. Local only; register protocol and runnable sources before outcomes. No acquisitions, private collections, board, or reopening old locked panels.

**Population fixed before extraction.** Use the hash-bound X43 `flagship_stream/documents.jsonl.gz` and corresponding raw `pile.txt`. Whole documents starting at or after 100,600,000,000, length >=2049. One 2049-byte window per SHA-unique document, start = `int(sha[16:32],16) % (length-2048)`. Registered source splits train/calibration/final_test → W3 train/dev/confirmation; take smallest SHA256(`W3-natural-v1:` + document digest) in each eligible split: 2048 / 128 / 128 docs. Exclude prior K15 I–P2 panel hashes and X43 budget-v2 manifest hashes across splits. Freeze full identities and start offsets without reading confirmation bytes. Validate full document SHA before slicing. No enrichment, packing, gaps in loss, targets borrowed across docs, or target-dependent key selection. Exactly 4,194,304 unique training targets per arm, 262,144 all-byte targets/eval split, one pass. Conditioning on document length and one sampled window/doc limits generalization.

**Real base model and mounts.** Reuse hash-verified dense C14 byte Transformer checkpoint `9b0da60f...` (trained on 972,375,733 targets in earlier corpus region, no new backbone fit). Original 128-byte reset blocks. Workbench and live memory reset only at the 2048-target window. Whole-bank P100 rehearsal v10/m15/boundary-aware m20 (not v6). Longest materialized suffix at depths 8/6/4/2/1/root for direct byte histogram, structural END excluded from byte normalization. Compute exact live-window 8/4/2 backoff histograms from *previous* continuation events, not current target. Include neural, archive, live and latest addressed first-successor copy as direct source experts. Disjoint byte spans exclude the evaluated occurrence; does not prove no duplicated passage anywhere in P100.

**Natural write/read policy.** At visible input index `i`, select the longer of suffix lengths 4/2 with a materialized node and a prior same-suffix end `j <= i-18`, latest such j. The write is computed upon observing byte `j+2`, with that position's causal hidden state; lag >=16, same window. Direct copy may use byte `j+1` even when no child page qualifies. The join inspects the two most frequent *byte* edges at the selected locus (ties ascending), if both have materialized children with byte mass. This is a bounded proposal, not complete attention over the tree; direct prediction keeps all 256 probabilities. Normalize each child's histogram. At birth rank those two codes by parent count times `(1 + 32 * child_probability_of_saved_tag)` with tag `byte[j+2]`. All active/absent positions remain in all-byte loss. Record coverage, lag, candidate hit rate and denominator.

**Train four twins from the same initialization.** A small attention block over current/earlier and edge slots scores the sources; a causal neural writer adds a learned correction to the saved tag and a learned edge correction starts at zero. `full`; `blind` (both child distributions replaced by their mean, same counts/marginals, candidate IDs, past/current features, write, attention and read schedule); `fixed` (exact one-hot tag and no learned edge correction; still train source trust with access to the same view); `direct` (join expert excluded, still fit direct mixture, same shape). Also score neural alone, calibrated direct, and held-out interventions blind/erase at full weights. No hard address-policy learning claim. To keep the comparison cheap, compute frozen hidden states once per batch and share read pages, not learned parameters or optimizer state. FP32 head, seed 4703, AdamW 0.002, weight decay .01, clip 1, B=4 docs, 512 updates each in registered order; no validation selection/sweep. Loss every shifted byte. CPU references/full-vs-prefix causality and gradient to earlier writer must pass; authenticate native member and compare compact pages to stock `branch-of`. Precompute only fixed causally scheduled operands; target gathers for likelihood must never be controller features. Time data preparation, shared backbone/head training and evaluation; teacher-forced batching is not serial decode latency.

**Decision.** Document-mean paired nats/byte, 10,000 document bootstrap draws seed 4703. Promote only if dev full beats EACH of direct, fixed and trained blind by >=.001 and each paired 95% lower bound >0. Only then extract and score unchanged confirmation; same gate. Failure stands, no tuning or locked scores. Report all dev arms even on failure. Numeric failures, source mismatches, or resource overrun stop; retain receipts.

**Budget.** One approved physical 0/1 GPU, broker lease, OMP=4, project interpreter, detached launcher with atomic state and progress/heartbeat/owner/release checks for training. Limit this stage to 1,400 additional card-seconds including failures (X47 previously <=66/1800); no CPU fallback fits. Prep CPU, bounded batching and local ignored scratch; no raw windows, bulk caches or checkpoints staged. Precompute train/dev before acquiring a GPU; if gates pass, confirmation extraction after dev only. No driver changes or publication.

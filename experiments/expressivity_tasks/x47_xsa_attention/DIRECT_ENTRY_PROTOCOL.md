# T11 — queue already-chosen workbench entries behind a trained direct retrieval bypass

Dense sampled P2 costs ~11 s/4,096 targets on the frozen retained host; grouped trained direct ~1.83 s on its terminal transport (T10; different predictors). T2 reduced program-batch fragmentation for a **host-only** BASE bypass; 248 entries were spread across 109 nonempty B32 time indices. It didn't pay for a strong direct fallback. Now test one new optional predictor and compare **two schedules for exactly that predictor**. Not a speed comparison between policies at equal quality. No optimizer step, held-out score, large training, feature regeneration, external change or lease. X47 through S16 ≤1386/1800.

**Predictor.** A trainable host-only Bernoulli gate, T2 initialization (zero weight, bias `-log(15)`), selects DIRECT or ENTER at each actual frontier. DIRECT uses the post-T9 `DirectTrust` and its four experts; the head is grad-enabled here. ENTER executes the original unrestricted P2 step-1 `PackedMemoryPolicy` on the original host scores, **not** a direct-augmented base. No direct probes, trust scores or auxiliary direct loss on ENTER and no program factors, reads, writes or cell mutation on DIRECT. Each client's raw observed tape and bounded local count table advance exactly once per actual byte, including across switches; program cells survive a direct gap. One independently admitted immutable whole P100 workspace per cell, two initially empty 256-page LRUs: T10 grouped terminal/certifying parent for direct, reference page traversal for workbench edges and occurrence certificates. Charge BOTH `S` and `R` plus the real separate positional and live workers. No mask, target, prescribed address or unchosen results supplied to the predictor. Program draws use per-document/per-visible/factor uniforms seed 7809; host-only gate seed 7823. The live single-frontier interface cannot take future gate choices. In teacher forcing only causal host and host-only gate calculations may run ahead. Never advance any private stream through an unresolved byte.

**Two clocks.** Indexed reference runs currently chosen DIRECTs together and currently chosen ENTERs together at each byte index. In the queued clock inspect only each unfinished stream's *current* frontier. Execute its ready DIRECT cohort. Run the ENTER cohort from that same snapshot only if at least `min(8, batch_size)` streams chose ENTER, or if no DIRECT stream was ready; otherwise leave those issuers exactly at their unresolved frontier until more work arrives or the queue drains. One program per actual ENTER, no refill quota, no discarded gate draws. Group only legal, already-chosen reads; different physical batches/cache access order permitted. Same one-byte appends on both clocks: no native append coalescing. Targets enter only after the chosen predictor emits and before the next byte is observed. Count all-byte pathwise NLL, gate log probability on *every* byte plus conditional sampled opcode+operand log probabilities only on ENTER. Charge .001 per logical direct archive probe or program key, .0001 per non-emit program instruction; full remaining within-document loss and prices, fixed baseline 2 per remaining byte. Never reward a gate only with the current target or an unexecuted alternate prediction.

**Qualification and one diagnostic.** Test the live/teacher-forced contract on ragged, all-direct, all-program and mixed streams, literal independent head/program outputs, no speculative branch calls, distinct same-origin bindings, refusal/cleanup, delayed recall→writer gradient across direct and complete priced objective. Freeze runnable source, pass CPU gates. Then four fresh strict four-thread CUDA-invisible processes in order `index-A`, `queue-A`, `queue-B`, `index-B`: one complete fresh forward/backward each on T4 retained **bytewise** features and original 32×128 verified TRAIN targets; same exact S14 post-step head (no rebuild), P2 checkpoint and initial gate. 16,384 gradient-target computations, 4,096 distinct, zero updates and host gradients. Each schedule must independently sample decisions; no replayed routes, future direct histograms or oracle values. Require T2's gate positions/counts at initialization (not equality to its byte scores or program events on a different host packet). Preserve failures; one diagnostic up to 360 s, no retry for measurements/gates.

**Equivalence before price.** Compare ordered per-doc gate and program choices, keys/status/register/row evidence, all direct backoffs/histograms/local evidence and argmax exactly; equal observations and logical work prices per frontier. Real query batching, wire/row counts, physical locate work and timing reported, never subtracted. Compare *all* byte, gate, conditional, joint and trust scores, all losses, cost-to-go and objective at `5e-5 + 2e-5*abs(ref)`; first adjoints on every program/direct/gate parameter, matching used masks and per-tensor max error ≤`2e-4 + 2e-4*ref_abs_max` (T2); require nonzero contribution from each module. For same-clock A/B also require bit-identical scores and gradients. Only private transient arrays for comparisons, public hashes/error counts. To recommend queueing on this fixture additionally require fewer actual program batches and mean complete forward+backward wall ≤.85× indexed, worst main, m20 and positional-worker peak RSS each ≤1.20×. Charge diagnostic callbacks in measured work; report setup/native/CPU and interpreter-inclusive cost separately. A learned entry rate, quality benefit, generated-byte serving rate and eventual cost at a different gate are not outcomes of this test.

# W2: resolve the *current* byte by joining two branch reads to an earlier write

Local no-training acceptance test after [W1](RESULT_W1_WORKBENCH.md), base `8d3e4c127`. Freeze this protocol, then source and tests in local commits before outcomes. No natural-text panel, P100, optimizer, SXGC rebuild, private data, board work or push.

**Complete panel.** Two independently mounted worlds: closed documents `[key=aM, key=bS]` or `[key=aS, key=bM]`. In each, stream the entire synthetic prompt `unit=<tag>;0123456789;key=` byte by byte, for each tag M and S; only score the *one current byte* after the final `=`. The target is not supplied to the decoder. The earlier cue is outside its last eight observed bytes. The task grammar (`unit=` writes; `key=` reads) is constructed, not inferred. World, tag label, answer, target time and archive identity/hash are never model features. Fresh live session and empty single record per independent prompt; no live history search for the cue. Use the same pinned native XSA as W1. Serve each tiny sealed fixture with two read-only, same-version replicas so two independent child requests can be outstanding concurrently after the parent answers. Record actual requests; no answer cache or fixed child list.

**Mechanism.** Reuse W1's fixed 20-slot FP32 self-attention/MLP workspace. The device recognizes markers in the visible suffix and issues a store of the latest observed byte as a learned vector initialized to its one-hot code. At `key=` request its parent histogram, select the two supported edges on device, then request both children as one dependent round. Rebuild the view with the replies bound to their logical keys. For edge i compute `s_i = dot(saved_vector, child_i_byte_counts)`; scatter to that edge, normalize positive total; fall back to normalized parent counts on no match, uniform if no byte evidence. END is never a byte. Use the W1 mixture `(uniform + 4 * archive_distribution)/5` when there is evidence. Emit **now**, before observing the code. Capacity is two; refuse greater fanout, do not silently truncate. This is a constructed join with trainable weights, not a claim of learned parse, address selection, or arbitrary graph traversal.

**Before timing:** run all four cases × full / erase / blind; also run a fixed non-neural CPU join on all four, reading the same live bytes, both child histograms and saved cue, never accepting the expected answer as an input. Erase masks only the saved payload; preserve address, timing, read operands and call shapes. Blind replaces both child payloads by their common average, preserving total counts per tag but not the association to edges (not a random swap). Perform the same fixed-shape record scaling and two-row mixing in all three neural arms. Compare to the parent-only distribution at the intermediate pass. Full must change its current greedy code under either intervening variable (4/4), match the fixed join on all 256 probabilities, and gain >0.3 probability on the correct code vs parent. Both ablations must return to parent-only on all four at identical per-prefix reads/pass schedule. Absolute tolerance 3e-5; CPU/GPU replay of the identical saved neural state, discrete requests/opcodes exact. Retain the whole small panel, not just winners. Check source version/session reset, order-independent binding, structural END, binary edge/tag, overcapacity. Verify later loss can reach the real earlier tensor writer without an optimizer step.

# T9 — qualify and price a trainable *direct retrieval* baseline on the retained host

T8 qualified the frozen-route/value intervention but did not supply the other essential comparison. BASE or a bare host is **not** strong direct retrieval; W3's direct result used a different host, exposure, historical features and input geometry. Build a separate inexpensive comparator with no instruction sampler, joins, delayed neural writes, locator, or dependence on a learned arm. The aim is real causal feature/gradient/cost evidence, not to select a quality winner. No W3 shards used as source probabilities, dev/confirmation reads, new exposure panel or GPU. Same T4 retained bytewise 150M packet and SHA-verified 32 TRAIN windows ×128 real shifted targets. Fresh local 4-thread strict FP32 processes/settings, X47 ≤1324/1800.

**Fixed direct experts.** At each scored frontier: (0) the host's full-support next-byte distribution; (1) P100 m20, first byte-positive authorized histogram among actual literal suffix lengths 8/6/4/2/1 and root, only lengths already present. Ask the next question **only** after the previous answer for that document. Distinguish unavailable (including a positive unmaterialized transition), certified absent, and END-only before fallback. END is not 0x00/0x1e/0xff and never a byte vote. Disable the archive expert if no complete byte-positive answer. (2) the current document's longest supported 8/4/2/1 byte suffix with an **observed successor** (else observed unigram), (3) its most recently observed follower as a point prediction, only for a nonempty suffix. Local counts/last follower update on actual observed transitions; no search in future text or hidden-state carry across resets. Bounded length before mutation and explicit close/clear. Logical receipts cover the actual chosen keys, source/version, status, selected counts/mass incl END, private document origin/frontier, local counts and latest byte/age. Only hashes/tallies retained. No global memo of private queries. W3's child evidence, fixed joins, target-likelihood columns and any old neural payloads are excluded, not silently considered free.

A 64-wide tanh trust head over current normalized hidden[:256], causal depth/support/peak/miss/age features and host agreement with each of the three direct proposals produces masked weights for a **full normalized 256-byte mixture**. Initialize common seeded head (7873), small random final weights and biases [0,0,0,−log(4)]; no validation tuning. Host always legal. Same model shape and head on both schedules. Score the true next byte *outside* the head **before** appending it. Mean all-byte NLL only; AdamW .002, wd .01, clip 1, empty state; host frozen. Neither a capacity-matched P2 nor a quality-certified 'best' comparator.

**Numerical/logical gates.** Unit test brute prefix statistics incl specials, duplicate followers/overlap, cap/frontier/reset, exact-empty vs unavailable vs END, no unchosen suffix probes, analytic full mixture/adjoints and future intervention. On real TRAIN, independently qualify the selected archive histogram with the other existing `W3BP0001 S` suffix-ID resolver plus selected `R` pages (no child-pair reads), and local with literal prefix scans at 1/7/17/63/128 in first four windows. These extra oracle reads/time are separate and paid in CPU accounting. No index or source edits.

**Measured schedules.** Four sequential fresh CPU worker processes with new native mount/cache + head/optimizer lifetimes (return only numeric diagnostic arrays to their trusted parent through anonymous memory, no durable snapshots), in order `serial, grouped, grouped, serial`, one CPU diagnostic. Both score B32 at every real frontier (exactly 128 head calls per pass). Serial resolves each document's chosen archive/backoff probes separately. Grouped deduplicates only *currently required* immutable keys across unresolved documents in the same suffix-probe round, batches them on that same whole-P100 materialized capability; never prefill future learned reads or cache target-discovered plans. Same bounded 256-page LRU per fresh mount; physical fetch order/cost may differ. Identical incremental local statistic in all timed cells. Require per-document evidence digests, expert availability/support, **all** byte log probabilities and gate weights, all NLLs, preclip derivatives/used masks, updated weights and AdamW state/counters bit-identical across four independent one-step runs; finite normalized outputs max unit-mass error ≤2e−5, nonzero finite trust gradients and real weight change. Retain tensor hashes and error counts/maxima, private arrays in RAM only. One 8-minute CPU diagnostic incl oracle; stop on mismatch, no tuning or substituting a short benchmark. Total **16,384 scored target computations on 4,096 distinct TRAIN positions**, four disposable direct updates, no P2/host updates or card. Report physical hist calls, distinct keys per call, page RPCs/rows/bytes, peak cache use, branch statuses, local increments/storage, CPU core-s, wall including scoring/backward/update, prep/close/lifecycle and RSS separately. Optional grouped default only if correctness and mean wall ≤.90× serial, peak main RSS ≤1.20×. Regardless of speed, keep serial as an oracle. No inference about all-byte held-out performance, complete serving latency, new 2B weights or sustained training from this diagnostic.

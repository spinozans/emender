# One host packet to a CPU workbench beat both GPU controllers here, at higher CPU cost

**For the retained 150M host, 48-wide controller and four available CPU threads, prefer the CPU placement for this measured serving envelope.** Keep the host and its recurrent graphs on GPU. One `[B,512]` FP32 transfer per byte batch supplies hidden and base probabilities; all typed page values, operand decisions and emit arithmetic then stay on CPU. No D2H fence per dependent operand. This placement isn't intrinsically cheaper: B16 sampled CPU core-seconds more than doubled. Don't assume the same result for a much wider controller, CPU-constrained server, training, or a different host.

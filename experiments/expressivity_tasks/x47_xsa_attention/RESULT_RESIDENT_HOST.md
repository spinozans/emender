# Bounded host memory survived 680 admissions

[ResidentArena](../../../ndm/memory_program/resident_host.py) prepares an explicit finite set of single-token graph widths on **one** capture stream and one shared, session-owned recurrent-state arena. Exact width only; width misses execute the actual eager batch. A released slot is cleared and every graph workspace retired on neutral private rows before readmission. No shape cache growth on client arrival. Preparation refuses to publish over-budget graph pools; arena bounds are checked before tensor allocation. Neither is a total-process physical-memory limit.

[Protocol](RESIDENT_HOST_PROTOCOL.md) `59b8bc6d7`, source `2cda2eae6`, **72 CPU tests**. Real retained FP32 149.9M GDN2, no index/controller timing. Sixteen eager signatures generated 848 reference bytes. Across **40 fresh waves, 680 admissions, 2,120 actual responses**, every `(client, row, generation, frontier, emitted byte)` digest matched. Two known graphs handled 40 width-1 and 80 width-16 steps; 40 width-3 steps fell back without padding or capture. 80 real prefills, 80 partial/final release operations, 160 neutral replays, stale handles rejected and slots verified zero. Replacement clients did not overwrite the checked live peer. Same 32 TRAIN prompts repeated, not 680 distinct documents or an open-arrival throughput sample.

**Resource gate passed.** Preparing both graphs took 0.318 s; persistent arena 240,762,880 bytes, graph pools 25,165,824 bytes reserved. After warm waves, **all 36** synchronized post-release readings were exactly **859,400,704 allocated and 1,430,257,664 reserved bytes**; RSS spanned 1,847,540–1,847,788 KiB. No per-wave cache purge. Closing returned allocation to 618,572,800 bytes vs 609,004,544 before preparation (+9.125 MiB once); post-close purge lowered allocator reservation to 664,797,184. The model remained loaded. This resolves the practical *bounded service* concern for this configuration, not the cause of every S5 fresh-build increment, a proof about unbounded uptime, or certification of cross-tenant physical erasure.

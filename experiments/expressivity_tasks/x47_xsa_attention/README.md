# A1: banked XSA attention read, local implementation & measurement protocol

See [system decision](../../../docs/XSA_MEMORY_SYSTEM.md). This milestone is the native → device read seam, **not** a trained language model or built-in GPU traversal of every SXI2 format. New code isolated from banked K-series engines. CPU Python reference is an independent oracle; no Python loop over live rows/candidates inside the GPU read.

**First operator.** Tile width 1..64 and feature width 1..128. One row is one query/head/bank. `idx[R,F]` is int32 `-1` for padding, otherwise a local device address into a compact K/V table; never a corpus-global 32-bit offset. The mapping to `(bank,version,doc,offset,value schema)` and the membership mask is the provider's responsibility. `bias[R,F]` is finite log occurrence prior, not a value/mask sentinel. A page exceeding capacity, uncertain bounds or incompatible schema must be refused or explicitly identified as a different, declared candidate-selection policy. Empty bank yields a zero vector and adjoint, not a uniform distribution. Repeated indices contribute multiplicity and accumulate into shared K/V gradients. Independent row normalizations followed by explicit additive bank scales. No corpus-sized GPU table. First shape has equal Q/K and V widths for a small fused kernel, not a general requirement on a model.

**Parity (before any speed promotion):** direct PyTorch float64 oracle, trainable queries/keys/values/bias, finite-difference check, inputs containing zeros and extreme finite biases, mixed/empty bank rows, shared rows/duplicate indices, all-empty table, dimension tails, first-step query=0. A single bank with all `n` positions and unit mass reduces to ordinary dense scaled dot-product attention for that bank. For fp32 forward+all first gradients allclose `rtol=1e-4,atol=3e-5` at registered unit-gradient input scale, BF16 `rtol=.03,atol=.02`; record maxima + seed/shapes. Check restoration/closure of a bank-row ordering permutation, scale=0 ablation, and per-bank independence. Atomic gradient accumulation need not be bit-identical. Empty outputs and masked gradients must be exactly zero. Fail closed if any parity arm fails. Additional precision/shape/serving gates are separate. Record actual device architecture, versions and contiguous shapes. No silent CPU fallback.

**Speed (not a training budget):** compare the same packed pages against vectorized PyTorch on device; include an optimized/library baseline if applicable, explicit pre-gather cost if using SDPA. Wall and CUDA-event timings after correctness and warmup, medians plus p95, samples/iterations specified, first-compile timings separate. Try R=1/8/128/2048, F=8/32/64, D=32/64/128, fp32 and BF16 subset; contiguous vs random/duplicate working sets. Freeze a tractable grid, iteration count, correctness tests and independent native end-to-end workload before launch. Detect expensive gradient zero/allocations or atomic collisions. No assumed win. Separately and honestly price lookup, native packing, any request serialization, H2D, read, sync and total on actual mounted sources; replaying a tensor or retrieving a cached histogram is not a warm live serving measurement. No model optimizer, training, new raw collection or reserved LM panels. All checks/benchmarks local, GPU only via project's broker and serial physical card 0/1 with release and spent-seconds receipt, <=0.5 new card-hours including failures; prior cumulative <=6546 seconds. Do not claim all shape/speed checks passed merely because a fixture passed. Report phase status and blockers as they happen.

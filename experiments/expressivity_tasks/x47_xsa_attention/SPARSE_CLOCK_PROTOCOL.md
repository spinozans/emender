# T2 — a trainable host-only entry decision and an exact sparse teacher-forcing clock

The dense P2 machine rebuilds scratch even to decide not to use it. T1 reached 302 targets/s on its fast B32 gradient batch, still cost-vetoed. Add an **optional new predictor**, not a faster interpretation of existing P2: a trainable affine Bernoulli gate on the causal host feature chooses BASE (emit the normalized host LM directly) or ENTER (run the unrestricted typed workbench). No content rule, similarity threshold, top-k across positions, prescribed key, join target, or quota to refill; every position can enter. Initial weight zero, bias log(1/15) = 1/16 enter probability. This untrained sparse prior is not evidence that it preserves LM quality. BASE bypass is **not** the trained direct retrieval control. Dense policy remains available unchanged. No optimizer, no holdout, no model update. X47 ≤1153/1800.

**Exact algorithm for this new predictor.** Teacher forcing may batch the causal base/entry scoring on verified observed inputs. Gate features do not read private cells, memory outputs, true next bytes or future routes. Indexed action-independent uniforms, same in both schedules. No workbench scoring/lookup/save on BASE. Reference clock processes every time index, scoring before observing each next byte; packs only simultaneous ENTERs at that index. Compact clock runs the next *already chosen* ENTER of each document together, even at different time indices. Before a chosen read, consume only intervening BASE bytes whose losses have already been scored. Never append across an unresolved ENTER or beyond the current causal watermark; preserve each document's order, complete raw transcript and persistent cells. End by advancing the already-scored BASE tail. Compute all-byte NLL, joint score-function term including the gate on **every byte**, conditional opcode+operands on ENTER, subsequent within-window costs including after recall; same .001/key, .0001/non-emit, baseline 2 nats per remaining byte. No differentiation of indices, independent-gate surrogate, truncated writer graphs or suppressed bypass losses. Coalescing can change physical I/O batches, not chosen per-stream keys or statuses. Distinguish response distribution from numerical value of the surrogate. API for live inference must compute entry only from the current causal host packet; no future mask argument.

**Tests.** CPU frozen-weights parity of dense-time vs sparse-clock on ragged, no-enter, all-enter, mixed and delayed cell cases; compare every real byte log-prob, entry and conditional log-prob, objective and first derivatives; adversarial append/read witness for no future lookup. Distinct RNG coordinate families for gate seed **7823**, program **7809**, same verified row/actual visible byte in both schedules. Microbatch host inputs by document length only. No address snapshots or sampled program replay in the natural test.

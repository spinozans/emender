# P1: chosen-program span reads and training-path profile (before measurement)

Starting Emender `0adb462b2`, X47 cumulative ≤93/1800 card-seconds. Local only. This is a profiling/training-path qualification, not a quality panel. No new corpus, dev extraction, W3 confirmation access, changes to native binaries, or historical W3 result. Use existing pinned B2 and W3 executables and the existing P100 rehearsal descriptor. Add no task-specific opcode or program to the sampler.

**Interface.** In addition to the actual live and P100 byte branches, register `occurrences` (text → complete bounded document-relative spans), `contents` and `following` (bound span → real text / following byte and up to 16 bytes of same-document context and its span). Each returned value read encodes the actual bytes using a fresh differentiable mean of the model's byte embeddings. No invented activation at a corpus offset. `following` at the live watermark or document end has no row. A stale namespace/version, out-of-range span or capacity refusal never becomes a successful empty answer. Whole admitted banks only. P100: existing one-open B2 verified positional-worker, exact raw cap eight. A known within-doc count >8 on the same m20 mount can certify refusal BEFORE locate; absence of a materialization must not. Live: one growing native session per window, reads/verification bounded to observed bytes. Never put a target, a selected historical address, a supplied join trace, or a future write in policy input.

**CPU gates before profile.** Validate real archive geometry and checked corpus fd, span equality, binary bytes (including 0/30/255), same-document and open-frontier bounds, empty vs refusal, duplicates and coalescing, separate capabilities, reader value gradients. Include F6/existing P100 positive probes as adapter qualifications, NOT as the sampled distribution. Compare batched conditional opcode/operand scorer with scalar reference on fixed actions/log probabilities, gradients, greedy behavior, unequal masks and replay; stochastic trajectories need not share the old RNG sequence. Retain the prior runtime suites. Source and tests committed before device measurement.

**Registered population and cost.** First shard of already receipt-verified W3 TRAIN; rows 4..7, first **129 bytes per window**, all 4×128 shifted targets in one batch. Original individual raw document digests, registered W3 selection, shard and C14 checkpoint hashes bound; no W3 derived join pages read. Use C14 pretrained causal hidden and base likelihood, frozen. MemoryPolicy defaults (d=48, four heads, default step/row/key/cell caps); pattern length 16 (supported by live service), 32 recent bytes. Registry order P100 then tape, each byte edges / occurrences / contents / following. Default compiled weights, seed 7411 for init and 7412 for device sampling. No forcing/boosting join, write, locate or recall frequency. Sample chosen programs, keep writes in graph for 128 predictions, score before advancing; one AdamW update, LR .002 wd .01, clip 1, cost .001/logical requested key and .0001/non-EMIT instruction, fixed pre-action remaining horizon baseline 2 nats per remaining byte. No hyperparameter search, second seed or refit. One real update is a measurement, not a quality claim. If no successful delayed/spatial result was sampled report zero, do not fill it with fixture operations. Native CPU witness is separate.

**Report.** Inclusive synchronized wall for the teacher-forced batch through optimizer; split setup, host+program forward (including frozen backbone and native reads), backward, update; provider call walls/counts as nested diagnostics, not additive GPU times. Count opcodes, refusals, successful/empty hits by capability, rows and recall of cells actually written on prior bytes, lag, trainable parameter gradients and peak device allocation. Batch categorical choices across active docs per dependency depth; use real conditional samples and log probabilities. Distinguish returned span count, selected span-value reads, and useful effects on quality. A finite sampled NLL on TRAIN is not dev evaluation or serial decode speed.

**Stop/scale rule.** One bounded profile lease, ≤200 card-seconds incl. failure/rounding, physical 0 or 1 only; allow a repair of a genuine implementation fault only with retained failure and within that cumulative allowance. Hard fail closed on broken qualifications, provider identity, invalid lease, nonfinite loss/grad/norm, missing submitted update or memory exhaustion. Do not open new dev data if even **one** trainable arm at the measured target rate projects beyond remaining X47 allowance for ≥1,048,576 nonrepeated targets. This is a planning estimate at measured batch geometry, not proof of an optimized system's ceiling. If feasible, freeze a separate matched-cost, matched-exposure protocol for trainable vs frozen routes with trainable values vs strong direct reader before dev; still no W3 confirmation. Otherwise retain the actual bottleneck and stop, not a tiny substitute fit.

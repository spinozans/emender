# T7 — can we hold the *executed route* fixed and still train the values?

T5 qualified reproducible strict offline updates; T6 accelerated frozen features but failed the cross-size update gate. Use **only the checked T4 retained 150M bytewise packet** for this control. A real quality trial needs learned-execution vs frozen-execution with trainable values, not just freezing an opcode head while its inputs drift. Build and price that control, not a held-out experiment. No card, 4 CPU threads. X47 ≤1324/1800.

**Route contract.** From an immutable P2 step-1 selector, generate fresh sampled opcodes and *all conditional operands* on the actual document frontiers and chosen native reads (seed 7809). Retain only bounded discrete instructions, per-step logical evidence digests and provenance in a private in-memory tape: host feature SHA, selector/seed/run context, document/start/raw observed-input SHA, scope/version/reader order/types and limits. No logits, target, register values or native replies to reuse. Bound worst-case step count before capture. Don't treat a public tape as an admission capability. Each use reopens real authorized mounts and fresh document sessions, scores before append, looks up only currently selected keys, checks actual request binding/keys/cap before dispatch, validates status and ordered complete result layout incl duplicate keys, multiplicities of raw hits and private-span origins before proceeding. Normalize only the equivalent fresh live session nonce to the same source document/window. Nonce-normalization is not cross-document equality. Keep neural values and learned pair weights differentiable/changeable. Unsupported structure or changed binding is a hard failure before an optimizer step; never coerce a different query to the recorded outcome. For forced choices use **pathwise all-byte NLL only**; log-policy probabilities of a forced route are not an on-policy objective. Keep ordinary `teacher_force(...,mode='sample')` unchanged by default. Include CPU adversarial test for same-shaped but different returned bindings/mass, stale origin or input, separate value credit and no route gradient.

**Six B32 passes (32 × 128 TRAIN).** One strict local CPU process, original mounted data/host packet and P2 initialization/limits, .001/key + .0001/nonemit and horizon baseline 2 for the ordinary on-policy step. No selection based on outcomes. (1) frozen capture under sample seed 7809, (2) one ordinary fresh AdamW update (must reproduce T5 strict retained control exactly), (3) one independently initialized forced-route value-only AdamW update (same .002/wd .01/clip1 and input exposure, no policy surrogate), (4) post-update full values on their own newly sampled routes with the same indexed uniforms, (5) updated fixed-control values on their original captured routes, (6) updated **full** values on the original frozen routes. Real native work in all six, no precomputed answers, no short path on a miss. Control adds capture and validation costs, charge them separately. Fresh document/cell/RNG resets at every pass, no committed state or adjoints carried across optimizers. Capture and initial forced/full predictions, action and dispatch digests must match; all three frozen uses verify every real register layout and request. Post-training fixed replay must have identical executed route even if its values change. Require nonzero value gradient/update including writer where exposed and no update to dedicated selector-only opcode/transition/pointer/prior weights in the fixed arm. Compare post-full sampled vs frozen instruction/operand/request digests **per position** and byte distributions at the same updated full weights; count actual changes (zero is a result). This is sensitivity on the same TRAIN bytes, not held-out quality, proof of useful joins, an independently trained 2B result, or a ranking of learning arms. Gate is a usable intervention + evidence, not a desired loss direction. No strong-direct/quality panel yet. Exactly **24,576 scored computations, 4,096 distinct target positions, two independent one-step updates**, zero card-s. Preregister/freeze/gate; bounded CPU diagnostic (<8 min); only hashes/scalars/work to git.

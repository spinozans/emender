# S8 — keep the large host on GPU, price one small-controller device boundary

After S7, wide sampled B16 ran at 175 bytes/s vs direct 567; the 2.22B tensor shape was feasible but didn't remove serial memory/controller costs. Before writing another special-purpose kernel, test whether this 48-wide dynamic controller benefits from being on the CPU next to its typed pages/readers. X47 ≤779/1800. This is **not** offloading the large model. No alternative routes, new training, holdouts, SXGC or index changes.

Keep the real S7 149,855,670-parameter host on GPU with one resident 1/16 graph pool. Compare GPU Triton, GPU packed-eager, CPU packed-eager tiny controller, same P2 weights/FP32, all registers/cells on the controller's device, native service unchanged. On CPU placement perform one packed GPU→CPU copy per new prediction batch of 256 causal hidden + 256 base log probabilities/client. Never transfer each candidate/page from GPU. Exactly one generated argmax acknowledgement per client on its policy device, live bytes and next host inputs unchanged. OMP/PyTorch 4 threads, not tuned. CPU adapter outputs must not alias mutable host graph buffers. Distinguish measured blocking transfer wall (includes waiting for host completion) from estimated link time. Price server and native CPU core-seconds as well as GPU memory; a GPU savings isn't a system savings by itself.

CPU tests for shape, device/view/gradient and no-copy contracts. Before timing, compare cross-device fixed program including every conditional distribution, late write gradient, host/parameter adjoints and statuses at P2 tolerances; use CPU and GPU copies of identical random fixture inputs/weights. Then actual closed-loop service on the same S4–S7 TRAIN prompts and P2 categorical seeds: two blocks B1/B16, 32 prompt + 32 autoregressive responses, greedy and sampled. Block 0 GPU Triton, GPU eager, CPU eager in each mode, block 1 reverse arm list. 24 cells, 6,528 actual bytes. Direct/bare costs already measured, not rerun. Compare every stream's bytes, opcodes, operands, bindings and outcomes to S7 small; if divergent retain clocks but no same-work speed claim. Log host and policy placements, counts/bytes of boundary transfers and all interval/CPU/native costs. No serving claim from forced replay.

**Default gate on this retained host only:** require conformance, matching work, correct transfer count and both modes at both B1 and B16 ≥1.20× **the faster of the two GPU rates** and p99 ≤1.10× **the lower GPU p99**. Otherwise keep CPU placement optionally for experiments, not promoted as a faster runtime. Standalone training or a real trained wide checkpoint remains a different study. ≤150 additional inclusive card-s incl failure/repair; gate and freeze source before lease, physical 0/1 single worker and independent watcher.

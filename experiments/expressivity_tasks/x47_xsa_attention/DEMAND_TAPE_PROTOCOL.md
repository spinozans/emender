# S17 — materialize a private live index only for a chosen native read

T11's B32 gradient cell observed 4,128 actual bytes across 32 private live processes, but P2 requested only 80 live branches and seven live locates. Its queued *training* clock is not a decode scheduler. S14's four-expert direct-only service didn't need live workers at all. Test an online DIRECT/ENTER predictor and one optional **private native tape** lifetime change. Both arms use exactly the same fixed predictor, logical tape, m20 traversal, positional backend, host and synchronous real-ticket scheduler. This is about resource demand at an initial sparse gate, not evidence of learned contact, loss/quality or a universal latency improvement. No change to SXGC, external layers, files, allocator/driver, training corpus, learned weights or holdout. X47 through T11 ≤1386/1800. One qualified detached producer, **≤130 inclusive additional card-seconds**, only on broker-chosen physical 0/1, before the existing deadline. No timing retry.

**Predict and observe.** Use the verified S14 post-T9 direct head as-is (no rebuild), original step-1 P2 and T2 zero-weight/`-log(15)` host-only gate. Eval/frozen FP32, four CPU threads, one `[B,512]` actual host packet/tick, bridge normalized hidden[:256] plus host logp. Gate samples seed 7823 at `(row_id, visible)`, P2 uses S12 arrival uniforms seed 7530, anchored at the admitted prompt regardless of intervening DIRECT bytes. At *current* frontiers only, group DIRECTs and ENTERs by actual choice, no queue floor/wait, no coalescing observations across clients. Each DIRECT computes trained trust on full-support host+archive/local/latest evidence, no workbench; ENTER runs unrestricted P2 on original host scores, no direct probe. Program cells survive DIRECT. Deliver argmax and observe it once, including final/canceled byte. Use S14's reference-page serving transport for direct, reference P2 with same-version certifying parent for positions; one freshly verified whole P100 m20 + separate positional worker per cell, separate initially cold 256-page LRUs. No terminal frames. No future targets, gate masks, route tape or external answers. Fail on changed predictor/mount, stale session/ticket, bad reply or ambiguous append. No async native query under this owner.

**One intervention.** Eager opens a fresh SXGC `session 16` per admission and appends each prompt/returned byte immediately. Demand maintains the same private bounded mirror of actually observed bytes, with a distinct opaque logical session/version per admission even at identical origins. Local counts, logical reader watermarks, span bounds/content/follow and rolling context advance on every observation, even without a native process. Only a chosen, in-range live histogram or locator may start a private native process. Before each such query, append *only* the missing observed bytes since its checked native frontier (one nonempty bounded catch-up append; nothing if current); require acknowledged new visibility. Do not count an issued append as a prediction or serve a stale index; do not force a final sync on release. No cross-client buffers, detached speculative prebuild, sharing of private handles, durable raw trace, or supplying machine state from the oracle. Track real starts/exits, append frames/bytes, branch and locate RPCs, synced and discarded suffix bytes, and logical observations separately. Bind lifetime/capacity before reading. Failed/expired bindings cannot re-open or answer even mirror-only reads. CPU tests cover same-origin isolation, byte sentinels/open EOF, prompt+gaps, pure direct/no open, contents vs native reads, overcap, injected sync/query failure, actual native eager/demand parity, order/retirement, mutated weights, complete cleanup and service regressions.

**One generated workload.** S14 retained 149,855,670 and S7 replicated dense 2,221,786,584 FP32 shapes (replicated first, not a second trained checkpoint), real cover `(1,4,8,16)` at capacity16/context64, ≤6 disjoint launches, no padding. Exact same 32 SHA-bound TRAIN prompts ×32 bytes; no feature packet or future bytes supplied to decode. On each shape generate a closed eager oracle (two blocks of 16 ×12 replies), then four fresh arrival trials (4 offers/60 ms spaced, 16 at 0/50 ms burst; waiting limit 32; every eighth row stops after byte 3, others finish 12). Replicated order spaced eager→demand, burst demand→eager; retained order spaced demand→eager, burst eager→demand. 384 oracle bytes and 4×348 arrival bytes/shape, **3,552 real returned bytes** in ten cells if complete. Revoke/reap before slot reuse, no later query under old admission. Independent watcher must see advancing work, renewal and release; charge both model loads/transfers/build and graph prep. Retain partial evidence if stopped.

**Decision.** Exact bytes, per-client DIRECT/ENTER identities, probe keys/full histograms/local evidence, program instructions/status/operands/requests, ordered register provenance and logical work at every emitted prefix vs shape's closed oracle. Compare full 256 byte scores, gate logp and joint logp plus chosen four trust scores or conditional program logp at `5e-5 + 2e-5*abs(ref)`; same checks on full oracles across sizes. Separately verify expected gate pattern from coordinates, span/version isolation and bytewise observation, host work, scrub, balanced native opens/reaps, actual logical vs physical append/search traffic. Distinguish completed byte from real LF walk. Functional qualification is independent of savings. To recommend demand for this bounded sparse arrival mix require all parity and, on **each size/offer pair**, at least one actual live native read, demand private process starts ≤.50× eager and physical native append calls ≤.50×, generated throughput ≥.95× and offer→first p95 ≤1.10×. Only claim a throughput win across this panel if rates ≥1.10× in every pair. Report main/shared/private and device memory separately (summed exit HWMs are not simultaneous RSS), setup/lifecycle and core-s, offer jitter/queues/first/interresponse/sojourn. This does not defer archive verification, justify cross-client reuse or qualify longer horizons, positive locate tails, optimizers or sustained open load. Freeze/test CPU before any lease.

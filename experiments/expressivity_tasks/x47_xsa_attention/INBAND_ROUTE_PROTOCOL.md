# T8 — record the execution of a training forward, without a second selector pass

T7 matched all addresses and scalar loss but failed complete-vector identity between a second gradient-disabled selector and a gradient-bearing training forward. Capture alone added 8.587 s, 2,854 logical keys and 99,152 LF steps. Its control remains unqualified. T8 tests a different placement: **seal a bounded, private instruction/evidence tape directly from a normal sampled, gradient-bearing rollout while its parameters remain unchanged, before backward or any optimizer step**. Do not use T7's no-grad capture as a training oracle. Full events and byte distributions, not merely labels or argmax, remain exact gates. This experiment does not establish the reason for the T7 discrepancy.

Same T4 serial retained 150M packet only, independently bound by SHA + observed window/source/reader scope. Same four-thread strict FP32 CPU train-mode step-1 P2, B32 ×128 checked TRAIN targets, indexed seed 7809, active parameters/grad mode for **all six** rollouts. No CUDA, extra data, tuning, change to the precision/tolerances or repeated/chained training. The recorder returns only validated discrete choices/structural evidence, never numeric outputs, target labels or reusable read answers. Comparison tensors in the **external diagnostic only**, not available to the policy. After any measured failure write nonprivate diff counts/maxima, stop with actual completed work, never relax the gate. ≤8 min for one CPU diagnostic, no retry to qualify a result. X47 remains ≤1324/1800.

1. **In-band capture + full update.** During one ordinary all-byte sampled B32 teacher force, the observer hashes the actual selected requests and executed register layouts and raw hits, as in T7. It does not drive or change selection, autograd, random stream, legal options or native dispatch. Verify source parameter identity/versions through tape completion. Return the **original** live sampled objective. Same .001/key + .0001/nonemit future-cost surrogate, 2 per remaining byte constant baseline, AdamW .002/wd .01/clip1. Independent complete initial predictions/scores/events/dispatch, preclip gradients, optimizer and weights must be bit-identical to T5 strict retained and T7 ordinary full step; physical/logical work must match (no additional native calls to get the tape). Charge recorder + update and lifecycle. Compare descriptively to T7's separately priced capture plus step; moving calls across experiments is not a paired wall-speed trial. No claim the route stays frozen across future batches if captured **after** a selector learns: multiple initial routes require a separate unchanged selector or tapes from the initial weights.
2. **Independent fixed-value update.** Fresh initial parameters, empty optimizer, fresh authorized live readers and real chosen P100 reads. Replay only the sealed integer choices using the T7 structure/binding guard, with grad mode and weights active as in training. Before changing weights, require same true per-position/per-document events and dispatch/work, all 1,048,576 byte scores, 4,096 joint scores and scalar all-byte NLL **exact** vs (1). Never train a forced route with REINFORCE. Backpropagate *only* pathwise mean NLL and require nonzero writer gradient + actual writer weight change, no gradient/weight change to dedicated opcode, transition, pointer and prior tensors. Same optimizer hyperparameters.
3. **Full updated, live.** Fresh sessions, same indexed uniforms. One new sampled forward under updated full weights, in-band record the new routes; no optimizer/backward. This is only a same-TRAIN counterfactual.
4. **Positive replay control.** At those same updated weights force the new tape on fresh sessions. Require all new byte/joint/NLL scores, actual reads, per-doc event digests and work exact vs (3). This controls for the replay mechanism, not just the old policy. Stop on failure.
5. **Fixed updated, frozen initial route.** Updated value-only weights, original tape, check true request/result/dispatch identity again. No optimizer. Compare to (2) at the same positions to isolate changed values.
6. **Full updated, frozen initial route.** Same weights as (3)/(4), original tape, compare all positions per document for actual opcode, instruction+operand, nonempty native request, structural evidence and predicted distributions/argmax differences. Count positions where the *whole* route history up to the current decision is still identical and check that outputs there agree within 5e−5 + 2e−5·|live| (exact floating point not promised when peers select different batch geometries). Beyond first divergence do not attribute a new prediction only to its current opcode: earlier changed writes and batch composition also matter. Report NLL only as in-sample sensitivity. A zero route-change count is a legitimate measurement.

Fresh source/binary validation, no tape sharing across documents/capabilities, score before append, reset live heads/cells every pass. Budget 6 × 4096 = **24,576 computations on 4,096 distinct positions**, two disposable independently initialized policy updates, zero host updates/card-s. Evidence includes partial counts on failure, per-pass native admission/core/RSS/time and per-document difference aggregates, full state/dispatch/output identities; no raw tape, packet, tensor snapshots, text or weights in git. Functional gate: both exact reproductions, complete freeze/gradient/work checks and full accounting. Not a held-out test or an autonomous fixed-route generator for unknown future bytes.

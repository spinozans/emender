# S12 — bounded in-process arrival, cancellation and native reader lifetime

A sequence of closed cohorts isn't a service with new requests arriving. After S11 the host can serve odd widths using existing real graphs; S6 verified host-only churn. Implement a trusted single-owner local byte service for **changing membership**, with one reusable immutable P100 mount under one already-admitted whole-domain scope, per-client native live process, private memory-program session and owned GDN2 admission. Not a network endpoint or tenant auth system. X47 ≤1120/1800.

**Contract.** Admission needs a bound document prompt and explicit output limit; reject over-capacity *before opening* private resources. Never identify a client by reusing its slot number. A synchronous step can select/reorder ready live handles; group genuinely new prompt prefills vs actual last-delivered byte advances, then one chosen-only barrier workbench (or fixed direct bypass). Never advance on an unreturned guess; no partial return on failure. Discard the entire owner on an uncertain backend/append/delivery failure; stale/duplicate/foreign tickets and exhausted horizons refused before execution. Release/cancel individually or as a set, close its private native reader, drop all owned tensors, prompt, memoized labels and indexed RNG belonging to those clients. Scrub host graph/slots as S6. No raw traces in retained logs. User-held outputs, allocator physical residue, network races, and arbitrary code in a binding factory are outside the logical erasure guarantee. Register CPU tests for capacity, stale/foreign, cancellation/reuse, mixed frontier input regrouping, fault cleanup, action-independent sample stream vs S8.

**Fixture/oracle.** Verified TRAIN rows 0..31, first 32 prompt bytes, 12 possible real outputs/client, P2 step-1 CPU sampled controller or fixed direct; same weights/prices/RNG conventions as S11. One prebuilt FP32 150M four-width resident store with cover enabled (16 live +16 neutral), max frontier 64. First generate independent unmodified-policy barrier oracle at B16 (both blocks × direct/sample, 768 bytes); match full digests to S11 and also digest prefixes before disposing traces. For arrival comparisons four clients (row%8==0) are canceled by caller after **3** returned bytes, other 28 finish at **12**. No count/horizon/task label supplied to policy beyond bounded uniform table dimensions. All programs execute afresh. Match every served byte prefix and normalized opcode/operand/key/status digest.

**Open offered clock, in-process.** Producer independently offers the 32 descriptors on a monotonic clock; consumer cannot delay offers until compute is done. Two published patterns: 4 clients every 60ms (8 groups), or 16 at t=0 plus 16 at 50ms. Queue cap 32, active cap 16; no waiting to form a preferred width. Drain already offered work into available slots before each tick, one response per active client, acknowledge at synchronous return, release completed/canceled together. Published order: spaced/direct, burst/sampled, spaced/sampled, burst/direct. Count measured offer jitter, admission wait, first-response from offer, interresponse and sojourn, closed native resources, maximum actual live/queue, memory and rates from first offer through release. Shared setup/teardown separately timed. No external service, guaranteed offered/ack deadlines or SLA. Four trials ×348 responses = **1392** arrival bytes plus **768** oracle = **2160**. Compare only same predictor+prefix, not unlike arrival rates as model speedups. Gate = complete matched prefixes, cancellations/terminal/freed counts, bounded capacity, evidence offers occurred while previous clients were in service, no extra host encodes, zero end payload and no surviving private/native children after shutdown. Archive/native root teardown must not race a live client. ≤150 additional inclusive card-s across all attempts; local 0/1 owner, independent witness; no training, private data, external changes, quality evaluation or publication.

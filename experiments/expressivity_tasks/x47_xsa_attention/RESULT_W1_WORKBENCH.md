# W1: a working, untrained branch program on a rebuilt Transformer workspace

**The controller chose the second native request and used a value it wrote. It was slower than direct backoff and produced the same distribution on this fixture.** This qualifies the first loop in the [workbench design](../../../docs/XSA_WORKBENCH_TRANSFORMER.md), not natural-language quality or useful learned navigation. No optimizer step, Pile read, P100 timing, private data, or native build.

## What actually ran

[Protocol](W1_PROTOCOL.md) `3dae84276`; [model](workbench_model.py), [native adapter](workbench_native.py), [decode loop](workbench.py), [tests](test_workbench.py) and [runner](workbench_run.py) frozen at `2d26ebfa8` before either device gate. One **605,757-parameter**, FP32, 20-slot × width-288 Transformer, one four-head self-attention block and residual MLP. The slots hold 8 recent bytes, 2 logical branch bookmarks, live/parent/child/recall/control inputs and 5 readers. Each typed reader can see its input, both handles, and the recent bytes. At birth uniform attention and an output projection copy the designated payload into its register; the downstream opcode, edge, writer and probability heads consume these registers. Initial byte probabilities include a uniform fallback. This is an explicitly constructed policy, not a pretrained LM.

CPU native services were one open causal session per independent document and one read-only sealed m20 session per fixture world. The latter contains **four short documents**, not a full `.sxi2` or an optimized 100 GB service. Mount binding, document boundaries, prefix visibility, fixed 8/4/2 suffix lookup, legal edges, write lifetime and memory capacity are enforced by the runtime. The model returns an opcode, two ranked edge IDs, and a greedy byte on each pass. In particular **Python doesn't decide `d` versus `c`**. The write is a device tensor, not a bookmark that triggers a hidden native re-read. The compiler policy can hold two alternatives and one next-byte-conditional record; this is not a general learned workspace allocator.

## Trace and interventions

The four archive documents are `retry_de`, `retry_de`, `retry_da`, `retry_c`. The live prefix is `retry_`. Below are the actual opcodes and archive replies for one matching path. The live suffix checks also ran and found no observed continuation on these steps.

| Visible transcript | Controller action | Consequence |
|---|---|---|
| `retry_` | `BASE` | `BRANCH(retry_)` → `d:3, c:1` in the archive. |
| `retry_` | `FOLLOW d` | Retain both handles; native `BRANCH(retry_d)` → `e:2, a:1`. |
| `retry_` | `WRITE_EMIT` | Save normalized child vector under `retry_d` for the next observation. Use the **parent** for the current prediction: `P(d)=0.60078` including the local fallback. |
| `retry_d` | `BASE_RECALL`, then `EMIT` | Read the live source, **no archive RPC**. With the saved vector `P(e)=0.534115`; with only that vector zeroed, `P(e)=0.00390625`. |

- **Change the index, not the model or prefix:** swapping the fork bytes in the archive changed the executed second request `retry_d` → `retry_c`. With the *original* index, a separate CPU test made the neural edge-score correction favor `c`: that also issued `retry_c` despite its lower native count. That child returned END only; no child value was written. Disabling attention transport of the byte payload (leaving control metadata intact) preserved the initial read but eliminated the follow and write.
- **Change the value, not the address:** in each archive world the erasure changed the later distribution by **0.530208** max on a matching observation, **exactly 0** on a mismatch. Bookmarks and read schedules were held fixed; no earlier emission changed. A separate autograd check sent later-byte loss to the actual writer weight through the stored tensor, without an update. This is not a derivative through discrete branch choice.
- **Check all outcomes, not just the modal byte:** [9 CPU tests passed](receipts/w1/cpu/tests.txt), including independent raw-byte scanning of all 257 branch bins, open/closed END, non-crossing binary matches, live evidence, source removal, reset, stale binding and scope refusal. Eight ordered trace cases per device (two archives × match/mismatch × keep/erase); max absolute error against analytic byte probabilities **1.59e−8**. The GPU loaded the actual CPU checkpoint: canonical state SHA-256 `e07aa9ff697e80fdf7eb5299a3a1692139a976fb4815cdce2cde4877951e4a39`. Discrete replay matched exactly; max CPU/GPU discrepancy across tested distributions, recalls and writes **0**. Full [CPU views](receipts/w1/cpu/cpu.json) and [GPU views](receipts/w1/gpu/parity.json), including keys/counts, logical positions, flags, chosen/alternate edges, write and read values.

## What did a generated byte cost?

One physical RTX 6000 Ada, Torch 2.9.1+cu128, FP32 eager, OMP=4. Each arm **generated** `de` or `ce` (not teacher-forced) following `retry_`. Thirty-two paired two-byte episodes per arm; both worlds equally represented, order rotated, after four warmup pairs per arm. Archive stayed resident. Fresh live-session launch/prefill excluded; every actual read, host dispatch, workspace rebuild, neural pass, decision return, live append and byte-end device sync included. This is serial decode on repeated tiny fixture keys, not throughput on novel corpus queries.

| Arm | Transformer passes per pair | Native branch calls per pair | Mean ms/byte | Median ms/two-byte pair |
|---|---:|---:|---:|---:|
| Rebuilt + conditional write (GPU) | 3 + 2 | 5 + 3 | 4.305 | 8.227 |
| Same Transformer, current-suffix only (GPU) | 2 + 2 | 4 + 4 | 3.464 | 6.851 |
| Direct native backoff + arithmetic (CPU, no model) | 0 | 4 + 4 | 0.534 | 1.041 |

The archive child was read **one byte earlier**, not one time fewer: both paths paid two archive reads plus six live suffix probes. The rebuilt policy did one extra Transformer pass. Its median pair cost was **20% higher** than the same-model control (mean within-pair difference +1.68 ms); about 7.9× the bare CPU baseline. The latter is not a CPU-vs-GPU comparison of the same neural network.

Separate synchronized diagnostics, eight pairs per arm: for rebuilt, mean accumulated per emitted byte was **0.359 ms** for native branch RPCs (includes pipe, JSON and validation), **0.107 ms** workspace packing, **0.095 ms** transfer, **3.324 ms** for Transformer calls, **0.082 ms** returning decisions, **0.038 ms** for append. Mean per rebuilt forward call 1.330 ms, including eager dispatch and synchronization, **not kernel-only time**. These fences and the primary clock are different runs. Both archive processes opened/ingested/sealed in 3.31 and 2.37 ms; mean live/decoder setup 1.58 ms in the rebuilt arm. [Raw times per pair and per diagnostic phase](receipts/w1/gpu/samples.jsonl) · [summary](receipts/w1/gpu/timing.json) · [offline receipt checks](receipts/w1/verified.json).

**Decision:** keep this as the executable reference. Don't optimize or train a prefetch policy on the premise that it adds evidence: on this task it doesn't. A useful next test would require the child read to change the *current* prediction, or a retained computation to provide value beyond an equally cheap fresh read. That is a different experiment, not an outcome of W1.

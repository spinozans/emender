# The CPU memory program sent exact gradients to a real 150M byte host

**Correctness passed; the registered cost gate did not.** With the staged bridge, the GPU held only **589 MiB** during the B32 program rollout, rather than **7,709 MiB** with the ordinary autograd tape. Every tested parameter adjoint matched. But the complete B32 gradient batch took **21.91 vs 13.57 s** (1.614×, limit 1.50×). Keep this an optional memory constraint trade-off, not the measured default. [Protocol](HOST_VJP_PROTOCOL.md) `767402e1d`, [transaction](../../../ndm/memory_program/host_vjp.py), source `85dc7b9cf`.

**What ran.** Real retained 149,855,670-parameter GDN2, training-mode native chunk kernels over 128 causal input bytes, BF16 autocast / FP32 master weights. Four documents per host microbatch. CPU FP32 288,987-parameter packed P2 controller, fresh sampled operations with indexed uniforms, exact whole-P100 + document-live readers. Direct retained the host tape through the program; remat staged CPU feature/logit leaves, backpropagated the full same objective, re-ran each causal host microbatch and injected the packet gradient. Each recomputed packet matched the corresponding prepass exactly. One gradient transaction, **zero optimizer updates** per cell. Nothing was learned or selected on held-out data.

That is not recompute time; we neither subtract it from the gate nor claim the measured wall gap is caused by the algorithm. Setup, purge, gradient snapshots and comparisons are outside gradient wall, inside lease.

**Equivalence.** 80 CPU gates. Same document/target/window hashes, logical instructions, provider keys/statuses and dispatch digests at each size; all 1,179,648 compared byte log probabilities and 4,608 joint scores identical, along with all-byte NLL and surrogate. All **597 host and 35 policy parameter tensors** had nonzero gradients. Across direct/remat max first-order differences 3.73e-9 B4 / 2.10e-9 B32. B32: 489 writes, 595 nonempty recalls of a prior-byte cell, 2,854 logical keys, 1 successful live contents read from a returned following-span rather than directly from a slice. Gradient coverage does not show that learning these decisions improves loss. 9,216 targets across all arms, incl. repeated paired observations; no trainable 2B result. Even the faster measured B32 path would need ~3,475 s for 1,048,576 gradient targets **before optimizer/eval**, vs 888 card-s left.

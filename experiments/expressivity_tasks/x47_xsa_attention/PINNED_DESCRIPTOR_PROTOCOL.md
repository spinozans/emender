# S16 — reuse the checked document descriptor, not a native worker

[S15](RESULT_BRANCH_DOMAIN.md) found a real setup saving (.235× summed open time) but rejected sharing the m20 process: its peak was 1.418× fresh. Leave that disposition in place. S16 separates **immutable mount description** from **native process lifetime**. Keep the same reference `R` traversal and do not make a warm-worker test smaller until it passes. CPU only, zero card-seconds; X47 ≤1386/1800. No model update, holdout, new dataset, external source change or network work.

**Candidate.** One trusted, thread/PID-bound, finite image of the whole admitted P100 version. Pin executable, index, text, separator and manifest, verify the executable SHA, exact registered mount identity, index directory/CRC and extents, sidecar SHAs, source stamps, all boundary starts/anchors. Retain checked read-only document metadata and pins only. Recheck live path/open-FD identities before/after construction and around grants and reads including cache hits. Fail closed on ordinary file replacement, mutation, stale/foreign owner or ambiguous worker state. Immutable metadata must not let one wave change another's document offsets. This is not a hostile-process security claim or a full index-content hash. No reusable raw query/answer cache, model state, open positional reader or surviving m20 in the image. A descriptor or pair of FDs **alone** cannot authorize a new checked launch.

Each sequential wave obtains a **new** m20 process via the pinned executable/index, verifies the real 16-byte header/root/tree and liveness, runs one bounded grant with an empty 256-page LRU, revokes the grant, closes/reaps that worker before another wave. Private positional/live bindings remain fresh as in S15. Enforce scope/version, wave budget, one active wave, no stale launch or expired-reader access; close pins even on failure. Validate on CPU with stale/overlapping launch, malformed worker or invalid pin, immutable-offset, post-return/close and cleanup checks. No SXGC change. Baseline is the original S15 **fresh** opener with full verification and fresh pins/descriptor/process per wave, not S15's memory-heavy resident path.

**Price once, after tests and a source freeze.** Four new CUDA-invisible strict four-thread subprocesses in order `fresh-A`, `image-A`, `image-B`, `fresh-B`; 360 s diagnostic cap, no retry for timing/gates. Same four S15 waves without changes to inputs, seed, precision, schedules or predictor: rows 0–31 of the verified T4 retained bytewise packet, eight distinct TRAIN documents/wave × first 32 observed frontiers, frozen post-T9 direct on 0/2, freely sampled P2 step-1 on 1/3 (seed 7530). Score before appending actual bytes; no generated traffic, gradients, training targets or updates. 1,024 predictions/cell, 4,096 total on 1,024 distinct positions. Check every per-wave score/trust-or-joint/argmax/evidence digest, sampled dispatch/logical work, exact row requests/replies and wire counts against each other **and S15 fresh-A**. Four m20 handshakes/exits per cell, all private actors reaped, expired grants refuse. Full descriptor verifications per cell: reference four, candidate one. Retain only counts, timing, process/identity evidence and digests.

**Decision.** Separate functional qualification from price. Primary wall starts *before* first attestation and ends *after* last worker, grant and image/pin close. Summed open wall charges all verification/construction including making offsets immutable, four real worker launches/handshakes, and binding overhead; no free first open. Report detailed open/close and per-wave wall, main+child core-s, input/model checks, interpreter-inclusive wall and main/native peaks. Recommend image reuse on this four-wave workload only if exactness/lifetime gates pass, mean primary wall ≤.85× reference, mean summed open wall ≤.60×, and worst main and m20 peak RSS each ≤1.20× reference. A failure doesn't justify weakening validation, changing reuse count or replacing the reference. No claims for positive LF walks, long-lived servers, GPU throughput or prediction quality.
